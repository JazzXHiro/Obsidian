### How to Use “Learning New Thing” Slot

- Pick one new skill or technology (e.g. Git & GitHub workflows, a JS framework, Linux basics, or a soft skill like speed reading).
    
- Follow a structured 4-week micro-course or playlist, aiming for ~1 hour/day.
    

---

### Tips for Maximizing This Timetable

1. **Set Clear Daily Goals:** Before each session note the specific topic/chapter or problem set.
    
2. **Use Pomodoro Within Blocks:** Break 2-hour sessions into 4×25 min bursts with 5 min breaks.
    
3. **Weekly Review (Sat 21–22 h & Sun 21–22 h):**
    
    - Check what you accomplished
        
    - Adjust next week’s backlog-focus if you’re ahead/behind
        
4. **Stay Flexible:** If a tough module needs extra time, borrow an hour from “Learning New Thing” or weekend review.
