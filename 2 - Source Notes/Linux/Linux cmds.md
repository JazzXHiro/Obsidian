# Linux cmds

1. **source** - The `source` command (or `.` in Bash/Zsh) **executes a script in the current shell session** instead of a subshell. This means any changes (like environment variables, aliases, or shell functions) persist after the script runs.

2. **fc-list** - Lists all fonts installed on your system that are recognized by `fontconfig` (the library managing fonts in Linux).

3. **grep** - Filters the output of `fc-list` to show only lines containing a specific keyword (case-sensitive by default).
