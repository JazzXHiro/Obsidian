# Data Structure

Data Structure is a way of organizing data so that it can be used effectively.

## Why Data Structure?

1. They are essential in creating in fast and powerful algorithms.

2. They help to manage and organize data.

3. They make code cleaner and easier to understand.

## Complexity Analysis

### 1. **Big - O Notation -** Worst case in time and space.

```
n - the size of the input

Complexities ordered in from smallest to largest.
```


| Time             | Notation     |
| ---------------- | ------------ |
| Constant Time    | $O(1)$       |
| Logarithmic Time | $O(log(n))$  |
| Linear Time      | $O(n)$       |
| Linearthmic Time | $O(nlog(n))$ |
| Quadric Time     | $O(n^2)$     |
| Cubic Time       | $O(n^3)$     |
| Exponential Time | $O(b^n),b>1$ |
| Factorial Time   | $O(n!)$      |

### 2. Big-O Properties

$$
\begin{in}
O(n+c)=O(n)
