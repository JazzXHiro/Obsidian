# 9. Comments

## Basic Definition Card (Question :: Answer)

What is a comment in source code?::A **comment** is a programmer-readable note that is inserted directly into the source code of the program. Comments are ignored by the compiler and are for the programmer's use only.

## Types of Comments Card (Question ? Answer)

What are the two main types of comments in C++?
?
1. **Single-line comments** (using `//`).
2. **Multi-line comments** (using `/*` and `*/`).

## Single-line Comment Syntax

What is the syntax for a single-line comment and what does it ignore?
?
The **`//`** symbol begins a C++ single-line comment, which tells the compiler to ignore everything from the `//` symbol **to the end of the line**.

## Multi-line Comment Syntax

What is the syntax for a multi-line comment and what does it ignore?
?
The **`/*` and `*/`** pair of symbols denotes a C-style multi-line comment. **Everything in between the symbols is ignored.**
