# Statements and the structure of a program

## Statement
 A **statement** is a type of instruction that causes the program to _perform some action_. Most (but not all) statements in C++ end in a semicolon.

## Functions
In C++, a **function** is a collection of statements that get executed sequentially (in order, from top to bottom).
	Every C++ program must have a special function named **main** (all lower case letters).

## Identifier
The name of a function (or object, type, template, etc…) is called its **identifier**.

## Character
A **character** is a written symbol or mark, such as a letter, digit, punctuation mark, or mathematical symbol.

## String
A sequence of characters is called **text** (also called a **string** in programming contexts).

## Plain text
Conventionally, the term “text” is also used to mean **plain text**, which is text that contains only characters that appear on a standard keyboard, with no special formatting or styling. For example, plain text cannot represent bold words, as that requires styling.
	Our C++ programs are written as plain text.
