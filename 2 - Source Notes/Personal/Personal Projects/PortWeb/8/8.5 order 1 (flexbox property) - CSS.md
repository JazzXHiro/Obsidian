# 8.5 order 1 (flexbox property) - CSS

`order: 1;` is a flexbox property that controls the visual order of flex items within a flex container.

By default, flex items have `order: 0`. When you set `order: 1;` on `.contact__form`, it tells that element to appear **after** other items with the default order (0). This allows you to rearrange the visual layout without changing the HTML.

In your case, on medium devices (768px+), the contact form will display in a different position than it would naturally appear in the HTML — useful for repositioning elements responsively while keeping the DOM structure intact.
