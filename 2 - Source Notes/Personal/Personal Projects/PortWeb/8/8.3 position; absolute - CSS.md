# position; absolute - CSS

`position: absolute;` removes an element from the **normal document flow** and positions it **relative to its nearest positioned ancestor**.

### What it does:

**Normal flow (without `position: absolute`):**
```
┌─────────────────────┐
│ Form input          │
├─────────────────────┤
│ Form textarea       │
├─────────────────────┤
│ Success message     │  ← Takes up space in normal flow
└─────────────────────┘
```

**With `position: absolute`:**
```
┌─────────────────────┐
│ Form input          │
├─────────────────────┤
│ Form textarea       │
└─────────────────────┘
    Success message    ← Floats outside normal flow
```

### In your code:

```css
.contact__form {
  position: relative;        /* Reference point for absolute positioning */
  row-gap: 1rem;
}

.contact__message {
  position: absolute;
  bottom: -2rem;            /* 2rem BELOW the form */
  font-size: var(--small-font-size);
}
```

The success/error message **doesn't take up space in the form** — it floats below it. When the form is submitted, the message appears **2rem below** without pushing other content down.

**Key points:**
- `position: relative` on parent creates a positioning context
- `bottom: -2rem` positions the message relative to that parent
- The message is taken out of normal flow, so it overlays without affecting layout

This is useful for feedback messages that should appear without disrupting the form layout!
