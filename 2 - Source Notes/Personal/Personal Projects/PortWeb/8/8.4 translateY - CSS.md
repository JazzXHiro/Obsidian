# 8.4 translate - CSS

`translateY` is a CSS transform function that moves an element vertically along the Y-axis.

- `translateY(-.25rem)` moves the element **up** by 0.25rem (negative values go up)
- `translateY(.25rem)` would move it **down** by 0.25rem (positive values go down)

In your code, `.home__link:hover` uses `transform: translateY(-.25rem)` to slightly lift the social media icons upward when you hover over them, creating a subtle interactive effect.
