# transition; autofill - CSS

`:autofill` targets input fields when the browser **automatically fills them** (like with saved passwords or contact info).

```css
.contact__input:autofill {
  transition: background-color 6000s, color 6000s;
}
```

### What's the problem?

By default, browsers apply a **blue background** and change text color when autofilling:

```
┌─────────────────────────┐
│ john@example.com        │  ← Blue background (browser's autofill)
└─────────────────────────┘
```

This **breaks your dark design**.

### The solution:

```css
transition: background-color 6000s, color 6000s;
```

This creates a **6000-second (100 minute) transition** for the background and text color changes.

**Why?** It delays the color change so long that it's imperceptible to users. By the time the transition completes, the user has already focused away from the field, so the autofill colors disappear before they're visible.

**It's a workaround** because CSS can't directly override browser autofill colors (for security reasons). This technique essentially hides the visual change by making it take an extremely long time.

**Better approach (not in your code):**
```css
.contact__input:autofill {
  -webkit-autofill-background-color: var(--body-color);
  -webkit-text-fill-color: var(--white-color);
}
```

But that only works in Chrome/Webkit browsers. Your current approach is safer cross-browser!
