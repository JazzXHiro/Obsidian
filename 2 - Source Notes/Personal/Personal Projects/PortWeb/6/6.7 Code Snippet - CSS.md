# Code Snippet - CSS

The `top: 0;` in `.projects__data` works together with `position: absolute;` to position the overlay:

```css
.projects__data{
  position: absolute;
  top: 0;      /* ← Aligns to the TOP edge of the card */
  left: 0;     /* ← Aligns to the LEFT edge of the card */
  width: 100%;
  height: 100%;
  background-color: hsla(var(--hue), 8%, 8%, .4);
}
```

**What it does:**

- `top: 0;` — Positions the overlay **0 pixels from the top** of the parent (`.projects__card`)
- Combined with `left: 0;`, `width: 100%;`, and `height: 100%;` — it creates an overlay that **covers the entire project card image**

**Visual explanation:**

```
┌─────────────────────────┐  ← top: 0 (starts here)
│  ┌───────────────────┐  │
│  │                   │  │
│  │   OVERLAY COVERS  │  │  ← The semi-transparent dark layer
│  │   ENTIRE IMAGE    │  │
│  │                   │  │
│  └───────────────────┘  │
└─────────────────────────┘
   ↑
   left: 0 (starts here)
```

This creates the **dark semi-transparent overlay** on top of your project images where the title, description, and button will appear. Without `top: 0;`, the overlay wouldn't be anchored to the top of the card.
