# pointer-events - CSS

The `pointer-events` property controls **how an element responds to mouse/touch interactions**.

### Common Values:

| Value | Effect |
|-------|--------|
| `auto` | Normal behavior (default) — element is clickable |
| `none` | Element **ignores** all mouse/touch events — clicks pass through to elements behind it |

### Example:

```css
.overlay {
  pointer-events: none;  /* Clicks go through this element */
}

.overlay:hover {
  pointer-events: auto;  /* Now it's clickable again */
}
```

### In Your Project Context:

In your `.projects__data` you have this commented out:

```css
.projects__data {
  /* opacity: 0;
  pointer-events: none;   ← This!
  transition: opacity .4s; */
}
```

When uncommented, here's what happens:

1. **Initially:** The overlay is invisible (`opacity: 0`) and `pointer-events: none` means you can click **through** the overlay to the image beneath
2. **On hover:** The overlay fades in and `pointer-events: auto` makes the button clickable

**Without `pointer-events: none`:** Even an invisible overlay would block clicks on elements behind it, which would be frustrating for users.
