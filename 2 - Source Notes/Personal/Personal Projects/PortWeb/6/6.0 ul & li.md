# ul & li

**`<ul>`** = **Unordered List** (the container)  
**`<li>`** = **List Item** (each item inside)

```html
<ul>           <!-- the list container -->
  <li>Home</li>      <!-- item 1 -->
  <li>About</li>     <!-- item 2 -->
  <li>Contact</li>   <!-- item 3 -->
</ul>
```

| Element | Role | Visual default |
|---------|------|----------------|
| `<ul>` | Groups all items together | Adds padding/margin |
| `<li>` | A single item in that list | Shows a bullet point |

**Related:**
- `<ol>` = **Ordered List** (numbered: 1, 2, 3…)
- `<ul>` = **Unordered List** (bullets: •, •, •)

In your nav, you use `<ul class="nav__list">` as the container and `<li>` for each nav link.
