# Padding vs Margin - CSS

## Core difference

- **Padding** = space **inside** an element (between content and border)
    
- **Margin** = space **outside** an element (between elements)
    

```text
margin → | border | padding | content | padding | border | ← margin
```

---

## `padding`

### What it does

- Pushes content **inward**
    
- Increases clickable / visible area
    
- Is part of the element’s box
    

```css
.card {
  padding: 1rem;
}
```

### Key characteristics

- Cannot be negative
    
- Background color **extends into padding**
    
- Affects element size (unless `box-sizing: border-box`)
    
- Does **not collapse**
    

---

## `margin`

### What it does

- Pushes other elements **away**
    
- Creates spacing between elements
    

```css
.card {
  margin: 1rem;
}
```

### Key characteristics

- Can be **negative**
    
- Background does **not** extend into margin
    
- Does not affect element’s internal size
    
- **Can collapse vertically**
    

---

## Margin collapsing (important edge case)

Vertical margins between block elements can collapse into one.

```css
p {
  margin: 20px 0;
}
```

Two `<p>` elements stacked:

- Expected: `40px`
    
- Actual: `20px`
    

Padding **never collapses**.

---

## Padding vs Margin (side-by-side)

|Aspect|Padding|Margin|
|---|---|---|
|Location|Inside border|Outside border|
|Affects background|Yes|No|
|Can be negative|No|Yes|
|Collapses|No|Yes (vertical only)|
|Affects click area|Yes|No|

---

## When to use padding

Use padding when:

- Spacing content **inside** a component
    
- Increasing button click area
    
- Creating inner breathing room
    

Example:

```css
.button {
  padding: 0.75rem 1.5rem;
}
```

---

## When to use margin

Use margin when:

- Separating components
    
- Creating layout spacing
    
- Positioning elements relative to each other
    

Example:

```css
.section {
  margin-bottom: 4rem;
}
```

---

## Common real-world pattern (correct)

```html
<section class="section">
  <div class="container">
    <!-- content -->
  </div>
</section>
```

```css
.section {
  margin-bottom: 4rem;     /* spacing between sections */
}

.container {
  padding-inline: 1.5rem;  /* spacing inside content */
}
```

---

## Common mistakes

- Using margin to create button padding ❌
    
- Using padding to separate sections ❌
    
- Forgetting margin collapse behavior ❌
    
- Mixing padding and margin without intent ❌
    

---

## Interview-ready explanation

> “Padding controls internal spacing between content and border, while margin controls external spacing between elements. Padding affects the element’s box; margin affects layout flow.”

---

## One-line rule

**Padding is for content comfort. Margin is for layout separation.**
