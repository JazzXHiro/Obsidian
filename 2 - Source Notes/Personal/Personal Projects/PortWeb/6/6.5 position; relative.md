# position; relative

The `position: relative;` property on `.projects__card` does a few important things:

1. **Creates a positioning context** — Any child element with `position: absolute;` will be positioned relative to this card, not the entire page. This is commonly used for overlays, badges, or hover effects on project cards.

2. **Enables z-index** — It allows you to use `z-index` on the card to control stacking order.

3. **Allows offset properties** — You can use `top`, `right`, `bottom`, `left` to nudge the card from its normal position (though it's not being used here).

In the tutorial you're following, this is likely preparation for adding an **overlay effect** on the project cards — where the `.projects__data` section slides up or fades in over the image on hover. That overlay would use `position: absolute;` to sit on top of the image, and it needs the parent (`.projects__card`) to have `position: relative;` to work correctly.

**Example of what it enables:**
```css
.projects__data {
  position: absolute;  /* Positioned relative to .projects__card */
  bottom: 0;
  left: 0;
  /* ... overlay styling */
}
```

Without `position: relative;` on the card, the absolutely positioned overlay would float off to the nearest positioned ancestor (or the viewport), breaking the layout.
