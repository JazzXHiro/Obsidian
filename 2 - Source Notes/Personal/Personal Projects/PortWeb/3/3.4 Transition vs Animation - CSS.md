# Transition vs Animation - CSS

## 🧠 Big Picture

Both are CSS ways to create motion, but they solve **different problems**.

|Feature|`transition`|`animation`|
|---|---|---|
|Trigger|Needs a **change** (hover, class toggle)|Runs **by itself**|
|Complexity|Simple (start → end)|Complex (many steps)|
|Control|Limited|Full timeline control|
|Typical use|Hover effects, toggles|Loaders, loops, keyframes|

---

## 1️⃣ `transition` — _Animate a Change_

### What it does

> Smoothly animates a property **when its value changes**.

It does **nothing** unless something changes.

### Example

```css
.button {
  color: white;
  transition: color 0.4s;
}

.button:hover {
  color: red;
}
```

### What happens

- No hover → white
    
- Hover → color changes
    
- `transition` makes that change smooth
    

### Key rule

> **Transitions need a trigger.**

Common triggers:

- `:hover`
    
- `:focus`
    
- Adding/removing a class with JS
    
- Media query change
    

---

## 2️⃣ `animation` — _Run on Its Own_

### What it does

> Runs a predefined sequence of styles **automatically**.

It does **not** need hover or interaction.

### Example

```css
@keyframes fadeIn {
  from { opacity: 0; }
  to   { opacity: 1; }
}

.box {
  animation: fadeIn 1s ease;
}
```

### What happens

- As soon as `.box` appears → animation runs
    
- No user action required

---

## 🧩 Key Difference (Mental Model)

```
transition → reacts to change
animation  → creates change
```

---

## 🔁 Multiple Steps vs One Step

### Transition (only start → end)

```css
transition: width 0.4s;
```

### Animation (many steps)

```css
@keyframes slide {
  0%   { transform: translateX(0); }
  50%  { transform: translateX(50px); }
  100% { transform: translateX(0); }
}
```

---

## 🎯 When to Use WHAT (Very Important)

### ✅ Use `transition` for:

- Hover effects
    
- Menu open/close
    
- Color, width, opacity changes
    
- Simple UI feedback
    

Example:

```css
.nav__link {
  transition: color 0.3s;
}
```

---

### ✅ Use `animation` for:

- Loading spinners
    
- Continuous motion
    
- Intro animations
    
- Repeating effects
    

Example:

```css
.loader {
  animation: spin 1s linear infinite;
}
```

---

## ⚠️ Performance Tip (Interview Gold)

- **Best to animate:** `transform`, `opacity`
    
- **Avoid animating:** `width`, `height`, `top` (layout cost)
    

Both `transition` and `animation` follow this rule.
