# document.getElementById

## 🧠 What `document.getElementById` Is

```js
document.getElementById("header")
```

It is a **DOM method** used to **find an HTML element by its `id`**.

In plain English:

> “Go to the page (`document`) and give me the element whose `id` is `"header"`.”

---

## 🔍 Breaking the Name Apart

### 1️⃣ `document`

- Represents the **entire web page**
    
- It’s the root object of the DOM

### 2️⃣ `getElementById`

- A **method** (function)
    
- Searches the DOM for an element with a specific `id`

### 3️⃣ `"header"`

- The **exact value** of the `id` attribute
    
- IDs are **case-sensitive** and **unique**

---

## 🧩 Example in HTML

```html
<header id="header"></header>
```

JavaScript:

```js
const header = document.getElementById("header");
```

Now:

- `header` holds a **reference to that element**
    
- You can manipulate it

---

## 🔁 What You Can Do After Selecting It

```js
header.style.backgroundColor = "black";
header.classList.add("scroll-header");
header.textContent = "My Header";
```

This is how JS **controls the page**.

## ⚠️ Very Important Rules

### ✅ IDs must be unique

```html
<div id="box"></div>
<div id="box"></div> ❌ wrong
```

If duplicates exist:

- JS returns the **first one**
    
- Bugs guaranteed

---

### ❌ If element doesn’t exist

```js
const x = document.getElementById("does-not-exist");
console.log(x); // null
```

Trying to use `x.style` will cause an error.

---

## 🆚 Compared to Other Selectors

|Method|What it selects|
|---|---|
|`getElementById`|One element by ID|
|`querySelector`|First matching selector|
|`querySelectorAll`|All matching selectors|

Example:

```js
document.querySelector("#header"); // same result
```

But:

- `getElementById` is **faster**
    
- Simpler
    
- Most common for single elements
    

---

## 🎯 Interview-Ready Explanation

> “`document.getElementById` retrieves a reference to a DOM element with a specific ID, allowing JavaScript to manipulate it.”

---

## 🧠 One-Line Rule (Memorize This)

> **Use `getElementById` when you want exactly one element and you know its ID.**
