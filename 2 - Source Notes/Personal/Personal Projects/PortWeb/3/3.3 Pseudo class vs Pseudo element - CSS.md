# Pseudo class vs Pseudo element - CSS

## 🧠 The Selector

```css
.nav__link:hover::after
```

Read it like a sentence:

> “Select the `::after` pseudo-element of `.nav__link` **when the link is hovered**.”

Let’s break down the two symbols.

---

## 1️⃣ Single Colon `:` → **Pseudo-class**

### What `:hover` Is

```css
:hover
```

A **pseudo-class** represents a **state** of an existing element.

Common pseudo-classes:

- `:hover`
    
- `:active`
    
- `:focus`
    
- `:visited`
    
- `:checked`
    

In your code:

```css
.nav__link:hover
```

Means:

> “When the user’s mouse is over `.nav__link`.”

Nothing new is created — it’s the **same element**, just in a different state.

---

## 2️⃣ Double Colon `::` → **Pseudo-element**

### What `::after` Is

```css
::after
```

A **pseudo-element** represents a **virtual element** created by CSS.

It:

- Does **not** exist in HTML
    
- Is generated by CSS
    
- Acts like a real element for styling
    

Common pseudo-elements:

- `::before`
    
- `::after`
    
- `::first-letter`
    
- `::first-line`
    

---

## 🔍 What `::after` Specifically Does

`::after` creates a **virtual element after the content** of the selected element.

Example:

```css
.nav__link::after {
  content: "";
  display: block;
  width: 0;
  height: 2px;
}
```

This is often used for:

- Underlines
    
- Highlights
    
- Decorative effects

---

## 🧩 Putting It All Together

```css
.nav__link:hover::after {
  width: 100%;
}
```

### Execution logic:

1. User hovers over `.nav__link`
    
2. `:hover` becomes active
    
3. The `::after` pseudo-element responds
    
4. Its width changes (animated if transition exists)

---

## 🧠 Visual Mental Model

```text
.nav__link (real element)
 ├─ :hover (state)
 └─ ::after (virtual child element)
```

---

## 🎯 Interview-Ready Explanation

> “The single colon denotes a pseudo-class representing an element’s state, while the double colon denotes a pseudo-element that represents a virtual element created by CSS.”
