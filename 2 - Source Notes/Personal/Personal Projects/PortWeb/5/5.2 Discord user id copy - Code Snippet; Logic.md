## 🧠 JavaScript (add once in your JS file)

```js
function copyDiscord(event) {
  event.preventDefault(); // stops page jump

  const discordUsername = "YourUsername#1234";
  const msg = document.getElementById("discord-msg");

  navigator.clipboard.writeText(discordUsername).then(() => {
    msg.textContent = "Discord username copied!";
    
    setTimeout(() => {
      msg.textContent = "";
    }, 2000);
  });
}
```

🔁 Replace `YourUsername#1234` with your actual Discord username.

This line creates a **placeholder element** that JavaScript can update dynamically.

```html
<span id="discord-msg" class="copy-msg"></span>
```

## 🧠 What This Element Is

`<span>` is an **inline HTML element** used to hold **small pieces of content**, usually text.

By itself, this span:

- Shows **nothing**
    
- Takes **no visible space**
    
- Just exists in the DOM

Think of it as an **empty label waiting to be filled**.

---

## 🔍 Part-by-Part Explanation

### 1️⃣ `<span> ... </span>`

- Inline container
    
- Does **not** break lines (unlike `<div>`)
    
- Commonly used for:
    
    - Messages
        
    - Icons
        
    - Small dynamic text

---

### 2️⃣ `id="discord-msg"`

- Gives the element a **unique identifier**
    
- Allows JavaScript to find it:
    

```js
document.getElementById("discord-msg");
```

This is how JS knows **where to show the message**.

---

### 3️⃣ `class="copy-msg"`

- Used for **styling with CSS**
    

Example:

```css
.copy-msg {
  font-size: 0.85rem;
  color: var(--first-color);
}
```

ID = JavaScript  
Class = CSS

(That separation is best practice.)

---

## 🔁 How It’s Used in Your Code

### JavaScript fills it dynamically:

```js
msg.textContent = "Discord username copied!";
```

Result in the browser:

```html
<span>Discord username copied!</span>
```

After a timeout, JS clears it:

```js
msg.textContent = "";
```

The message disappears again.
