## 🧠 JavaScript (add once in your JS file)

```js
function copyDiscord(event) {
  event.preventDefault(); // stops page jump

  const discordUsername = "YourUsername#1234";
  const msg = document.getElementById("discord-msg");

  navigator.clipboard.writeText(discordUsername).then(() => {
    msg.textContent = "Discord username copied!";
    
    setTimeout(() => {
      msg.textContent = "";
    }, 2000);
  });
}
```

🔁 Replace `YourUsername#1234` with your actual Discord username.

## 🧪 Alternative (Keep BOTH behaviors)

If you want:

- **Left click → copy**
    
- **Right click → open profile**
    

Then keep the real link and do this instead 👇

```html
<a href="https://discord.com/users/403871332208738304"
   target="_blank"
   class="home__link"
   onclick="copyDiscord(event)">
  <i class="ri-discord-fill"></i>
</a>
```

This works because:

- `event.preventDefault()` stops navigation
    
- Right-click still works
