# justify-content vs align-content

## 🧭 First: Axes Refresher (Very Important)

With default Flexbox:

```css
flex-direction: row;
```

- **Main axis** → horizontal (left ↔ right)
    
- **Cross axis** → vertical (top ↕ bottom)

---

## 1️⃣ `justify-content` — spacing of items **within a row**

### What it controls

> **How flex items are spaced along the MAIN axis (inside each row).**

```css
.container {
  display: flex;
  flex-wrap: wrap;
  justify-content: space-between;
}
```

### What it affects

- Items **inside a single row**
    
- Horizontal spacing (for `row` direction)

### Common values

- `flex-start`
    
- `center`
    
- `space-between`
    
- `space-around`
    
- `space-evenly`

---

## 2️⃣ `align-content` — spacing of rows **inside the container**

### What it controls

> **How multiple rows are spaced along the CROSS axis.**

```css
.container {
  display: flex;
  flex-wrap: wrap;
  align-content: space-between;
}
```

### What it affects

- **Rows themselves**, not individual items
    
- Vertical spacing **between rows**
    

⚠️ **This does NOTHING if there is only one row.**

---

## 🔥 THIS is the Key Difference (Memorize)

|Property|Controls|Axis|Requires wrap?|
|---|---|---|---|
|`justify-content`|Items in a row|Main axis|❌ No|
|`align-content`|Rows in container|Cross axis|✅ Yes|

## 🧪 Example That Shows the Difference

### HTML

```html
<div class="container">
  <div class="box"></div>
  <div class="box"></div>
  <div class="box"></div>
  <div class="box"></div>
  <div class="box"></div>
</div>
```

### CSS

```css
.container {
  height: 400px;
  display: flex;
  flex-wrap: wrap;

  justify-content: space-between;
  align-content: space-between;
}
```

### Result

- Boxes are spaced **horizontally** in each row → `justify-content`
    
- Rows are spaced **vertically** inside container → `align-content`
    

---

## ⚠️ Common Mistake (Very Important)

People expect this to work:

```css
align-content: center;
```

…but forget:

```css
flex-wrap: wrap;
```

❌ Result: **Nothing happens**

Why?

- There is only **one row**
    
- `align-content` has nothing to align
    

---

## 🆚 `align-items` vs `align-content` (Quick Clarifier)

|Property|Affects|
|---|---|
|`align-items`|Items **inside a row**|
|`align-content`|**Rows** inside container|

```css
align-items: center;   /* vertical align of items */
align-content: center; /* vertical spacing of rows */
```

---

## 1️⃣ `flex-start`

### `justify-content: flex-start`

Items stick to the **start of each row**:

```
Row 1: | item item item      |
Row 2: | item item           |
```

### `align-content: flex-start`

All rows stick to the **top of the container**:

```
| Row 1 |
| Row 2 |
|       |
|       |
```

---

## 2️⃣ `center`

### `justify-content: center`

Items are centered **within each row**:

```
Row 1: |    item item item   |
Row 2: |      item item     |
```

### `align-content: center`

All rows are grouped in the **vertical center**:

```
|       |
| Row 1 |
| Row 2 |
|       |
```

---

## 3️⃣ `space-between`

### `justify-content: space-between`

Space goes **between items**, none at row edges:

```
Row 1: |item    item    item|
Row 2: |item        item   |
```

### `align-content: space-between`

Space goes **between rows**, none at top/bottom:

```
| Row 1 |
|       |
|       |
| Row 2 |
```

---

## 4️⃣ `space-around`

### `justify-content: space-around`

Each item has space around it  
(edges get half space):

```
Row 1: |  item   item   item  |
Row 2: |   item     item     |
```

### `align-content: space-around`

Each row has space around it  
(top/bottom get half space):

```
|   Row 1   |
|           |
|   Row 2   |
```

---

## 5️⃣ `space-evenly`

### `justify-content: space-evenly`

Equal space **everywhere horizontally**:

```
Row 1: |   item   item   item   |
Row 2: |     item     item     |
```

### `align-content: space-evenly`

Equal space **everywhere vertically**:

```
|   Row 1   |
|   Row 2   |
|           |
```

---

## 🔥 Side-by-Side Summary Table

|Value|`justify-content` does|`align-content` does|
|---|---|---|
|`flex-start`|Items to row start|Rows to container top|
|`center`|Items centered in row|Rows centered vertically|
|`space-between`|Space between items|Space between rows|
|`space-around`|Space around items|Space around rows|
|`space-evenly`|Equal item spacing|Equal row spacing|

---

## ⚠️ Common Mistake (Very Important)

```css
align-content: center;
```

❌ **Nothing happens** if:

- There is only **one row**
    
- `flex-wrap: wrap` is missing
    

Because there are **no multiple rows to space**.

---

## 🎯 Interview-Ready Explanation

> “The same values apply to both properties, but `justify-content` distributes space between flex items along the main axis, while `align-content` distributes space between multiple rows along the cross axis and only works when wrapping is enabled.”

That answer is **exactly correct**.
