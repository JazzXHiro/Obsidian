# Code Snippet - CSS

The "columns" come from **Flexbox**, not CSS Grid.

Your `.home__buttons` has:

```css
.home__buttons{
  display: flex;
  flex-wrap: wrap;
  gap: .5rem;
  justify-content: center;
  margin-top: 2rem;
}
```

With `display: flex`, items (your two buttons) sit **side by side** in a row by default (`flex-direction: row`).

So `column-gap: 1.5rem;` sets the **horizontal space between those flex items** (the "Download CV" button and the "Projects" button).

In Flexbox:
- `column-gap` = horizontal gap (between items in a row)
- `row-gap` = vertical gap (when items wrap to a new line)
- `gap` = shorthand for both
