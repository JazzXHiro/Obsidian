# target = _blank

In this HTML code, `target="_blank"` is an attribute of the anchor (`<a>`) tag that controls **where the linked page opens**.

Specifically, `target="_blank"` means:

- The link will open in a **new browser tab or window** (rather than replacing the current page)

**Common `target` values:**

- `_blank` - Opens in a new tab/window
- `_self` - Opens in the same frame (default behavior)
- `_parent` - Opens in the parent frame
- `_top` - Opens in the full body of the window
