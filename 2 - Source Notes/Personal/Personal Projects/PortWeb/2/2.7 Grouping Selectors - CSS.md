# 2.7 Grouping Selectors - CSS

## 🧠 The Code

```css
.nav__toggle,
.nav__close {
  font-size: 1.5rem;
  cursor: pointer;
}
```

---

## 🔑 Why Are There TWO Selectors?

The **comma (`,`)** means:

> **Apply the same styles to multiple selectors.**

This is called **grouping selectors**.

So CSS reads this as:

```text
Apply these rules to:
- .nav__toggle
AND
- .nav__close
```

---

## 🧩 What This Is Equivalent To

This:

```css
.nav__toggle,
.nav__close {
  font-size: 1.5rem;
  cursor: pointer;
}
```

is exactly the same as writing:

```css
.nav__toggle {
  font-size: 1.5rem;
  cursor: pointer;
}

.nav__close {
  font-size: 1.5rem;
  cursor: pointer;
}
```

But shorter, cleaner, and more maintainable.

---

## 🔍 What These Classes Usually Are

In a responsive navbar:

```html
<i class="nav__toggle ri-menu-line"></i>
<i class="nav__close ri-close-large-line"></i>
```

- `.nav__toggle` → **hamburger menu icon (open menu)**
    
- `.nav__close` → **close (×) icon**
    

Both:

- Are icons
    
- Are clickable
    
- Need the same size
    
- Need the pointer cursor
    

So they **share styles**.

---

## 🎯 Why This Is Good Practice

Grouping selectors:

- Avoids duplicated CSS
    
- Keeps code DRY (Don’t Repeat Yourself)
    
- Makes future changes easy
    

Example:  
Change size once → both icons update.
