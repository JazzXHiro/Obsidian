# 2.6 hover - CSS

This is a **hover interaction rule** in CSS.

---

## 🧠 The Code

```css
.nav__logo:hover {
  color: var(--first-color);
}
```

---

## 1️⃣ `.nav__logo` — The Selector

This targets any element with the class:

```html
<a class="nav__logo">MyLogo</a>
```

So this rule applies **only** to the logo element in your navigation.

---

## 2️⃣ `:hover` — The Pseudo-Class

### What `:hover` Means

`:hover` is a **CSS pseudo-class** that activates when:

> The user’s mouse pointer is placed over the element.

It represents a **temporary state**, not a real element.

So this rule applies:

- Only while the cursor is hovering
    
- Not before
    
- Not after
    

---

## 3️⃣ `{ color: var(--first-color); }` — The Style

### 🔹 `color`

Changes the **text/icon color** of the element.

If `.nav__logo` contains:

- Text → text color changes
    
- Icon font → icon color changes
    

---

### 🔹 `var(--first-color)`

This uses a **CSS variable** defined earlier, likely in `:root`:

```css
--first-color: hsl(var(--hue), 80%, 48%);
```

Benefits:

- Consistent theme color
    
- Easy theme switching
    
- Dark/light mode friendly
    

---

## 🔁 What Happens Visually

Before hover:

- Logo uses default color (probably white or gray)
    

On hover:

- Logo smoothly changes to the **primary accent color**
    

This gives:  
✔ Visual feedback  
✔ Better UX  
✔ Professional feel

---

## 🧪 Why This Is Important UX

Hover effects:

- Show that an element is **interactive**
    
- Improve usability
    
- Make navigation feel responsive
    

Without hover:

- Links feel “dead”
