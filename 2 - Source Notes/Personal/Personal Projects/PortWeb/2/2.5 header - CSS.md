# header - CSS

## 🧠 The CSS Rule

```css
.header {
  position: fixed;
  width: 100%;
  top: 0;
  left: 0;
  background-color: var(--body-color);
  z-index: var(--z-fixed);
  transition: box-shadow .4s;
}
```

This styles the **page header/navigation bar** so it stays visible while scrolling.

---

## 1️⃣ `.header { ... }` — The Selector

Targets:

```html
<header class="header"></header>
```

So everything inside this block applies **only to the header**.

---

## 2️⃣ `position: fixed;` — Sticky to the Viewport

### What it does

- Removes the element from normal document flow
    
- Positions it **relative to the viewport**
    
- Keeps it visible even when scrolling

Result:

> The header stays at the top of the screen at all times.

Without this:

- Header scrolls away normally

---

## 3️⃣ `width: 100%;` — Full Width Bar

### Why it’s needed

A fixed element **shrinks to content width** unless specified.

```css
width: 100%;
```

Forces the header to:

- Stretch across the entire viewport

---

## 4️⃣ `top: 0;` — Stick to the Top

```css
top: 0;
```

Positions the header:

- At the very top of the viewport

This only works because `position: fixed` is set.

---

## 5️⃣ `left: 0;` — Align to Left Edge

```css
left: 0;
```

Ensures:

- No horizontal offset
    
- Header starts at the left edge

Together:

```css
top: 0;
left: 0;
```

→ Top-left corner of the screen.

---

## 6️⃣ `background-color: var(--body-color);` — Themed Background

Uses a **CSS variable**:

```css
var(--body-color)
```

---

## 7️⃣ `z-index: var(--z-fixed);` — Stay Above Everything

### What `z-index` does

Controls **stacking order** (which element appears on top).

```css
z-index: var(--z-fixed);
```

This ensures:

- Header appears **above page content**

- Not hidden by sections, images, or modals

The variable might be defined like:

```css
--z-fixed: 100;
```

---

## 8️⃣ `transition: box-shadow .4s;` — Smooth Shadow Animation

### What it does

Animates **only the `box-shadow` property**.

Duration:

- `0.4s` (400 milliseconds)

Typical use:

- Add a shadow when user scrolls

- Remove shadow at top


Example JS/CSS combo:

```css
.scroll-header {
  box-shadow: 0 2px 10px rgba(0,0,0,.2);
}
```

When class toggles → shadow animates smoothly.

## 🧠 One-Line Summary

- `fixed` → always visible
    
- `top: 0` → pinned to top
    
- `z-index` → above content
    
- `transition` → smooth shadow
