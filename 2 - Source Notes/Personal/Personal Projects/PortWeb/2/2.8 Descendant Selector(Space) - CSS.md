# Descendant Selector(Space) - CSS

## 🔹 Descendant Selectors (Space )

### Syntax

```CSS
.nav__menu a {
  color: white;
}
```
### Meaning

> **Apply styles to `<a>` elements INSIDE `.nav__menu`.**

This targets:

```CSS
<div class="nav__menu">
  <a>✔ styled</a>
</div>

<a>❌ not styled</a>
```

### Mental model

Think **INSIDE / CHILD OF**:

`a INSIDE .nav__menu`
