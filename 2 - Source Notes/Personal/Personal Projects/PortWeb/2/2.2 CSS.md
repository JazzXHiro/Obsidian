# CSS

	## 🧠 What This Section Is

```CSS
/*=============== VARIABLES CSS ===============*/

:root {

  --header-height: 3.5rem;

  

  /*========== Colors ==========*/

  /*

      Color mode HSL(hue, saturation, lightness)

  

      Change favorite color:

  

      Default Cyan: hsl(180, 80%, 48%)

      Blue: hsl(220, 90%, 64%) - Pink: hsl(300, 70%, 64%)

      Green: hsl(110, 70%, 64%) - Purple: hsl(255, 70%, 64%)

      Orange: hsl(15, 80%, 64%) - Red: hsl(358, 80%, 64%)

  

      For more colors visit: https://htmlcolorcodes.com/

      -> Choose any color

      -> Copy the color mode (HSL)

  */

  --hue: 180;

  --first-color: hsl(var(--hue), 80%, 48%);

  --first-color-alt: hsl(var(--hue), 80%, 44%);

  --white-color: hsl(var(--hue), 8%, 92%);

  --black-color: hsl(var(--hue), 4%, 8%);

  --gray-color: hsl(var(--hue), 4%, 50%);

  --body-color: hsl(var(--hue), 8%, 8%);

  --container-color: hsl(var(--hue), 8%, 12%);
```

This whole block defines **CSS variables (custom properties)** that control:

- Layout sizes
    
- Theme colors
    
- Light/dark consistency
    
- Easy color switching
    

It is essentially your **design system**.

## 1️⃣ CSS Comment Blocks

```css
/*============= VARIABLES CSS =============*/
```

and

```css
/*============= Colors =============*/
```

These are **CSS comments**.

- They do nothing functionally
    
- They improve readability
    
- They divide the file into logical sections
    

The long `=====` style is just a **visual divider**.

---

## 2️⃣ `:root { ... }` — The Global Scope

```css
:root {
```

### What `:root` means

`:root` is a **CSS pseudo-class** that represents the **highest-level element** of the document (the `<html>` element).

Variables defined here are:

- **Global**
    
- Available everywhere
    
- Inherited by all elements
    

Think of `:root` as:

> “Global config for my entire website”

---

## 3️⃣ CSS Variables (Custom Properties)

CSS variables always start with `--`

Example:

```css
--header-height: 3.5rem;
```

### What this does

- Defines a reusable value
    
- `3.5rem` ≈ relative size based on root font size
    
- Used later like this:
    

```css
height: var(--header-height);
```

This makes layout changes **safe and centralized**.

---

## 4️⃣ The Color System Comment (Important)

```css
/*
  Color mode HSL(hue, saturation, lightness)
  Change favorite color:
*/
```

This explains that the project uses **HSL color mode**, not RGB or HEX.

### Why HSL is used

Because:

- Hue = color type
    
- Saturation = intensity
    
- Lightness = brightness
    

This makes **theme control MUCH easier**.

---

## 5️⃣ `--hue: 180;` — The Master Color Knob

```css
--hue: 180;
```

This is the **most important line**.

- `180` = cyan
    
- Change this ONE value → entire site theme changes
    

Examples:

```css
--hue: 220; /* Blue */
--hue: 110; /* Green */
--hue: 358; /* Red */
```

This is **professional theming**.

---

## 6️⃣ Derived Colors Using `var(--hue)`

Example:

```css
--first-color: hsl(var(--hue), 80%, 48%);
```

### What’s happening

- `var(--hue)` injects the hue value
    
- Saturation and lightness vary
    
- All colors stay in the same color family
    

So if you change:

```css
--hue: 300;
```

Everything becomes **pink-themed** automatically.

---

## 7️⃣ Color Roles (Design System)

Each variable has a **semantic role**, not a random name:

```css
--first-color        /* primary accent */
--first-color-alt    /* hover / secondary */
--white-color        /* text / icons */
--black-color        /* background */
--gray-color         /* muted text */
--body-color         /* page background */
--container-color    /* card / section bg */
```

This is **very important**.

You are not saying:  
❌ “blue”, “dark blue”, “light blue”

You are saying:  
✅ “primary”, “background”, “text”

That’s scalable design thinking.

---

## 9️⃣ How These Variables Are Used Later

Example usage:

```css
body {
  background-color: var(--body-color);
  color: var(--white-color);
}

header {
  height: var(--header-height);
  background-color: var(--container-color);
}
```

Change values once → entire site updates.

---

This approach gives you:

- Centralized theming
    
- Easy dark/light mode
    
- Easy brand color changes
    
- Cleaner CSS
    
- Less duplication
    

This is **industry-grade CSS**, not beginner code.
