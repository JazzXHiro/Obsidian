# 1.3 Link


```html
<link rel="shortcut icon" href="PortWeb/img/favicon.png" type="image/x-icon">
```

---

## 🧠 What `<link>` Is Used For

`<link>` connects your HTML document to **external resources**.

Common uses:

- Favicons
    
- Stylesheets (CSS)
    
- Fonts
    
- Preconnects
    

This specific `<link>` connects a **favicon**.

---

## 🔍 Attribute-by-Attribute Breakdown

### 1️⃣ `rel="shortcut icon"`

**rel = relationship**

This tells the browser:

> “This file is the website’s favicon.”

- `icon` → standard
    
- `shortcut icon` → legacy (for older browsers)
    

Modern best practice:

```html
<link rel="icon" href="favicon.png">
```

But `shortcut icon` still works everywhere.

---

### 2️⃣ `href="PortWeb/img/favicon.png"`

**href = hyperlink reference**

This is:

- The **path** to the favicon file
    

In your case:

- `PortWeb/` → root folder
    
- `img/` → image directory
    
- `favicon.png` → icon file
    

📌 Important:

- Path must be **correct relative to the HTML file**
    
- If wrong → no favicon appears
    

---

### 3️⃣ `type="image/x-icon"`

**type = MIME type**

This tells the browser:

> “What kind of file is this?”

- `image/x-icon` → traditional `.ico` files
    
- For `.png`, modern browsers ignore this anyway
    

Better modern usage:

```html
<link rel="icon" type="image/png" href="favicon.png">
```

Or omit `type` entirely — browsers auto-detect.

---

## 🔁 How the Browser Uses This

![Image](https://www.dwuser.com/education/content/quick-tip-adding-a-favicon-to-your-website/images/chrome.jpg)

![Image](https://upload.wikimedia.org/wikipedia/commons/2/22/Wikipedia_favicon_in_Firefox_on_KDE_%282023%29.png)

1. Browser parses `<head>`
    
2. Sees `<link rel="icon">`
    
3. Requests the image
    
4. Displays it in:
    
    - Browser tab
        
    - Bookmarks
        
    - History
        

---

## 🧪 What Happens If You Remove Attributes?

|Removed|Effect|
|---|---|
|`rel`|Browser doesn’t know it’s an icon|
|`href`|Nothing to load|
|`type`|Usually fine|
|Entire tag|Default browser icon|

---

## 🧠 Interview-Ready Explanation

> “This link tag tells the browser where the website’s favicon is located, what its relationship is to the page, and what type of image it is.”

---

## ✅ Modern Best Practice (Clean & Correct)

```html
<link rel="icon" href="/img/favicon.png" type="image/png">
```

Or simplest:

```html
<link rel="icon" href="/img/favicon.png">
```
