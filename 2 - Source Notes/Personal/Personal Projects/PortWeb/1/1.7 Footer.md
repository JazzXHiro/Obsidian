# Footer

## 🧠 The Code

```html
<footer class="footer">
```

---

## 1️⃣ `<footer>` — The Element

### 🔹 What `<footer>` Is

`<footer>` is a **semantic HTML element** that represents the **footer of a page or a section**.

It typically contains:

- Copyright information
    
- Author / owner info
    
- Social links
    
- Secondary navigation
    
- Legal links
    

It tells browsers and search engines:

> “This is the concluding or supporting information for this content.”

---

### 🔹 Where `<footer>` Can Be Used

A `<footer>` can appear:

- At the **end of the entire page**
    
- At the **end of a section**
    
- At the **end of an article**
    

Example:

```html
<article>
  <h2>Blog Post</h2>
  <p>Content...</p>
  <footer>Written by Ishu</footer>
</article>
```

---

## 2️⃣ `class="footer"` — The Class Attribute

### 🔹 What `class` Does

`class="footer"` gives you a **styling hook**.

It allows you to:

- Style the footer with CSS
    
- Reuse the same styles elsewhere if needed
    

Example:

```css
.footer {
  background: #020617;
  text-align: center;
}
```

---

## 🧠 Why Use `<footer>` Instead of `<div>`?

```html
<div>    ❌ generic
<footer> ✔ semantic
```

Benefits:

- Better SEO
    
- Better accessibility
    
- Clear document structure
    
- Screen readers identify it as footer content
    

Search engines understand that:

- This is **not main content**
    
- It’s supporting information
