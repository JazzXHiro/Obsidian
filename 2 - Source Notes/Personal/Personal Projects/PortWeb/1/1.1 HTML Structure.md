# HTML Structure

## 🧱 Basic HTML Document Structure

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My Website</title>
</head>
<body>

  <h1>Hello World</h1>
  <p>This is my first webpage.</p>

</body>
</html>
```

This is the **minimum professional HTML skeleton**.

---

### 1️⃣ `<!DOCTYPE html>`

```html
<!DOCTYPE html>
```

- Tells the browser to use **HTML5 standards mode**
    
- Prevents quirks mode
    
- Must be the **first line**
    

> Think of it as: “Browser, behave correctly.”

---

### 2️⃣ `<html> ... </html>`

```html
<html lang="en">
```

- Root element of the document
    
- Wraps **everything**
    
- `lang="en"` helps:
    
    - Screen readers
        
    - Search engines
        
    - Accessibility
        

---

### 3️⃣ `<head> ... </head>`

The **metadata section** (not visible on the page).

```html
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My Website</title>
</head>
```

#### What goes in `<head>`:

- Character encoding
    
- Page title
    
- SEO metadata
    
- CSS links
    
- Icons
    
- Fonts
    

---

#### 🔹 `<meta charset="UTF-8">`

- Defines text encoding
    
- Prevents broken characters (₹, é, emojis)
    

---

#### 🔹 `<meta name="viewport">`

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

- Enables responsive design
    
- Essential for mobile devices
    

---

#### 🔹 `<title>`

```html
<title>My Website</title>
```

- Shown in:
    
    - Browser tab
        
    - Search results
        
- Important for SEO
    

---

### 4️⃣ `<body> ... </body>`

Everything **visible** on the webpage goes here.

```html
<body>
  <h1>Hello World</h1>
  <p>This is my first webpage.</p>
</body>
```

Includes:

- Text
    
- Images
    
- Buttons
    
- Forms
    
- Layout elements
    

---

### 5️⃣ Common Structural Tags (Semantic HTML)

Instead of using only `<div>`, modern HTML uses **semantic tags**:

```html
<header>Navigation / Logo</header>
<main>
  <section>Content</section>
  <article>Independent content</article>
</main>
<footer>Footer info</footer>
```

Benefits:

- Better SEO
    
- Better accessibility
    
- Cleaner DOM

### 🧪 Minimal vs Professional

### ❌ Minimal (works, but weak)

```html
<html>
<body>Hello</body>
</html>
```

#### ✅ Professional (correct)

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width">
</head>
<body>
  Hello
</body>
</html>
```

---

### 🎯 Interview One-Liner

> “An HTML document consists of a DOCTYPE, a root html element, a head section for metadata, and a body section for visible content.”

Perfect answer.
