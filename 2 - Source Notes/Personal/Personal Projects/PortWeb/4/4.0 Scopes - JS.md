# Scopes - JS

# All Types of Scope in JavaScript

JavaScript has **5 main scopes** (not counting some edge cases).

---

## 1️⃣ **Global Scope** ✅ (You already know)

### What it is

Declared **outside** any function or block.

```js
let siteName = "Portfolio";
```

Accessible:

- Everywhere in the file
    

⚠️ Use sparingly.

---

## 2️⃣ **Function Scope** ✅ (Local Scope)

### What it is

Declared **inside a function**.

```js
function greet() {
  var msg = "Hello";
}
```

Accessible:

- Only inside the function
    

Applies to:

- `var`
    
- `let`
    
- `const`
    

---

## 3️⃣ **Block Scope** ✅ (ES6+)

### What it is

Declared inside `{}` blocks like:

- `if`
    
- `for`
    
- `while`
    

```js
if (true) {
  let x = 10;
  const y = 20;
}
```

Accessible:

- Only inside the block
    

❌ `var` does **not** respect block scope.

---

## 4️⃣ **Module Scope** ⭐ (Very Important, Often Missed)

### What it is

When you use **ES modules**, each file has its **own scope**.

```js
// file1.js
const secret = "hidden";
```

```js
// file2.js
console.log(secret); // ❌ Error
```

Even though both are global-looking, they are **isolated**.

To enable module scope in the browser:

```html
<script type="module" src="main.js"></script>
```

✔ Prevents global pollution  
✔ Modern JavaScript standard

---

## 5️⃣ **Lexical Scope** ⭐ (Conceptual, but critical)

### What it is

Lexical scope means:

> A function can access variables from **where it was defined**, not where it’s called.

```js
function outer() {
  let x = 10;

  function inner() {
    console.log(x); // ✅
  }

  inner();
}
outer();
```

This rule enables **closures**.

📌 Lexical scope is **how scopes are resolved**, not a container itself.
