# Scope Chain

# 🧠 What Is the Scope Chain?

### Definition (precise & interview-ready):

> **The scope chain is the ordered list of scopes that JavaScript searches when resolving a variable name.**

In short:

> “When JS sees a variable, it looks for it step by step from inner scope to outer scope.”

---

## 🔍 How Variable Lookup Works

When JavaScript encounters a variable:

```js
console.log(x);
```

It looks for `x` in this order:

1. **Current scope**
    
2. **Parent (outer) scope**
    
3. **Grandparent scope**
    
4. …
    
5. **Global scope**
    

If not found → ❌ `ReferenceError`

This ordered lookup path is the **scope chain**.

---

## 🧩 Simple Example

```js
let a = 1;

function outer() {
  let b = 2;

  function inner() {
    let c = 3;
    console.log(a, b, c);
  }

  inner();
}

outer();
```

### Scope chain for `inner()`:

```
inner scope  →  outer scope  →  global scope
```

- `c` → found in inner
    
- `b` → found in outer
    
- `a` → found in global
    

---

## 🧠 Visual Mental Model

```
[ inner ]
    ↓
[ outer ]
    ↓
[ global ]
```

JavaScript climbs **upward only**.

---

## ⚠️ Important Rule (Interview Gold)

> **The scope chain is determined by where functions are written, not where they are called.**

This is called **lexical scoping**.

---

## 🧪 Proof Example (Lexical Scope)

```js
let x = 10;

function foo() {
  console.log(x);
}

function bar() {
  let x = 20;
  foo();
}

bar();
```

### Output:

```
10
```

Why?

- `foo()` was **defined in global scope**
    
- Its scope chain is:
    

```
foo → global
```

Not:

```
bar → foo → global ❌
```

---

## 🔥 Scope Chain + Closure (Very Important)

```js
function makeCounter() {
  let count = 0;

  return function () {
    count++;
    console.log(count);
  };
}

const counter = makeCounter();
counter();
counter();
```

### Scope chain for returned function:

```
returned function
    ↓
makeCounter scope
    ↓
global scope
```

This preserved chain is what creates a **closure**.

---

## 🆚 Scope Chain vs Call Stack (Common Confusion)

|Concept|What it tracks|
|---|---|
|Scope Chain|Variable lookup|
|Call Stack|Function execution order|

They are **completely different**.

---

## 🧠 What Scope Chain Does NOT Do

- ❌ It does NOT look downward
    
- ❌ It does NOT search sibling scopes
    
- ❌ It does NOT change at runtime
    

The chain is **fixed at function creation time**.

---

## 🧠 Summary Table

|Feature|Scope Chain|
|---|---|
|Purpose|Resolve variable names|
|Direction|Inner → outer|
|Based on|Lexical scope|
|Changes at runtime|❌ No|
|Enables closures|✅ Yes|

---

## 🎯 Interview-Ready Explanation

> “The scope chain is the sequence of outer scopes that JavaScript uses to resolve variable references, starting from the current scope up to the global scope.”

---

## 🧠 One-Line Rule (Memorize This)

> **JavaScript looks for variables outward, never inward.**
