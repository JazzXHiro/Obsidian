# Cascade Order - CSS

# 🧠 What Is the CSS Cascade?

> **The cascade is the algorithm browsers use to decide which CSS rule applies when there are conflicts.**

“Cascade” literally means rules **flow together**, but only one wins.

---

## 🧭 The Cascade Order (High → Low Priority)

When two or more rules conflict, the browser checks **in this exact order**:

### 1️⃣ **Importance (`!important`)**

### 2️⃣ **Origin (where the CSS comes from)**

### 3️⃣ **Specificity (how precise the selector is)**

### 4️⃣ **Source Order (which rule appears last)**

If a rule wins at a step, the browser **stops checking further**.

---

## 1️⃣ `!important` — Highest Priority

```css
p {
  color: red !important;
}
```

- Overrides almost everything
    
- Even higher-specificity rules
    

⚠️ Bad practice unless absolutely necessary.

```css
/* This will NOT win */
#text {
  color: blue;
}
```

---

## 2️⃣ Origin — Where the CSS Comes From

Priority (highest → lowest):

1. **User `!important`**
    
2. **Author `!important`**
    
3. **Author CSS** (your styles)
    
4. **Browser default styles**
    

Example:

- Your CSS beats browser defaults
    
- But user accessibility rules can override yours
    

---

## 3️⃣ Specificity — How Targeted the Selector Is

Specificity is calculated like this:

```
Inline styles        → 1000
IDs (#id)            → 100
Classes (.class)     → 10
Elements (div, p)    → 1
```

### Example

```css
p { color: red; }              /* specificity: 1 */
.text { color: blue; }         /* specificity: 10 */
#title { color: green; }       /* specificity: 100 */
```

Applied to:

```html
<p id="title" class="text">Hello</p>
```

✔ Result: **green** (highest specificity wins)

---

## 4️⃣ Source Order — Last One Wins

If **specificity is equal**, the rule that appears **later in the CSS** wins.

```css
p {
  color: red;
}

p {
  color: blue;
}
```

✔ Result: **blue**

This is extremely common in real projects.

---

## 🧩 Inheritance (Special Case)

Some properties are inherited automatically:

- `color`
    
- `font-family`
    
- `font-size`
    

Example:

```css
body {
  color: white;
}
```

All child elements inherit it **unless overridden**.

Inheritance has **lower priority** than explicit rules.

## 🔥 Real Example (Navbar Case)

```css
.nav__menu {
  top: -100%;
}

.show-menu {
  top: 0;
}
```

Both have:

- Same origin
    
- Same importance
    
- Same specificity (1 class)
    

➡️ `.show-menu` wins **because it comes later**.

---

## 🎯 Interview-Ready Explanation

> “The CSS cascade determines which rule applies based on importance, origin, specificity, and source order, with later rules and more specific selectors taking precedence.”
