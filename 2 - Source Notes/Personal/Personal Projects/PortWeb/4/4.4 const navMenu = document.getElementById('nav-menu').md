# const navMenu = document.getElementById('nav-menu')

## 🧠 What Is Being Stored Here?

```js
const navMenu = document.getElementById('nav-menu');
```

### Short answer:

> **`navMenu` stores a reference to a DOM element object** (specifically, an `HTMLElement`).

It is **not** a string, not HTML text, and not a copy.

---

## 🔍 What `document.getElementById()` Returns

`document.getElementById('nav-menu')` returns:

- The **actual DOM node** that represents this HTML element:
    

```html
<div id="nav-menu"></div>
```

So `navMenu` now points to that element **inside the DOM tree**.

---

## 🧩 What Type Is `navMenu`?

In JavaScript terms:

```js
typeof navMenu; // "object"
```

More specifically:

- It’s an **HTMLElement**
    
- Often a more specific subtype like:
    
    - `HTMLDivElement`
        
    - `HTMLHeaderElement`
        
    - etc.
        

Example:

```js
navMenu instanceof HTMLElement; // true
```

---

## 🧠 Important Mental Model (Memorize This)

```
navMenu → reference → DOM element
```

- You are holding a **pointer** to a live element
    
- Any change you make affects the actual page
    

---

## 🔁 What You Can Do With This Reference

Because `navMenu` is a DOM element object, you can:

### Change styles

```js
navMenu.style.top = "0";
```

### Add / remove classes

```js
navMenu.classList.add("show-menu");
```

### Read or change content

```js
navMenu.textContent = "Menu";
```

### Attach events

```js
navMenu.addEventListener("click", () => {
  console.log("Clicked");
});
```

---

## ⚠️ What If the Element Does Not Exist?

```js
const navMenu = document.getElementById('nav-menu');
```

If there is **no element** with that ID:

```js
navMenu === null;
```

Trying to do:

```js
navMenu.classList.add("show");
```

➡️ ❌ Error: cannot read properties of null

That’s why you often see checks like:

```js
if (navMenu) {
  navMenu.classList.add("show-menu");
}
```

---

## 🆚 Comparison With Other Types (Important)

|Code|Stored value|
|---|---|
|`const x = "nav-menu"`|String|
|`const x = document.getElementById()`|DOM element object|
|`const x = {}`|Plain JS object|
|`const x = []`|Array|

A DOM element is a **special browser-provided object**.

---
