# address - HTML

The `<address>` tag is a **semantic HTML element** meant to provide contact information (email, physical address, phone, etc.) for a person or organization.

### What it's supposed to do:

```html
<address>
  <a href="mailto:email@example.com">email@example.com</a><br>
  123 Main Street<br>
  City, State 12345
</address>
```

### Default styling:

By default, browsers display `<address>` content in *italics*.

### ⚠️ In your code—it's **misused**:

```html
<address>NebulaTech</address>      <!-- Company name ❌ -->
<address>2024 - Present</address>  <!-- Date range ❌ -->
```

These aren't contact information, so `<address>` is semantically incorrect here.

### What you should use instead:

```html
<span class="resume__company">NebulaTech</span>
<span class="resume__date">2024 - Present</span>
```

Or even simpler (the class names provide all the semantic meaning needed):

```html
<span>NebulaTech</span>
<span>2024 - Present</span>
```

### Correct usage of `<address>`:

```html
<footer>
  <address>
    Contact me at: <a href="mailto:keerti@example.com">keerti@example.com</a>
  </address>
</footer>
```

The tutorial likely used `<address>` just to get italic styling, but it's not semantically correct for company names and dates.
