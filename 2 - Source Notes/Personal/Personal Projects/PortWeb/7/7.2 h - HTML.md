# h - HTML

The `<h>` tags are **heading elements** that create hierarchical headings in HTML. They range from `<h1>` to `<h6>`, where `<h1>` is the highest priority and `<h6>` is the lowest.

### Heading hierarchy:

```html
<h1>Main Title</h1>          <!-- Largest, most important -->
<h2>Section Heading</h2>      <!-- Second level -->
<h3>Subsection Heading</h3>   <!-- Third level -->
<h4>Sub-subsection</h4>       <!-- And so on... -->
<h5>Minor heading</h5>
<h6>Least important</h6>      <!-- Smallest -->
```

### Visual hierarchy:

```
H1 - BIGGEST TEXT
H2 - Bigger text
H3 - Normal text
H4 - Slightly smaller
H5 - Even smaller
H6 - Smallest text
```

### Default browser styling:

Each heading has default font sizes and margins, but you can override with CSS:

```css
h1 {
  font-size: 2rem;
  margin-bottom: 1.5rem;
}
```

### In your portfolio:

```html
<h2 class="section__title">Projects</h2>  <!-- Section heading -->
<h3 class="projects__title">Project 1</h3>  <!-- Project name -->
```

### Best practices:

1. **Use only one `<h1>` per page** — It should be your main page title
2. **Don't skip levels** — Go h1 → h2 → h3, not h1 → h3
3. **For SEO** — Search engines use headings to understand page structure
4. **For accessibility** — Screen readers use headings to navigate

Your portfolio correctly uses `<h2>` for section titles and `<h3>` for project names!
