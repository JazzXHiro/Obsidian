# grid - CSS

By default, `display: grid;` creates **rows**.

Without specifying `grid-template-columns` or `grid-template-rows`, items flow **downward** into implicit rows:

```css
.container {
  display: grid;
  /* No columns or rows defined */
}
```

```
┌──────────────────────┐
│  Item 1              │  ← Row 1
├──────────────────────┤
│  Item 2              │  ← Row 2
├──────────────────────┤
│  Item 3              │  ← Row 3
└──────────────────────┘
```

### To create columns instead:

You need to explicitly define `grid-template-columns`:

```css
.container {
  display: grid;
  grid-template-columns: 350px 350px;  /* Now items flow into 2 columns */
}
```

```
┌─────────────┬─────────────┐
│   Item 1    │   Item 2    │  ← Row 1
├─────────────┼─────────────┤
│   Item 3    │   Item 4    │  ← Row 2
└─────────────┴─────────────┘
  Column 1      Column 2
```

**Key difference:**
- **No columns defined** → Items stack vertically (rows only)
- **Columns defined** → Items fill columns left-to-right, then wrap to next row

---

A **grid container** is an element with `display: grid;` applied to it. It's the parent element that creates a grid layout system for its children.

### What it does:

It transforms the container into a **2D layout system** where you can position child elements in rows and columns.

```css
.projects__container {
  display: grid;  /* ← Makes this a grid container */
}
```

### Before `display: grid` (normal flow):

```
Children stack vertically, one per line:
┌──────────────────┐
│  Child 1         │
├──────────────────┤
│  Child 2         │
├──────────────────┤
│  Child 3         │
└──────────────────┘
```

### After `display: grid` (grid container):

```
Children can now be arranged in rows AND columns:
┌──────────┬──────────┐
│ Child 1  │ Child 2  │  ← Row 1
├──────────┼──────────┤
│ Child 3  │ Child 4  │  ← Row 2
└──────────┴──────────┘
 Column 1   Column 2
```

### Key powers of a grid container:

1. **Control child layout** — Position items precisely in rows/columns
2. **Auto-wrapping** — Items automatically flow to next row when column is full
3. **Spacing control** — `gap` property adds space between items
4. **Alignment control** — `align-items`, `justify-items` align items within cells

**Simple analogy:** Think of it like creating an invisible table (rows × columns) and placing your children inside the cells.
