# border - CSS

`solid` specifies the **border style** — it makes the border a continuous, unbroken line.

```css
border: 2px solid var(--first-color);
       └─┬─┘ └──┬──┘ └──────┬──────┘
         │      │           │
       width  style         color
```

**Breaking it down:**
- `2px` = border thickness
- `solid` = border style (continuous line)
- `var(--first-color)` = border color (cyan)

### Other border styles you could use:

| Style | Appearance |
|-------|-----------|
| `solid` | ━━━━━ (continuous line) |
| `dashed` | ━ ━ ━ (dashes) |
| `dotted` | ․․․․․ (dots) |
| `double` | ═════ (two lines) |
| `groove` | 3D indented |
| `ridge` | 3D raised |

**In your contact form:**
```css
border: 2px solid var(--first-color);
```

This creates a **2px cyan solid border** around input fields. Without `solid`, you'd need to specify a different style, or the border wouldn't display.
