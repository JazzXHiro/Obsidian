### **Explanation:**
Making `.resume__subtitle` a flexbox container aligns the **icon and text horizontally** with proper spacing and centering.

**Look at the HTML:**
```html
<h3 class="resume__subtitle">
  <i class="ri-award-fill"></i>      <!-- Icon -->
  <span>Experience</span>             <!-- Text -->
</h3>
```

**Without flexbox (default):**
```
Icon and text would stack vertically or be misaligned
```

**With flexbox:**
```css
.resume__subtitle{
  display: flex;           /* Align children horizontally */
  align-items: center;     /* Vertically center them */
  column-gap: .5rem;       /* Space between icon & text */
}
```

**Result:**
```
[Icon]  Experience
   ↑    ↑
   |    |
   All vertically centered
```

It's the same pattern you see in `.about__subtitle`—a common design to pair icons with labels. The flexbox is essential here because:

1. **Horizontal alignment** — Icon and text appear side-by-side
2. **Vertical centering** — Icon stays centered with the text, not floating at the top
3. **Consistent spacing** — `column-gap` ensures uniform distance

Without flexbox, the icon would be much harder to align properly with the text.
