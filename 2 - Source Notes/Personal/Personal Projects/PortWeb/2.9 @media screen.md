# 2.9 @media screen

## 🧠 The Big Picture

```css
@media screen and (max-width: 1150px) { ... }
```

This means:

> “Apply the styles inside **only when the screen width is 1150px or less**.”

In other words:

- Desktop → **ignore this**
    
- Tablet & Mobile → **use this**
    

This is how responsive layouts work.

---

## 1️⃣ `@media screen and (max-width: 1150px)`

### What this means

- `@media` → media query
    
- `screen` → screen devices (not print)
    
- `max-width: 1150px` → applies below 1150px
    

So the CSS inside runs on:  
✔ laptops  
✔ tablets  
✔ phones

---

## 2️⃣ Targeting `.nav__menu`

```css
.nav__menu { ... }
```

This targets your **navigation menu container** — usually the menu that slides in/out on mobile.

---

## 3️⃣ `position: fixed;` — Floating Menu

```css
position: fixed;
```

- Removes menu from normal flow
    
- Positions it relative to the viewport
    
- Allows it to overlay content
    

This is essential for mobile menus.

---

## 4️⃣ `top: 0; left: 0;` — Attach to Top

```css
top: 0;
left: 0;
```

Positions the menu:

- At the **top-left corner** of the screen
    

---

## 5️⃣ `width: 100%;` — Full Width Menu

```css
width: 100%;
```

Makes the menu:

- Stretch across the entire screen
    

This creates a **drawer-style mobile menu**.

---

## 6️⃣ `background-color: var(--body-color);`

```css
background-color: var(--body-color);
```

- Uses your global theme color
    
- Keeps consistent dark/light mode
    
- Prevents transparency issues
    

---

## 7️⃣ `box-shadow: 0 8px 16px hsla(0, 0%, 0%, 0.5);`

```css
box-shadow: 0 8px 16px hsla(0, 0%, 0%, 0.5);
```

Creates a shadow:

- `0` → horizontal offset
    
- `8px` → vertical offset
    
- `16px` → blur
    
- `hsla(...)` → semi-transparent black
    

Purpose:  
✔ Visual separation  
✔ Depth effect  
✔ Menu looks elevated

---

## 8️⃣ `padding-block: 5rem 4rem;` — Vertical Spacing

```css
padding-block: 5rem 4rem;
```

Modern CSS shorthand:

- `padding-top: 5rem`
    
- `padding-bottom: 4rem`
    

Why:

- Space for close icon at top
    
- Comfortable spacing for menu items
    

---

## 9️⃣ `border-radius: 0 0 1.5rem 1.5rem;`

```css
border-radius: 0 0 1.5rem 1.5rem;
```

Rounds **only the bottom corners**:

```
top-left     → 0
top-right    → 0
bottom-right → 1.5rem
bottom-left  → 1.5rem
```

Gives:  
✔ Modern mobile UI look  
✔ Soft drop-down menu feel

---

## 🔟 `transition: top .4s;` — Smooth Slide Animation

```css
transition: top .4s;
```

This prepares the menu for animation when:

- `top` value changes
    

Example:

```css
.nav__menu {
  top: -100%;
}

.show-menu {
  top: 0;
}
```

Menu slides down smoothly.
