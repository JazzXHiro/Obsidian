# Node.js

## 🧠 What is **Node.js**?

**Node.js** is a **runtime environment** that allows you to run **JavaScript outside the browser**, typically on servers.

> **In one line:**  
> **Node.js lets JavaScript run on the backend.**

---

## 🔍 Why Node.js Exists

Originally:

- JavaScript → browser only
    
- Servers → Java, Python, PHP, C++
    

Node.js changed that by:

- Taking Google Chrome’s **V8 engine**
    
- Adding system-level APIs (files, network, processes)
    
- Letting JS talk to the OS
    

Result:

> **One language for frontend and backend.**

### Core components:

1. **V8 Engine** – Executes JavaScript
    
2. **Event Loop** – Handles async operations
    
3. **Libuv** – Thread pool for I/O
    
4. **OS APIs** – File system, network, timers
    

---

## 🧵 Single-Threaded but Highly Concurrent

Yes — Node.js is **single-threaded** (like browser JS), but:

- Uses **event-driven**, **non-blocking I/O**
    
- Offloads heavy tasks to background threads
    
- Handles thousands of requests efficiently
    

Example:

```js
const http = require("http");

http.createServer((req, res) => {
  res.end("Hello World");
}).listen(3000);
```

One thread. Many connections.

---

## 🔁 Node.js Event Loop (Why It’s Fast)

![Image](https://media.geeksforgeeks.org/wp-content/uploads/20200224050909/nodejs2.png)

![Image](https://media.geeksforgeeks.org/wp-content/uploads/20220208175332/resizedimagePromo2-660x371.jpeg)

Instead of waiting:

- File reads
    
- DB calls
    
- Network requests
    

Node.js:

- Registers callbacks
    
- Moves on
    
- Handles responses when ready
    

➡️ No thread blocking  
➡️ High throughput

## 📦 npm — Node’s Superpower

Node.js ships with **npm (Node Package Manager)**.

You get:

- Millions of libraries
    
- One-command installs
    
- Dependency management
    

Example:

```bash
npm install express
```

This ecosystem is **why Node exploded in popularity**.

---

## 🌐 What Node.js Is Used For

### ✅ Perfect For:

- REST APIs
    
- Real-time apps (chat, gaming)
    
- Streaming services
    
- Microservices
    
- Serverless functions
    

### ❌ Not Ideal For:

- Heavy CPU-bound computation
    
- Scientific simulations
    
- Multithreaded numeric workloads

## 🧠 Node.js vs Browser JavaScript

|Feature|Browser JS|Node.js|
|---|---|---|
|Runs on|Browser|Server|
|DOM access|Yes|❌ No|
|File system|❌ No|Yes|
|Network|Limited|Full|
|Use case|UI|Backend|

Same language. Different environments.

---

## 🧪 Node.js vs Traditional Servers

|Aspect|Node.js|Java / Python|
|---|---|---|
|Threading|Event-driven|Thread-based|
|Scalability|High|Medium|
|Performance|Excellent I/O|Strong CPU|
|Dev speed|Fast|Moderate|
