# Bisection Method (Bolzano Method)

> **Idea:** Repeatedly apply the Intermediate Value Property to bracket and home in on a root.

---

## 📋 Prerequisites

- A function $$f(x)$$ that is **continuous** on the closed interval $$[a,b]$$  
- **Opposite signs** at the endpoints:  
  $$f(a)\cdot f(b)<0$$  
  (i.e.\ one of $$f(a)$$, $$f(b)$$ is negative and the other is positive)

---

## 📝 Algorithm

1. **Initialize:**  
   - Let $$a_0 = a,\quad b_0 = b$$  
   - Choose tolerance $$\varepsilon>0$$ (desired accuracy)

2. **Iterate** for $$n=1,2,\dots$$ until convergence:  
   3. Compute the midpoint  
      $$x_n = \frac{a_{n-1} + b_{n-1}}{2}$$  
   4. Evaluate $$f(x_n)$$  
   5. **Check for root:**  
      - If $$f(x_n)=0$$ (or $$|f(x_n)|<\delta$$ small), stop: $$x_n$$ is the root.  
   6. **Bracket update:**  
      - If $$f(a_{n-1})\cdot f(x_n)<0$$, set  
        $$a_n = a_{n-1},\quad b_n = x_n$$  
      - Else set  
        $$a_n = x_n,\quad b_n = b_{n-1}$$  
   7. **Stop criterion:**  
      - If $$|b_n - a_n| < \varepsilon$$, accept  
        $$x_n$$ (or midpoint of $$[a_n,b_n]$$) as approximate root.

---

## ✔️ Convergence & Error Bound

- By the Intermediate Value Theorem, each iteration halves the interval containing the root.  
- After $$n$$ steps, the error satisfies  
  $$|x_n - \alpha| \;\le\; \frac{b - a}{2^n}\,, $$  
  where $$\alpha$$ is the true root in $$[a,b]$$.

---

## 🧮 Example

Solve  
$$
x^2 - 2x - 7 = 0
$$  
on the interval $$[3,4]$$:

1. Check endpoints:  
   $$f(3)=9-6-7=-4<0,\quad f(4)=16-8-7=1>0$$  
2. Iteration 1:  
   - $$x_1=(3+4)/2=3.5$$  
   - $$f(3.5)=12.25-7-7=-1.75<0$$  
   - New bracket: $$[3.5,\,4]$$  
3. Iteration 2:  
   - $$x_2=(3.5+4)/2=3.75$$  
   - $$f(3.75)=14.0625-7.5-7=-0.4375<0$$  
   - New bracket: $$[3.75,\,4]$$  
4. Continue until $$|b_n - a_n|<\varepsilon$$.
