# 5.4 Numerical Integration

# 📐 Numerical Integration

### 🔲 Definition:
The **area bounded** by the curve $f(x)$ and the x-axis between limits $a$ and $b$ is denoted by:

$$
I = \int_a^b f(x)\,dx \tag{1}
$$
![[Pasted image 20250716104541.png]]

---

### 📏 Step Division:
Divide the interval $[a, b]$ into $n$ equal parts, each of length $h$ (called step size).

Let:

- $a = x_0$
- $x_1 = x_0 + h$
- $x_2 = x_1 + h$
- $x_3 = x_2 + h$
- $\dots$
- $x_n = x_{n-1} + h$

![[Pasted image 20250716105049.png]]

---

## 🧮 Integration Rules

---

### 1️⃣ Trapezoidal Rule

$$
\int_a^b f(x)\,dx = h \left[ \frac{y_0 + y_n}{2} + y_1 + y_2 + \dots + y_{n-1} \right]
$$

> ✅ Applicable on **any number of intervals**
> (first + last)/2 + remaining terms

---

### 2️⃣ Simpson's $\frac{1}{3}$ Rule (for even number of intervals)

$$
\int_a^b f(x)\,dx = \frac{h}{3} \left[ y_0 + y_n + 4(y_1 + y_3 + \dots) + 2(y_2 + y_4 + \dots) \right]
$$

> ⚠️ Applicable if total number of intervals is even interval
> (first + last) + 4(remaining terms) + 2(even terms)

---

### 3️⃣ Simpson’s $\frac{3}{8}$ Rule (for multiples of 3)

$$
\int_a^b f(x)\,dx = \frac{3h}{8} \left[ y_0 + y_n + 3(y_1 + y_2 + y_4 + \dots) + 2(y_3 + y_6 + \dots) \right]
$$

> ⚠️ Applicable if total number of intervals is a **multiple of 3**
> (first + last) + 3(remaining terms) + 2(multiple of 3 terms)

---


> [!NOTE] If we divide the function in 6 terms
> All three Rules can be applied to it
> 
> If a question asks to utilize both Simpson's 1/3 and 3/8 Rule and no interval is provided, we can assume the interval to be 6 safely.

# Questions
## 📊 Numerical Integration: Evaluate the Integral

Evaluate:

$$
\int_0^1 \frac{1}{1+x^2} \, dx
$$

Using:
1. Trapezoidal Rule  
2. Simpson’s $\frac{1}{3}$ Rule  
3. Simpson’s $\frac{3}{8}$ Rule  
Also find value of $\pi$.



### 📏 Step Size

$$
h = \frac{b - a}{n} = \frac{1 - 0}{6} = \frac{1}{6}
$$

### 📈 Data Table

| $x_i$               | $y_i = \frac{1}{1 + x_i^2}$                   |
| ------------------- | --------------------------------------------- |
| $x_0 = 0$           | $y_0 = 1$                                     |
| $x_1 = \frac{1}{6}$ | $y_1 = \frac{1}{1 + (1/6)^2} = \frac{36}{37}$ |
| $x_2 = \frac{2}{6}$ | $y_2 = \frac{1}{1 + (1/3)^2} = 0.9$           |
| $x_3 = \frac{3}{6}$ | $y_3 = \frac{1}{1 + (1/2)^2} = 0.8$           |
| $x_4 = \frac{4}{6}$ | $y_4 = \frac{1}{1 + (2/3)^2} = \frac{9}{13}$  |
| $x_5 = \frac{5}{6}$ | $y_5 = \frac{1}{1 + (5/6)^2} = \frac{36}{61}$ |
| $x_6 = 1$           | $y_6 = \frac{1}{1 + 1^2} = 0.5$               |

### 🟧 Trapezoidal Rule

$$
\int_0^1 \frac{1}{1 + x^2} dx = \frac{h}{2} \left[ y_0 + y_6 + 2(y_1 + y_2 + y_3 + y_4 + y_5) \right]
$$

Substitute values:

$$
= \frac{1}{6} \left[ \frac{1 + 0.5}{2} + \frac{36}{37} + 0.9 + 0.8 + \frac{9}{13} + \frac{36}{61} \right]
$$

$$
= 0.784923
$$

### 🟩 Simpson's $\frac{1}{3}$ Rule

$$
\int_0^1 \frac{1}{1 + x^2} dx = \frac{h}{3} \left[ y_0 + y_6 + 4(y_1 + y_3 + y_5) + 2(y_2 + y_4) \right]
$$

$$
= \frac{1}{18} \left[ (1 + 0.5) + 4\left(\frac{36}{37} + 0.8 + \frac{36}{61}\right) + 2\left(0.9 + \frac{9}{13}\right) \right]
$$

$$
= 0.785396
$$

### 🟦 Simpson's $\frac{3}{8}$ Rule

$$
\int_0^1 \frac{1}{1 + x^2} dx = \frac{3h}{8} \left[ y_0 + y_6 + 3(y_1 + y_2 + y_4 + y_5) + 2(y_3) \right]
$$

$$
= \frac{3}{8} \left(\frac{1}{6}\right) \left[ (1 + 0.5) + 3\left(\frac{36}{37} + 0.9 + \frac{9}{13} + \frac{36}{61}\right) + 2(0.8) \right]
$$

$$
= 0.785394
$$

### ✅ Approximate Value of $\pi$

Since:

$$
\int_0^1 \frac{1}{1 + x^2} dx = \tan^{-1}(1) - \tan^{-1}(0) = \frac{\pi}{4}
$$

Thus:

$$
\pi \approx 4 \times 0.785394 = 3.141576
$$

## 📐 Numerical Integration using Simpson's 3/8 Rule

### 🔢 Given

| $x$   | 4.0   | 4.2   | 4.4   | 4.6   | 4.8   | 5.0   | 5.2   |
|-------|-------|-------|-------|-------|-------|-------|
| $\log_e x$ | 1.3863 | 1.4351 | 1.4816 | 1.5261 | 1.5686 | 1.6094 | 1.6487 |

We are to evaluate:

$$
\int_4^{5.2} \log_e x \, dx \quad \text{using Simpson's } \frac{3}{8} \text{ rule}
$$

### 📏 Step Size

$$
h = \frac{5.2 - 4}{6} = \frac{1.2}{6} = 0.2
$$

### 🧮 Simpson's $\frac{3}{8}$ Rule Formula

$$
\int_a^b f(x)\, dx = \frac{3h}{8} \Big[ y_0 + y_6 + 3(y_1 + y_2 + y_4 + y_5) + 2y_3 \Big]
$$

#### Substituting values:

$$
= \frac{3}{8} \cdot \frac{1.2}{6} \Big[ (1.3863 + 1.6487) + 3(1.4351 + 1.4816 + 1.5686 + 1.6094) + 2(1.5261) \Big]
$$

#### Simplifying:

$$
= \frac{3}{6}(1.3863 + 1.6487) + 3(1.4351 + 1.4816 + 1.5686 + 1.6094) + 2(1.5261)
$$

### ✅ Final Answer:

$$
\int_4^{5.2} \log_e x \, dx \approx 1.827484
$$

## 🧮 Numerical Integration using Trapezoidal Rule

Use the **Trapezoidal Rule** to compute:

$$
\int_1^2 \frac{1}{x} \, dx
$$

using **3 intervals**, and compare it with the exact value.

### 📐 Step Size

$$
h = \frac{2 - 1}{3} = \frac{1}{3}
$$
### 📊 Table of Values

| $x_i$               | $y_i = \frac{1}{x_i}$ |
| ------------------- | --------------------- |
| $x_0 = 1$           | $y_0 = 1$             |
| $x_1 = \frac{4}{3}$ | $y_1 = \frac{3}{4}$   |
| $x_2 = \frac{5}{3}$ | $y_2 = \frac{3}{5}$   |
| $x_3 = 2$           | $y_3 = \frac{1}{2}$   |

### 🧾 Trapezoidal Rule Formula

$$
\int_a^b f(x)\, dx \approx \frac{h}{2} \Big[ y_0 + y_n + 2(y_1 + y_2 + \dots + y_{n-1}) \Big]
$$

Applying values:

$$
\int_1^2 \frac{1}{x}\, dx \approx \frac{1}{3} \cdot \frac{1}{2} \Big[ 1 + 0.5 + \frac{3}{4} + \frac{3}{5} \Big]
$$

Simplifying:

$$
= \frac{1}{6} (1 + 0.5 + 0.75 + 0.6) = 0.470
$$

### ✅ Final Answer

$$
\int_1^2 \frac{1}{x}\, dx \approx 0.470 \quad \text{(using Trapezoidal Rule)}
$$

## 📐 Numerical Integration using Simpson's $\frac{1}{3}$ Rule

## Problem

Calculate the value of the integral using Simpson's $\frac{1}{3}$ Rule:

$$
\int_0^{\frac{\pi}{2}} \sqrt{\sin x} \, dx
$$

### Step Size

Let:

- $h = \frac{\frac{\pi}{2} - 0}{6} = \frac{\pi}{12}$

### Table of Values

| $x_i$               | $y_i = \sqrt{\sin x_i}$ |
|---------------------|-------------------------|
| $x_0 = 0$           | $y_0 = \sqrt{\sin 0} = 0$ |
| $x_1 = \frac{\pi}{12}$ | $y_1 = \sqrt{\sin \frac{\pi}{12}} = 0.5087$ |
| $x_2 = \frac{\pi}{6}$  | $y_2 = \sqrt{\sin \frac{\pi}{6}} = 0.7071$ |
| $x_3 = \frac{\pi}{4}$  | $y_3 = \sqrt{\sin \frac{\pi}{4}} = 0.8409$ |
| $x_4 = \frac{\pi}{3}$  | $y_4 = \sqrt{\sin \frac{\pi}{3}} = 0.9306$ |
| $x_5 = \frac{5\pi}{12}$| $y_5 = \sqrt{\sin \frac{5\pi}{12}} = 0.9825$ |
| $x_6 = \frac{\pi}{2}$  | $y_6 = \sqrt{\sin \frac{\pi}{2}} = 1.000$ |

### Simpson's $\frac{1}{3}$ Rule Formula

$$
\int_0^{\frac{\pi}{2}} \sqrt{\sin x} \, dx = \frac{h}{3} \left( y_0 + y_6 + 4(y_1 + y_3 + y_5) + 2(y_2 + y_4) \right)
$$

Substitute values:

$$
= \frac{\pi}{36} \left[ 0 + 1 + 4(0.5087 + 0.8409 + 0.9825) + 2(0.7071 + 0.9306) \right]
$$

### Final Calculation

$$
= \frac{1}{36} \cdot \frac{22}{7} \cdot \left(11 + \dots \right) \approx 0.3779
$$

### ✅ Final Answer

$$
\int_0^{\frac{\pi}{2}} \sqrt{\sin x} \, dx \approx 0.3779
$$
