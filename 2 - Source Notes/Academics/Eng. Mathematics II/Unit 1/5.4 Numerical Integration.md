# 5.4 Numerical Integration

# 📐 Numerical Integration

### 🔲 Definition:
The **area bounded** by the curve $f(x)$ and the x-axis between limits $a$ and $b$ is denoted by:

$$
I = \int_a^b f(x)\,dx \tag{1}
$$
![[Pasted image 20250716104541.png]]

---

### 📏 Step Division:
Divide the interval $[a, b]$ into $n$ equal parts, each of length $h$ (called step size).

Let:

- $a = x_0$
- $x_1 = x_0 + h$
- $x_2 = x_1 + h$
- $x_3 = x_2 + h$
- $\dots$
- $x_n = x_{n-1} + h$

![[Pasted image 20250716105049.png]]

---

## 🧮 Integration Rules

---

### 1️⃣ Trapezoidal Rule

$$
\int_a^b f(x)\,dx = h \left[ \frac{y_0 + y_n}{2} + y_1 + y_2 + \dots + y_{n-1} \right]
$$

> ✅ Applicable on **any number of intervals**
> (first + last)/2 + remaining terms

---

### 2️⃣ Simpson's $\frac{1}{3}$ Rule (for even number of intervals)

$$
\int_a^b f(x)\,dx = \frac{h}{3} \left[ y_0 + y_n + 4(y_1 + y_3 + \dots) + 2(y_2 + y_4 + \dots) \right]
$$

> ⚠️ Applicable if total number of intervals is even interval
> (first + last) + 4(remaining terms) + 2(even terms)

---

### 3️⃣ Simpson’s $\frac{3}{8}$ Rule (for multiples of 3)

$$
\int_a^b f(x)\,dx = \frac{3h}{8} \left[ y_0 + y_n + 3(y_1 + y_2 + y_4 + \dots) + 2(y_3 + y_6 + \dots) \right]
$$

> ⚠️ Applicable if total number of intervals is a **multiple of 3**
> (first + last) + 3(remaining terms) + 2(multiple of 3 terms)

---


> [!NOTE] If we divide the function in 6 terms
> All three Rules can be applied to it
> 
> If a question asks to utilize both Simpson's 1/3 and 3/8 Rule and no interval is provided, we can assume the interval to be 6 safely.

# 📊 Numerical Integration: Evaluate the Integral

Evaluate:

$$
\int_0^1 \frac{1}{1+x^2} \, dx
$$

Using:
1. Trapezoidal Rule  
2. Simpson’s $\frac{1}{3}$ Rule  
3. Simpson’s $\frac{3}{8}$ Rule  
Also find value of $\pi$.

---

## 📏 Step Size

$$
h = \frac{b - a}{n} = \frac{1 - 0}{6} = \frac{1}{6}
$$

---

## 📈 Data Table

| $x_i$ | $y_i = \frac{1}{1 + x_i^2}$ |
|------|-----------------------------|
| $x_0 = 0$     | $y_0 = 1$                         |
| $x_1 = \frac{1}{6}$ | $y_1 = \frac{1}{1 + (1/6)^2} = \frac{36}{37}$ |
| $x_2 = \frac{2}{6}$ | $y_2 = \frac{1}{1 + (1/3)^2} = 0.9$ |
| $x_3 = \frac{3}{6}$ | $y_3 = \frac{1}{1 + (1/2)^2} = 0.8$ |
| $x_4 = \frac{4}{6}$ | $y_4 = \frac{1}{1 + (2/3)^2} = \frac{9}{13}$ |
| $x_5 = \frac{5}{6}$ | $y_5 = \frac{1}{1 + (5/6)^2} = \frac{36}{61}$ |
| $x_6 = 1$     | $y_6 = \frac{1}{1 + 1^2} = 0.5$ |

---

## 🟧 Trapezoidal Rule

$$
\int_0^1 \frac{1}{1 + x^2} dx = \frac{h}{2} \left[ y_0 + y_6 + 2(y_1 + y_2 + y_3 + y_4 + y_5) \right]
$$

Substitute values:

$$
= \frac{1}{6} \left[ \frac{1 + 0.5}{2} + \frac{36}{37} + 0.9 + 0.8 + \frac{9}{13} + \frac{36}{61} \right]
$$

$$
= 0.784923
$$

---

## 🟩 Simpson's $\frac{1}{3}$ Rule

$$
\int_0^1 \frac{1}{1 + x^2} dx = \frac{h}{3} \left[ y_0 + y_6 + 4(y_1 + y_3 + y_5) + 2(y_2 + y_4) \right]
$$

$$
= \frac{1}{18} \left[ (1 + 0.5) + 4\left(\frac{36}{37} + 0.8 + \frac{36}{61}\right) + 2\left(0.9 + \frac{9}{13}\right) \right]
$$

$$
= 0.785396
$$

---

## 🟦 Simpson's $\frac{3}{8}$ Rule

$$
\int_0^1 \frac{1}{1 + x^2} dx = \frac{3h}{8} \left[ y_0 + y_6 + 3(y_1 + y_2 + y_4 + y_5) + 2(y_3) \right]
$$

$$
= \frac{3}{8} \left(\frac{1}{6}\right) \left[ (1 + 0.5) + 3\left(\frac{36}{37} + 0.9 + \frac{9}{13} + \frac{36}{61}\right) + 2(0.8) \right]
$$

$$
= 0.785394
$$

---

## ✅ Approximate Value of $\pi$

Since:

$$
\int_0^1 \frac{1}{1 + x^2} dx = \tan^{-1}(1) = \frac{\pi}{4}
$$

Thus:

$$
\pi \approx 4 \times 0.785394 = 3.141576
$$
