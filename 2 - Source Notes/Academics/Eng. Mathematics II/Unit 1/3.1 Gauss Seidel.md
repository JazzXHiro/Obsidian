# Gauss–Seidel Method

The **Gauss–Seidel method** is an iterative technique for solving a system of linear equations of the form:
$$
A \cdot X = B
$$
where  
$$
A = [a_{ij}],\quad X = [x_1, x_2, \dots, x_n]^T,\quad B = [b_1, b_2, \dots, b_n]^T
$$

---

## Assumptions

- Matrix $A$ should ideally be **diagonally dominant** or **symmetric positive definite** for convergence.

---

## General Formula

For each equation $i = 1, 2, \dots, n$, rewrite it as:
$$
x_i = \frac{1}{a_{ii}} \left( b_i - \sum_{j=1}^{i-1} a_{ij} x_j^{(k+1)} - \sum_{j=i+1}^{n} a_{ij} x_j^{(k)} \right)
$$

Where:  
- $x_i^{(k+1)}$ is the new value at iteration $k+1$
- $x_j^{(k+1)}$ is the updated value (already computed in this iteration)
- $x_j^{(k)}$ is the value from the previous iteration

---

## Algorithm

### Step 1: Initialize  
Choose initial guesses:  
$$
x_1^{(0)}, x_2^{(0)}, \dots, x_n^{(0)}
$$

### Step 2: Iterate  
For $k = 0, 1, 2, \dots$ repeat until convergence:

For $i = 1$ to $n$:  
$$
x_i^{(k+1)} = \frac{1}{a_{ii}} \left( b_i - \sum_{j=1}^{i-1} a_{ij} x_j^{(k+1)} - \sum_{j=i+1}^{n} a_{ij} x_j^{(k)} \right)
$$

### Step 3: Convergence check  
If  
$$
\max_{1 \le i \le n} \left| x_i^{(k+1)} - x_i^{(k)} \right| < \varepsilon
$$  
for some desired tolerance $\varepsilon$, then stop.

---

## Notes

- Gauss–Seidel improves upon the Jacobi method by using the **latest updated values** in the same iteration.
- It often converges faster than Jacobi if the system satisfies the convergence conditions.
