# Newton Forward and Backward

# 📈 Interpolation for Equal Interval

## 🧮 Problem
**Estimate the population in**:
- $1895$
- $1925$

Given:

| Year ($x$) | Population $f(x)$ |
|------------|-------------------|
| 1891       | 46                |
| 1901       | 66                |
| 1911       | 81                |
| 1921       | 93                |
| 1931       | 101               |

---

## 🔢 Forward Difference Table

| $x$  | $f(x)$ | $\Delta f(x)$ | $\Delta^2 f(x)$ | $\Delta^3 f(x)$ | $\Delta^4 f(x)$ |
| ---- | ------ | ------------- | --------------- | --------------- | --------------- |
| 1891 | 46     |               |                 |                 |                 |
|      |        | 20            |                 |                 |                 |
| 1901 | 66     |               | $-5$            |                 |                 |
|      |        | 15            |                 | $2$             |                 |
| 1911 | 81     |               | $-3$            |                 | $-3$            |
|      |        | 12            |                 | $-1$            |                 |
| 1921 | 93     |               | $-4$            |                 |                 |
|      |        | 8             |                 |                 |                 |
| 1931 | 101    |               |                 |                 |                 |

---

## 🔹 Newton Forward Formula

$f(a + uh) = f(a) + u \Delta f(a) + \frac{u(u - 1)}{2!} \Delta^2 f(a) + \frac{u(u - 1)(u - 2)}{3!} \Delta^3 f(a) + \dots$

- $a + uh = 1895$
- $a = 1891,\ h = 10$
- $u = \frac{1895 - 1891}{10} = 0.4$


$f(1895) = 46 + 0.4 \times 20 + \frac{0.4(0.4 - 1)}{2} \times (-5) + \frac{0.4(0.4 - 1)(0.4 - 2)}{6} \times 2$


$= 46 + 8 - 0.6 + 0.45 = \boxed{54.8528}$

---

## 🔹 Newton Backward Formula

$f(a + uh) = f(a) + u \nabla f(a) + \frac{u(u + 1)}{2!} \nabla^2 f(a) + \frac{u(u + 1)(u + 2)}{3!} \nabla^3 f(a) + \dots$

- $a + uh = 1925$
- $a = 1931,\ h = 10$
- $u = \frac{1925 - 1931}{10} = -0.6$

$f(1925) = 101 + (-0.6) \times 8 + \frac{(-0.6)(-0.6 + 1)}{2} \times (-4) + \frac{(-0.6)(0.4)(1.4)}{6} \times (-1)$

$= 101 - 4.8 + 0.48 - 0.32 = \boxed{96.8268}$

## 🧩 Problem
**Estimate the number of men getting wages between ₹10 and ₹15 from the following data:**

### Given Data:

| Wages (₹) | Frequency |
|-----------|-----------|
| 0–10      | 9         |
| 10–20     | 30        |
| 20–30     | 35        |
| 30–40     | 42        |

## ➕ Cumulative Frequency Table

| Wages (below ₹x$) | $f(x)$ (C.F.)   | $\Delta f(x)$ | $\Delta^2 f(x)$ | $\Delta^3 f(x)$ |
| ----------------- | --------------- | ------------- | --------------- | --------------- |
| below ₹10         | 9               |               |                 |                 |
|                   |                 | 30            |                 |                 |
| below ₹20         | $9 + 30 = 39$   |               | 5               |                 |
|                   |                 | 35            |                 | 2               |
| below ₹30         | $39 + 35 = 74$  |               | 7               |                 |
|                   |                 | 42            |                 |                 |
| below ₹40         | $74 + 42 = 116$ |               |                 |                 |

## 🧮 Newton’s Forward Interpolation Formula

$f(a + uh) = f(a) + u\Delta f(a) + \frac{u(u - 1)}{2!} \Delta^2 f(a) + \frac{u(u - 1)(u - 2)}{3!} \Delta^3 f(a) + \dots$

Where:
- $a + uh = 15$
- $a = 10,\ h = 10$
- $u = \frac{15 - 10}{10} = 0.5$

### Substituting values:

$f(15) = 9 + 0.5(30) + \frac{0.5(0.5 - 1)}{2}(5) + \frac{0.5(0.5 - 1)(0.5 - 2)}{6}(2)$


Breaking down:
- $= 9 + 15 + \frac{0.5(-0.5)}{2} \cdot 5 + \frac{0.5(-0.5)(-1.5)}{6} \cdot 2$
- $= 9 + 15 - 0.625 + 0.125 = \boxed{23.5}$ (approximately)

## ✅ Final Answer

$\text{Number of men getting wages between ₹10 and ₹15} = f(15) - f(10) = 23.5 - 9 = \boxed{14.5} \approx 15$

# 🧮 Newton Forward Interpolation – Polynomial Estimation

## ❓ Problem
Find the lowest degree polynomial $f(x)$ that fits the data. Also, compute $f(5)$.

## 🔢 Given Data

| $x$ | $y = f(x)$ |
|-----|------------|
| 0   | 5          |
| 2   | 9          |
| 4   | 61         |
| 6   | 209        |
| 8   | 501        |

## 🧾 Forward Difference Table

| $x$ | $f(x)=y$ | $\Delta f(x)$ | $\Delta^2 f(x)$ | $\Delta^3 f(x)$ | $\Delta^4 f(x)$ |
| --- | -------- | ------------- | --------------- | --------------- | --------------- |
| 0   | 5        |               |                 |                 |                 |
|     |          | 4             |                 |                 |                 |
| 2   | 9        |               | 48              |                 |                 |
|     |          | 52            |                 | 48              |                 |
| 4   | 61       |               | 96              |                 | 0               |
|     |          | 148           |                 | 48              |                 |
| 6   | 209      |               | 144             |                 |                 |
|     |          | 292           |                 |                 |                 |
| 8   | 501      |               |                 |                 |                 |

## 📘 Newton Forward Interpolation Formula

$f(a + uh) = f(a) + u\Delta f(a) + \frac{u(u-1)}{2!} \Delta^2 f(a) + \frac{u(u-1)(u-2)}{3!} \Delta^3 f(a) + \cdots$

Where:
- $a = 0$, $x = 5$, $h = 2$
- So, $u = \frac{x - a}{h} = \frac{5 - 0}{2} = 2.5$

## 🧮 Interpolated Polynomial
Using the formula and evaluating at $x = 5$:

$f(5) = 5 + \frac{5}{2} \cdot 4 + \frac{5 \cdot 3}{2!} \cdot 48 + \frac{5 \cdot 3 \cdot 1}{3!} \cdot 48$

Alternate (polynomial form derived):

$f(x) = x^3 - 2x + 5$

*by*

### 🔢 Substituting into Newton's Formula

Let $u = \frac{x}{2}$, then:

$$
\begin{aligned}
f(x) &= f(0) + u \Delta f(0) + \frac{u(u - 1)}{2!} \Delta^2 f(0) + \frac{u(u - 1)(u - 2)}{3!} \Delta^3 f(0) \\
&= 5 + \frac{x}{2}(4) + \frac{\frac{x}{2}(\frac{x}{2} - 1)}{2}(48) + \frac{\frac{x}{2}(\frac{x}{2} - 1)(\frac{x}{2} - 2)}{6}(48)
\end{aligned}
$$

### 🔍 Simplifying Terms

**Term 1:**
$$
5
$$

**Term 2:**
$$
\frac{x}{2} \cdot 4 = 2x
$$

**Term 3:**
$$
\frac{1}{2} \cdot \left( \frac{x}{2} \cdot \left( \frac{x}{2} - 1 \right) \cdot 48 \right)
= 24 \cdot \frac{x}{2} \cdot \left( \frac{x}{2} - 1 \right)
= 6x(x - 2)
$$

**Term 4:**

Let $u = \frac{x}{2}$, then:

$$
\frac{1}{6} \cdot \left( u(u - 1)(u - 2) \cdot 48 \right) = 8 \cdot u(u - 1)(u - 2)
$$

Now expand:

$$
u(u - 1)(u - 2) = \frac{x}{2} \cdot \left( \frac{x}{2} - 1 \right) \cdot \left( \frac{x}{2} - 2 \right) = \frac{x(x - 2)(x - 4)}{8}
$$

So:
$$
8 \cdot \frac{x(x - 2)(x - 4)}{8} = x(x - 2)(x - 4)
$$

### ✏️ Final Polynomial Expression

So combining all terms:

$$
f(x) = 5 + 2x + 6x(x - 2) + x(x - 2)(x - 4)
$$

Now simplify:

1. $6x(x - 2) = 6x^2 - 12x$
2. $x(x - 2)(x - 4) = x^3 - 6x^2 + 8x$

Adding all terms:

$$
f(x) = 5 + 2x + 6x^2 - 12x + x^3 - 6x^2 + 8x
$$

Combine like terms:

- $x^3$
- $6x^2 - 6x^2 = 0$
- $2x - 12x + 8x = -2x$
- Constant: $5$

### ✅ Final Answer:

$$
\boxed{f(x) = x^3 - 2x + 5}
$$

## ✅ Final Computation

$f(5) = 5^3 - 2 \cdot 5 + 5 = 125 - 10 + 5 = \boxed{120}$
