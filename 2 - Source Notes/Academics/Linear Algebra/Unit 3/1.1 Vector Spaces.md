# Vector Spaces

### **1. Internal Composition**

Internal composition (or internal operation) refers to an operation where the result of combining two elements from a set stays within the same set. In the context of **vector spaces**, this typically refers to **vector addition**.

- Given a vector space $V$, vector addition is an **internal operation** because for any two vectors $\mathbf{u}, \mathbf{v} \in V$, their sum $\mathbf{u} + \mathbf{v}$ is also in $V$.

### **2. External Composition**

External composition (or external operation) involves an operation where an element from one set (e.g., a scalar) interacts with an element from another set (e.g., a vector), producing a result in the second set. In vector spaces, this refers to **scalar multiplication**.

- Given a vector space $V$ over a field $\mathbb{F}$, scalar multiplication is an **external operation** because multiplying a vector $\mathbf{v} \in V$ by a scalar λ∈F$$\lambda \in \mathbb{F}$$ results in another vector $\lambda \mathbf{v} \in V$.
