# 3.2 Linear Transformation

# Vector Space Homomorphism (Linear Transformation)  

**Definition:**  
Let $U(F)$ and $V(F)$ be two vector spaces over the same field $F$. A mapping $f: U \to V$ is called a **linear transformation** (or **vector space homomorphism**) if it satisfies:  

1. **Additivity:**  
   $f(\alpha + \beta) = f(\alpha) + f(\beta) \quad \forall \alpha, \beta \in U$  

2. **Homogeneity:**  
   $f(a\alpha) = a f(\alpha) \quad \forall a \in F, \alpha \in U$  

These can be combined into one condition:  
$f(a\alpha + b\beta) = a f(\alpha) + b f(\beta) \quad \forall a,b \in F, \alpha,\beta \in U$  

**Key Points:**  
- $V$ is called the **homomorphic image** of $U$ under $f$  
- Linear transformations preserve vector space operations  
- The set of all linear transformations from $U$ to $V$ is itself a vector space  

**Example:**  
For $U = V = \mathbb{R}^2$, the map $f(x,y) = (2x, 3y)$ is linear since:  
$f(a(x_1,y_1) + b(x_2,y_2)) = a f(x_1,y_1) + b f(x_2,y_2)$  


# Kernel of a Linear Transformation  

**Definition:**  
Let $f: U(F) \to V(F)$ be a linear transformation between vector spaces over field $F$. The **kernel** of $f$ is the set of all vectors in $U$ that map to the zero vector in $V$:  

$$
\text{Ker}(f) = \{ \alpha \in U \mid f(\alpha) = 0' \}
$$

where $0'$ denotes the zero vector in $V$.  

### Key Properties:  
1. The kernel is a **subspace** of $U$  
2. $f$ is injective (one-to-one) if and only if $\text{Ker}(f) = \{0\}$  
3. The kernel measures how much information is "lost" in the transformation  

**Example:**  
For the projection $f: \mathbb{R}^3 \to \mathbb{R}^2$ defined by $f(x,y,z) = (x,y)$, the kernel is:  
$$
\text{Ker}(f) = \{(0,0,z) \mid z \in \mathbb{R}\}
$$  

*(Note: The kernel is sometimes called the "null space" of the linear transformation)*

> **Note -**
> The dimension of null space is called Nullity

# Rank and Nullity of a Linear Transformation

Let T be a linear transformation from a vector space U(F) into a vector space V(F), where U(F) is a finite dimensional vector space. Then the dimension of the range of T is called the rank of T and is denoted by ρ(T) i.e.,

ρ(T) = rank of T = dim R(T)

and the nullity of T is defined as the dimension of the null space of T, denoted as n(T) i.e.,

n(T) = nullity of T = dim N(T)
