# White Box Testing

## White Box Testing

- **Alternative Names**:  
  Glass box testing, Clear box testing, Structural testing  
- **Primary Goal**:  
  Focus on input/output flow and enhance software security  
- **Internal Perspective**:  
  Tests internal structures (code, design, data structures) rather than just functionality  
- **Key Characteristics**:  
  - Analyzes inner workings of software  
  - Unlike black box testing which focuses on external behavior

# Control Structure Testing

- **Purpose**: Increases test coverage by examining control structures in the program.  
- **Types**:  
  1. **Condition Testing**  
  2. **Data Flow Testing**  
  3. **Loop Testing**
