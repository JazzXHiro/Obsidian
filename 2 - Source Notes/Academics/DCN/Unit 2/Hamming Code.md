Hamming Codes are a family of linear error‐correcting codes that not only detect single-bit errors but can also correct them. They work by inserting redundant parity bits into the data at positions corresponding to powers of 2. When the received code is checked, the pattern of errors in the parity bits can pinpoint the location of a single-bit error.
