# 1. Port Address & Socket Address


### 📌 **1. Port Address**

A **Port Address** is a **16-bit number** used to identify a **specific application (process)** on a host.

#### 🔑 Key Points:

- Each device (host) on a network has a unique **IP address**.
    
- Each **application/service** on that device is assigned a **port number**.
    
- Used by the **Transport Layer** (TCP/UDP) for **process-to-process communication**.
    

#### 📦 **Types of Port Numbers:**

|Range|Description|Examples|
|---|---|---|
|0 – 1023|**Well-known ports**|HTTP (80), FTP (21), DNS (53)|
|1024 – 49151|**Registered ports**|Used by applications|
|49152 – 65535|**Dynamic/private ports**|Temporary use by client apps|

#### 🧠 Example:

- A web server uses **port 80**.
    
- A DNS server uses **port 53**.
    

---

### 📌 **2. Socket Address**

A **Socket Address** uniquely identifies a **specific process on a specific host**.

#### 🔗 It is a combination of:

```
Socket Address = IP Address + Port Number
```

#### 🧠 Example:

```
192.168.1.5:80
```

This represents a web server running on **IP 192.168.1.5** using **port 80**.

#### 🧃 Usage:

- Allows client/server communication.
    
- Both **client and server** have their own socket addresses.
    
- Used by **TCP and UDP** protocols to establish connections.
    

---

### 🆚 **3. Difference Between Port Address and Socket Address**

|Feature|Port Address|Socket Address|
|---|---|---|
|Definition|Identifies a **process** on a host|Identifies a **process on a specific host**|
|Components|Only the **port number**|IP Address + Port Number|
|Uniqueness|Not globally unique|Globally unique|
|Used by|Transport Layer protocols|TCP/UDP for connection|

---

### ✅ **Summary**

- **Port Address** = Identifies a process (like a door number in a house).
    
- **Socket Address** = Identifies both the **house (IP)** and the **door (port)**.
    
- Both are essential for reliable communication in networks.
