# TCP

- **Byte Streaming -** The data received from the application layer is segmented into bytes.
- **Connection Oriented** - Reliability
- **Full Duples -** Both Sender and receiver can send data to each other simultaneously
- **Piggybacking -** When acknowledgment is being sent from receiver to sender, data can also be sent alongside with it.
