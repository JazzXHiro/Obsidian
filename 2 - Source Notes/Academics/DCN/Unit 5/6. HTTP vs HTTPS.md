# 6. HTTP vs HTTPS

## **HTTP** (Hypertext Transfer Protocol)
- Standard protocol for transmitting data over the web  
- Operates over **port 80**  
- Data transmission is **not encrypted**  

## **HTTPS** (Hypertext Transfer Protocol Secure)
- Uses encryption to protect data during transmission  
- Operates over **port 443**  
- Encrypts data using **SSL/TLS** protocols  
  - SSL (Secure Sockets Layer)  
  - TLS (Transport Layer Security)
