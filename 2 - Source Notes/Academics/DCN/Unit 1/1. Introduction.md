# Introduction

**Study Notes: Chapter 1 - Introduction to Data Communications and Networking**

---

### **1.1 Data Communications**  
- **Definition**: Exchange of data between two devices via a transmission medium (e.g., cable, fiber).  
- **Components** (Figure 1.1):  
  - **Sender**: Initiates communication.  
  - **Receiver**: Receives the data.  
  - **Medium**: Transmission channel (wired/wireless).  
  - **Message**: Data being transmitted.  
  - **Protocol**: Rules governing communication (e.g., formatting, timing).
    ![[Pasted image 20250306000947.png]]  

- **Data Flow Types** (Figure 1.2):  
  1. **Simplex**: One-way communication (e.g., keyboard to monitor).  
  2. **Half-Duplex**: Two-way, but not simultaneously (e.g., walkie-talkies).  
  3. **Full-Duplex**: Simultaneous two-way communication (e.g., phone call).  
     ![[Pasted image 20250306001228.png]]

---

### **1.2 Networks**  
- **Definition**: A set of nodes (devices) connected by communication links.  
  - **Node**: Computer, printer, or any data-sending/receiving device.  
  - **Link**: Medium transporting data (cable, air, fiber).  

#### **Network Criteria**  
1. **Performance**:  
   - Measured by **delay** (time to transmit) and **throughput** (data rate).  
2. **Reliability**:  
   - Low failure rate, high availability, and robustness.
3. **Security**:
   - Includes **data protection** against corruption, loss, and malicious users.  

#### **Physical Structures**  
- **Connection Types**:  
  - **Point-to-Point**: Dedicated link between two devices.
    ![[Pasted image 20250306002542.png]]  
  - **Multipoint**: Multiple recipients of single transmission.
    ![[Pasted image 20250306002604.png]]  
- **Physical Topologies** (Figures 1.4–1.9):
  
	- **Connection of devices:**
	  1. **Mesh**: Fully interconnected (robust but costly).
	     ![[Pasted image 20250306002657.png|400]]  
	  2. **Star**: Central hub connects all nodes (easy to manage).
	     ![[Pasted image 20250306004115.png|400]]  
	  3. **Bus**: Single backbone cable with drop lines (simple but prone to failure).
	     ![[Pasted image 20250306004135.png]]  
	  4. **Ring**: Circular connection (data travels in one direction).
	     ![[Pasted image 20250306004154.png]]  
	  5. **Hybrid**: Combines topologies (e.g., star backbone with bus networks).
	     ![[Pasted image 20250306004211.png|600]]  
	- **Types of Transmission:**
	  
	1. **Unicast**-
    - **Definition:** A one-to-one communication where data is sent from one sender to one specific receiver.
    - **Example:** A computer requesting a webpage from a web server.
      
	2. **Multicast**-
    - **Definition:** A one-to-many communication where data is sent from one sender to multiple specific receivers.
    - **Example:** IPTV, online video conferencing, and live-streamed webinars.
	
	1. **Broadcast**-
    - **Definition:** A one-to-all communication where data is sent from one sender to all devices in a network.
    - **Example:** ARP (Address Resolution Protocol) requests, radio and TV broadcasting.

#### **Network Categories**  
1. **LAN (Local Area Network)**:  
   - Short distances (e.g., office, building).  
   - High-speed connectivity.
     ![[Pasted image 20250306004649.png|400]]  
2. **WAN (Wide Area Network)**:  
   - Long distances (e.g., cities, countries).  
   - Includes **switched WAN** (e.g., internet) and **point-to-point WAN** (e.g., leased lines).
     ![[Pasted image 20250306005209.png|400]]  
3. **MAN (Metropolitan Area Network)**:  
   - Covers a city or campus.

### **1.3 The Internet**  
- A global communication system organizing vast information for users.  
- **Structure**:  
  - **Hierarchical organization** (Figure 1.13) with multiple tiers of ISPs (Internet Service Providers).
    ![[Pasted image 20250306005310.png|600]]  
  - **ISPs**: Provide internet access and interconnectivity.  

---

### **1.4 Protocols**  
- **Definition**: Rules governing data communication (what, how, and when to communicate).  
- **Key Elements**:  
  1. **Syntax**:  
     - Data structure/format (e.g., binary, ASCII).  
  2. **Semantics**:  
     - Meaning of data bits (e.g., control commands, addresses).  
  3. **Timing**:  
     - Synchronization (when to send/receive data) and speed matching.
