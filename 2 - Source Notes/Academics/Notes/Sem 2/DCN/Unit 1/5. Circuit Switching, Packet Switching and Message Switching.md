# Circuit Switching, Packet Switching and Message Switching

**Study Notes: Switching Techniques**

---

### **1. Basic Definitions**  
- **Low-Pass Channel**: Transfers frequencies near zero (baseband). Used in analog systems (e.g., traditional telephone lines).
  ![[Pasted image 20250306035807.png]]  
- **Harmonic**: A signal with a frequency that is an integer multiple of a reference signal’s frequency.  
- **Bit Rate**: Number of bits transmitted per unit of time (e.g., Mbps).  

---

### **2. Switching Techniques**  

#### **Circuit Switching**  
- **Definition**: Establishes a dedicated physical path between sender and receiver.
- In large networks, there can be multiple paths from sender to receiver. The switching technique will decide the best route for data transmission.
  ![[Pasted image 20250306041246.png|600]]
- **Phases**:  
  1. **Circuit Establishment**: Dedicated path setup (e.g., dialing in telephone networks).  
  2. **Data Transfer**: Continuous transmission (voice, video).  
  3. **Circuit Disconnect**: Path termination after communication.  
- **Technologies**:  
  - **Space Division Switches**: Physically separate paths (e.g., crossbar switches). A single transmission path is accomplished in a switch by using a physically separate set of cross points  
    - Space Division Switching can be achieved by using **crossbar switch**. A **crossbar switch** is a metallic cross point or semiconductor gate that can be enabled or disabled by a control unit.
    - The Crossbar switch is made by using the semiconductor.
    - Space Division Switching has high speed, high capacity, and nonblocking switches.
  - **Multistage Switches**: Reduces cross points; offers alternate paths if one fails.
    - Multistage Switch is made by splitting the crossbar switch into the smaller units and then interconnecting them.
    - It reduces the number of cross points.
    - If one path fails, then there will be an availability of another path.
- **Advantages of Circuit Switching**:  
  - Guaranteed bandwidth.  
  - Low latency during data transfer.  
- **Disadvantages of Circuit Switching**:  
  - Inefficient (idle paths waste capacity).  
  - High setup time (~10 seconds).  
  - Expensive for dedicated connections.  
- **Use Case**: Traditional telephone networks.  

---

#### **Message Switching**  
- **Definition**: Messages are stored and forwarded as a complete unit at intermediate nodes (no dedicated path).
  ![[Pasted image 20250306041502.png|600]]  
- **Process**:  
  - Entire message is sent as a single unit.  
  - Nodes store the message before forwarding (**store-and-forward**).  
- **Advantages**:  
  - Efficient bandwidth use (shared channels).  
  - Supports variable message sizes. 
  - Message priority can be used to manage the network.
  - Reduces traffic congestion via temporary storage.  
- **Disadvantages**:  
  - High latency (storage/forwarding delays).  
  - Requires large node storage capacity.  
- **Use Case**: Early email systems, telegrams.  

---

#### **Packet Switching**  
- **Definition**: Data is sent in one go by splitting into **packets** with headers (source, destination, sequence). Packets take independent paths.
- Packets are given a unique number to identify their order at the receiving end.
- All the packets are reassembled at the receiving end in correct order.
- If any packet is missing or corrupted, then the message will be sent to resend the data.
- If the correct order of the packets is reached, then the acknowledgment message will be sent.
  
  ![[Pasted image 20250306042254.png|600]]
- **Approaches**: 

| **Datagram (Connectionless)**                                                                                                                                                                | **Virtual Circuit (Connection-Oriented)**                                                        |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| No pre-established path.                                                                                                                                                                     | Path set up before transmission (call request/accept).                                           |
| Packet is known as a datagram, is considered as an independent entity. Contains information about destination, switch utilizes the information to forward the packet to correct destination. | ---                                                                                              |
| Packets may arrive out of order.                                                                                                                                                             | Packets follow a fixed route.                                                                    |
| Flexible routing.                                                                                                                                                                            | Lower routing flexibility.                                                                       |
| Congestion cannot occur as all the packets travel in different directions.                                                                                                                   | Congestion can occur when the node is busy, and it does not allow other packets to pass through. |
| Example: Internet (IP).                                                                                                                                                                      | Example: ATM networks.                                                                           |

- **Advantages of Packet Switching**:  
  - Cost-effective (shared resources).  
  - Reliable (reroutes packets if nodes fail).  
  - Efficient bandwidth usage.  
- **Disadvantages of Packet Switching**:  
  - Complex protocols (e.g., TCP/IP).  
  - Unsuitable for real-time apps (latency).  
  - Packet loss/corruption requires retransmission.  
- **Use Case**: Internet data transmission.  

---

### **3. Key Comparisons**  

| **Feature**            | **Circuit Switching**      | **Message Switching**      | **Packet Switching**       |  
|------------------------|----------------------------|----------------------------|----------------------------|  
| **Path Type**          | Dedicated                  | No dedicated path          | Shared/Predefined (VC)     |  
| **Delay**              | Low during transfer        | High (store-and-forward)   | Variable (depends on route) |  
| **Efficiency**         | Low (idle paths)           | Moderate                   | High (shared bandwidth)    |  
| **Cost**               | High (dedicated setup)     | Moderate                   | Low                        |  
| **Use Case**           | Voice calls                | Historical data networks   | Internet, modern networks  |  


---

### **5. Key Terms**  
- **Store-and-Forward**: Message stored at nodes before forwarding.  
- **Datagram**: Independent packets with dynamic routing.  
- **Virtual Circuit**: Predefined path for packet routing.  
- **Crosspoint**: Physical/electronic connection in switches.  

---

**Summary**:  
- **Circuit Switching**: Best for real-time, continuous communication (voice).  
- **Message Switching**: Outdated; high latency but efficient storage.  
- **Packet Switching**: Dominant in modern networks (Internet) due to flexibility and efficiency.
