# Performance Metrics

**Study Notes: Communication Channels and Performance Metrics**

---

### **1. Communication Channels**  
**Definition**: A medium through which data is transmitted from a sender to a receiver.  

#### **Types of Communication Channels**:  
1. **Guided (Wired) Media**:  
   - **Twisted Pair Cable**:  
     - Used in LANs (e.g., Cat6 for Ethernet).  
     - Vulnerable to crosstalk and EMI.  
   - **Coaxial Cable**:  
     - Higher bandwidth than twisted pair (e.g., cable TV).  
     - Shielded design reduces interference.  
   - **Fiber Optic Cable**:  
     - Uses light pulses for data transmission.  
     - High bandwidth, low attenuation, immune to EMI (e.g., internet backbone).  

2. **Unguided (Wireless) Media**:  
   - **Radio Waves**:  
     - Omnidirectional, used in Wi-Fi, Bluetooth, and cellular networks.  
   - **Microwaves**:  
     - Line-of-sight communication (e.g., satellite links, 5G mmWave).  
   - **Infrared**:  
     - Short-range, line-of-sight (e.g., remote controls).  

---

### **2. Performance Metrics**  
Key parameters to evaluate channel effectiveness:  

| **Metric**                      | **Definition**                                            | **Formula/Example**                                                             |     |
| ------------------------------- | --------------------------------------------------------- | ------------------------------------------------------------------------------- | --- |
| **Bandwidth**                   | Range of frequencies a channel can carry.                 | Measured in Hz (e.g., 2.4 GHz for Wi-Fi).                                       |     |
| **Data Rate**                   | Actual data transmitted per second (bps).                 | Influenced by bandwidth and SNR (e.g., 1 Gbps in fiber optics).                 |     |
| **Latency**                     | Time delay for data to travel from source to destination. | Includes propagation delay (distance/speed) and processing delay (e.g., 50 ms). |     |
| **Throughput**                  | Effective data transferred successfully per unit time.    | Often lower than data rate due to overhead (e.g., 900 Mbps on a 1 Gbps link).   |     |
| **Error Rate**                  | Ratio of corrupted bits to total bits transmitted.        | BER (Bit Error Rate) = Errored Bits / Total Bits.                               |     |
| **Signal-to-Noise Ratio (SNR)** | Ratio of signal power to noise power.                     | Higher SNR = Better quality (e.g., 30 dB).                                      |     |
| **Jitter**                      | Variation in latency over time.                           | Critical for real-time apps (e.g., VoIP requires < 30 ms jitter).               |     |

---

### **3. Key Relationships**  
- **Shannon's Theorem**:  
  $$C = B \cdot \log_2(1 + \text{SNR})$$
  - $C$ : Maximum channel capacity (bps).  
  - $B$ : Bandwidth (Hz).  
  - $SNR$ : Signal-to-noise ratio (linear scale).  

- **Bandwidth vs. Data Rate**: Higher bandwidth allows higher data rates but is limited by physical factors (e.g., attenuation).  
- **SNR vs. Error Rate**: Higher SNR reduces error rates (e.g., fiber optics vs. wireless in noisy environments).  

---

### **4. Factors Affecting Channel Performance**  
1. **Attenuation**: Signal loss over distance (e.g., UTP cables need repeaters for long distances).  
2. **Interference**:  
   - **EMI** (Guided media).  
   - **Multipath Propagation** (Wireless media).  
3. **Distortion**: Signal shape changes due to frequency-dependent delays.  
4. **Environmental Factors**: Weather (microwave/satellite), physical obstructions (Wi-Fi).  

---

### **5. Application-Specific Requirements**  
| **Application**         | **Key Metrics**                              | **Example**                                  |  
|-------------------------|---------------------------------------------|---------------------------------------------|  
| **Video Streaming**      | High throughput, low jitter.                | 4K streaming requires >25 Mbps throughput.   |  
| **Online Gaming**        | Low latency (<50 ms), stable jitter.        | Latency >100 ms causes lag.                  |  
| **IoT Sensors**          | Low power, moderate error tolerance.        | LoRaWAN for long-range, low-data transmission. |  
| **Satellite Comms**      | High latency tolerance, low error rate.     | Propagation delay ~250 ms (geostationary).   |  

---

### **6. Measurement Tools**  
- **Ping**: Measures latency (e.g., `ping google.com`).  
- **Speed Tests**: Check throughput (e.g., Ookla Speedtest).  
- **BERT (Bit Error Rate Tester)**: Quantifies error rates.  
- **Spectrum Analyzers**: Assess bandwidth and SNR.
