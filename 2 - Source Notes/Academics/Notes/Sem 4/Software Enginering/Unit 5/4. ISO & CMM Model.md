# Software Quality Framework

A structured methodology to ensure software meets quality standards throughout its lifecycle.

## Components:
1. **Quality Planning**  
   - Define objectives, standards, and metrics.  

2. **Quality Assurance (QA)**  
   - Ensure adherence via reviews, audits, and process improvements.  

3. **Quality Control (QC)**  
   - Monitor compliance via testing, inspections, and defect tracking.  

4. **Quality Improvement**  
   - Enhance quality via root cause analysis and process optimization.  

5. **Quality Metrics**  
   - Track and analyze data for informed decisions.  

6. **Quality Management**  
   - Organizational leadership and support for quality initiatives.  

## Common Frameworks:  
- ISO 9000 series  
- Capability Maturity Model (CMM)  
- Six Sigma

# ISO Quality Models

Internationally recognized standards for evaluating software quality:

- **ISO/IEC 9126** (Foundational model)  
- **ISO/IEC 25010** (Updated and extended version)

## ISO/IEC 9126 Quality Model

## 6 Major Characteristics:  
1. **Functionality** → Does it meet intended purpose?  
2. **Reliability** → Performance under specified conditions.  
3. **Usability** → Ease of use.  
4. **Efficiency** → Resource optimization.  
5. **Maintainability** → Ease of fixes/improvements.  
6. **Portability** → Adaptability across environments.

## ISO/IEC 25010 Quality Model (Updated)

## 8 Quality Characteristics:  
1. **Functional Suitability**  
   - Accuracy and completeness of functions.  

2. **Performance Efficiency**  
   - Response time and resource usage.  

3. **Compatibility**  
   - Co-existence and interoperability.  

4. **Usability**  
   - Ease of learning and use.  

5. **Reliability**  
   - Stability and fault tolerance.  

6. **Security**  
   - Confidentiality, integrity, authentication.  

7. **Maintainability**  
   - Ease of analysis, changes, and testing.  

8. **Portability**  
   - Transferability across environments.

# Capability Maturity Model (CMM)

- **Purpose**: The Capability Maturity Model (CMM) is a tool used to improve and refine software development processes. It provides a structured way for organizations to assess their current practices and identify areas for improvement.
- **Structure**:  
  - **5 Maturity Levels**:  
    1. Initial  
    2. Repeatable  
    3. Defined  
    4. Managed  
    5. Optimizing  
  - **Key Process Areas (KPA)**: Define capabilities for levels 2-5.  
- **Benefits**:  
  - Systematic process improvement.  
  - Higher-quality products.  
  - Efficient project management.

## Key Process Areas (KPA) 
Each of these KPA (Key Process Areas) defines the basic requirements that should be met by a software process to satisfy the KPA and achieve that level of maturity.

**Levels of Capability Maturity Model (CMM)**

 1. **Level One : Initial** – Work is performed informally. A software development organization at this level is characterized by AD HOC activities (organization is not planned in advance.). 
 
 2. **Level Two : Repeatable** – Work is planned and tracked. This level of software development organization has a basic and consistent project management processes to TRACK COST, SCHEDULE, AND FUNCTIONALITY. The process is in place to repeat the earlier successes on projects with similar applications. 
 
 3. **Level Three : Defined** – Work is well defined. At this level the software process for both management and engineering activities are DEFINED AND DOCUMENTED.

4. **Level Four : Managed** – Work is quantitatively controlled. Software Quality management – Management can effectively control the software development effort using precise measurements. At this level, organization set a quantitative quality goal for both software process and software maintenance. Quantitative Process Management – At this maturity level, The performance of processes is controlled using statistical and other quantitative techniques, and is quantitatively predictable. 

5. **Level Five : Optimizing** – Work is Based Upon Continuous Improvement. The key characteristic of this level is focusing on CONTINUOUSLY IMPROVING PROCESS performance. Key features are: Process change management Technology change management Defect prevention
