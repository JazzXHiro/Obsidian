# Algebra of Matrices
#### Matrix - 
Number of elements written in the form of rows and columns or in a form of array is known as **Matrix**.

$$
\begin{pmatrix}
a_{11} & a_{12} &\dots.. a_{1n} \\
a_{21} & a_{22} &\dots.. a_{2n}  \\
. \\
. \\
a_{m1} & a_{m2} &\dots.. a_{mn}
\end{pmatrix}
$$
![[Algebra of Matrices 2025-02-04 00.03.03.excalidraw]]

### Types of Matrices -

- **Square Matrix -** Number of rows and columns are going to be equal
$$
m=n
$$
Ex:-
$$
\begin{pmatrix}
1 & 2 \\
3 & 4
\end{pmatrix}_{2*2}
$$

- **Rectangular Matrix -** Here, m and n are rows and columns of any given matrix
$$
m \ne n
$$
Ex:-
$$
\begin{pmatrix}
2&3 \\
2&9 \\
3&7
\end{pmatrix}_{2*3}
$$
- **Diagonal Matrix -** A diagonal matrix is a square matrix in which all the elements outside of the principal diagonal are zero. The element on the principal matrix can be any value(including zero).
$$ A  \; \text{matrix} \; A = [a_{ij}] \; \text{of order n*n is a diagonal matrix if:}$$

$$
a_{ij} = 0 \; \text{for} \; i \ne j
$$


**Example:**
$$

$$
$$
A = \begin{pmatrix} a_{11} & 0 & 0 \\ 0 & a_{22} & 0 \\ 0 & 0 & a_{33} \end{pmatrix}​​​
$$

- **Scalar Matrix -** A scalar matrix is a special type of diagonal matrix in which all the principal diagonal elements are equal and all non principal diagonal elements are zero.
$$
\text{A matrix A =} \; [a_{ij}] \; \text{of order n*n is a scalar matrix if:}
$$
$$
a_{ij} = \begin{cases}
c & \text{if } i = j, \\
0 & \text{if } i \ne j,
\end{cases}
$$
$$
\begin{flalign*}
\text{where c is a constant.} &&
\end{flalign*}
$$

- **Unit/Identity -** An **Identity Matrix** (also called a **Unit Matrix**) is a special square matrix in which all the elements of the principal diagonal are 1, and all other elements are 0.

An identity matrix $I_n$ of order $n×n$ is defined as:

$$
I_{n}= \begin{cases}
1&if \;i=j \\
0&if \;i\ne j
\end{cases}
$$

### Example:

For $n=3$, the identity matrix is:

$$
I_{n} = \begin{pmatrix}
1&0&0 \\
0&1&0 \\
0&0&1
\end{pmatrix}
$$

 **Properties of an Identity Matrix:**

1. **Multiplicative Identity**:
    
    - For any square matrix $A$ of order $n×n$:
$$
      AI_{n} = I_{n}A = A
$$
    - This property makes the identity matrix the multiplicative identity in matrix algebra.

1. **Diagonal Matrix**:
    
    - An identity matrix is a special type of diagonal matrix where all diagonal elements are 1.

2. **Symmetric Matrix**:
    
    - The identity matrix is symmetric since $I^T = I$.

3. **Determinant**:
    
    - The determinant of an identity matrix is always 1.

4. **Inverse**:
    
    - The identity matrix is its own inverse: $I_{n}^{-1} = I_{n}$.

- **Null Matrix -** A **Null Matrix** (also called a **Zero Matrix**) is a matrix in which all elements are zero. It can be of any size, whether square or rectangular.

    **Properties of a Null Matrix:**

1. **Additive Identity**:
    
    - For any matrix $A$ of order $m \times n,\; A+O =O + A= A$ 
    - The null matrix acts as the additive identity in matrix algebra.
2. **Multiplication**:
    
    - For any matrix $A$ of compatible order: 
      $A.O=O.A=O$
3. **Determinant**:
    
    - If the null matrix is square, its determinant is always $0$.
    - If the matrix is **not square**, it does not have a determinant. The concept of a determinant is defined only for **square matrices** (matrices where the number of rows equals the number of columns). Therefore, for a **non-square null matrix**, it is simply referred to as a matrix with all zero elements, and we cannot calculate a determinant for it
4. **Transpose**:
    
    - The transpose of a null matrix is also a null matrix: $O^T = O$.

- **Upper Triangular Matrix -** An upper triangular matrix is a square matrix in which all the elements below the principal diagonal are zero. In other words, for a matrix $A$, if $A[i][j] = 0$
  whenever $i >j$, then $A$ is an upper triangular matrix. The principal diagonal and the elements above it can be any value(including zeroes).
  For example-
$$
\begin{pmatrix}
1&2&3 \\
0&4&5 \\
0&0&6
\end{pmatrix}
$$
- **Lower Triangular Matrix -** A lower triangular matrix is a square matrix in which all the elements above the principal diagonal are zero. In other words, for a matrix $A$, if $A[i][j] = 0$
  whenever $i <j$, then $A$ is an lower triangular matrix. The principal diagonal and the elements below it can be any value(including zeroes).
  For example-
$$
\begin{pmatrix}
1&0&0 \\
4&2&0 \\
5&6&3
\end{pmatrix}
$$
- **Idempotent matrix -** A square matrix that satisfies the condition:
$$
A^2 =A
$$
  In other words, when the matrix is multiplied by itself, it remains unchanged.
  For example
$$
A = \begin{pmatrix}
1&0 \\
0&0
\end{pmatrix}
$$
  When you multiply it by itself
$$
  A^2=\begin{pmatrix}
1&0 \\
0&0
\end{pmatrix}
\times \begin{pmatrix}
1&0 \\
0&0
\end{pmatrix} = \begin{pmatrix}
1&0 \\
0&0
\end{pmatrix} = A
$$
- **Involuntary Matrix -** A square matrix $A$ that satisfies the condition:
$$
A^2=I
$$
  where $I$ is the identity of the same size as $A$
  For example
  $$
A = \begin{pmatrix}
0&1 \\
1&0
\end{pmatrix}
$$
  When you multiply it by itself,
  $$
  A^2=\begin{pmatrix}
0&1 \\
1&0
\end{pmatrix}
\times \begin{pmatrix}
0&1 \\
1&0
\end{pmatrix} = \begin{pmatrix}
1&0 \\
0&1
\end{pmatrix} = I
$$

  - **Nilpotent Matrix -** A square matrix for which there exists a positive integer k such that:
$$
    A^k = 0
$$
  In other words, when the matrix is raised to some power k, the result is zero matrix or null matrix. The smallest such integer k is called the i**ndex/class of nilpotency**.
  For example
  $$
A = \begin{pmatrix}
0&1 \\
0&0
\end{pmatrix}
$$
  If we raise it to the second power:
  $$
  A^2=\begin{pmatrix}
0&1 \\
0&0
\end{pmatrix}
\times \begin{pmatrix}
0&1 \\
0&0
\end{pmatrix} = \begin{pmatrix}
0&0 \\
0&0
\end{pmatrix} = 0
$$
  So, $A^2 =0$, and $A$ is a nilpotent matrix with index 2.

  - **Singular Matrix -** A singular matrix is a square matrix that does not have an inverse, This means that determinant of the matrix is zero. In other words, a matrix A is singular if:
$$
  \det(A) =0
$$
   A singular matrix has at least one of the following properties:

    - It is not invertible.
    - The rows or columns of the matrix are linearly dependent (i.e., one row or column can be expressed as a linear combination of others).
    - It has a zero determinant.

     **For example,**
     $$
A = \begin{pmatrix}
1&2 \\
2&4
\end{pmatrix}
$$
     The second row is a multiple of the first row (the second row is 2 times the first row), making the matrix singular. Its determinant is:
$$
     \det(A) = (1)(4) - (2)(2)= 4-4=0
$$

   - **Row Matrix -** A row matrix is a matrix that consists only of a single row of element. It is a 1xn matrix where $n$ represents the number of columns, and matrix has only one row.
   
   - **Column Matrix -** A column matrix is a matrix that consists only of a single column of element. It is a nx1 matrix where $n$ represents the number of rows, and matrix has only one column.

   - **Equality Matrix -** An **equality matrix** is not a standard term in linear algebra. However, if you're referring to **equality of matrices**, it means that two matrices are equal if and only if they satisfy two conditions:

   1. **Same dimensions**: Both matrices must have the same number of rows and columns.
   2. **Corresponding elements are equal**: The element in the $i$-th row and $j$-th column of the first matrix must be equal to the element in the $i$-th row and $j$-th column of the second matrix for all corresponding positions.

   - **Equivalent Matrix -** Two matrices are said to equivalent if they have the same order.
