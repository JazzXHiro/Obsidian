# 5.4.1 Common Integration Formulas

# 📘 Common Derivatives and Integrals

---

## 🔁 Derivatives

### 🔹 Basic Rules

$$
\frac{d}{dx}(cf(x)) = c \cdot f'(x)
$$

$$
\frac{d}{dx}(f(x) \pm g(x)) = f'(x) \pm g'(x)
$$

$$
\frac{d}{dx}(x^n) = nx^{n-1}
$$

$$
\frac{d}{dx}(c) = 0
$$

$$
\frac{d}{dx}(f(x)g(x)) = f'(x)g(x) + f(x)g'(x) \quad \text{(Product Rule)}
$$

$$
\frac{d}{dx}\left( \frac{f(x)}{g(x)} \right) = \frac{f'(x)g(x) - f(x)g'(x)}{g(x)^2} \quad \text{(Quotient Rule)}
$$

$$
\frac{d}{dx}[f(g(x))] = f'(g(x)) \cdot g'(x) \quad \text{(Chain Rule)}
$$

---

### 🔹 Polynomials

- $\frac{d}{dx}(c) = 0$
- $\frac{d}{dx}(x) = 1$
- $\frac{d}{dx}(cx) = c$
- $\frac{d}{dx}(x^n) = nx^{n-1}$
- $\frac{d}{dx}(cx^n) = ncx^{n-1}$

---

### 🔹 Trig Functions

- $\frac{d}{dx}[\sin x] = \cos x$
- $\frac{d}{dx}[\cos x] = -\sin x$
- $\frac{d}{dx}[\tan x] = \sec^2 x$
- $\frac{d}{dx}[\csc x] = -\csc x \cot x$
- $\frac{d}{dx}[\sec x] = \sec x \tan x$
- $\frac{d}{dx}[\cot x] = -\csc^2 x$

---

### 🔹 Inverse Trig Functions

- $\frac{d}{dx}[\sin^{-1}x] = \frac{1}{\sqrt{1 - x^2}}$
- $\frac{d}{dx}[\cos^{-1}x] = -\frac{1}{\sqrt{1 - x^2}}$
- $\frac{d}{dx}[\tan^{-1}x] = \frac{1}{1 + x^2}$
- $\frac{d}{dx}[\csc^{-1}x] = -\frac{1}{|x|\sqrt{x^2 - 1}}$
- $\frac{d}{dx}[\sec^{-1}x] = \frac{1}{|x|\sqrt{x^2 - 1}}$
- $\frac{d}{dx}[\cot^{-1}x] = -\frac{1}{1 + x^2}$

---

### 🔹 Exponential and Logarithmic

- $\frac{d}{dx}[e^x] = e^x$
- $\frac{d}{dx}[a^x] = a^x \ln a$
- $\frac{d}{dx}[\ln x] = \frac{1}{x}$, $x > 0$
- $\frac{d}{dx}[\ln |x|] = \frac{1}{x}$, $x \ne 0$
- $\frac{d}{dx}[\log_a x] = \frac{1}{x \ln a}$

---

### 🔹 Hyperbolic Functions

- $\frac{d}{dx}[\sinh x] = \cosh x$
- $\frac{d}{dx}[\cosh x] = \sinh x$
- $\frac{d}{dx}[\tanh x] = \text{sech}^2 x$
- $\frac{d}{dx}[\text{csch} x] = -\text{csch} x \cdot \text{coth} x$
- $\frac{d}{dx}[\text{sech} x] = -\text{sech} x \cdot \tanh x$
- $\frac{d}{dx}[\text{coth} x] = -\text{csch}^2 x$

---

## ➕ Integrals

### 🔹 Basic Rules

- $\int cf(x)\,dx = c \int f(x)\,dx$
- $\int [f(x) \pm g(x)]\,dx = \int f(x)\,dx \pm \int g(x)\,dx$
- $\int_a^b f(x)\,dx = F(b) - F(a)$, where $F(x) = \int f(x)\,dx$
- $\int_a^a f(x)\,dx = 0$
- $\int_b^a f(x)\,dx = -\int_a^b f(x)\,dx$

---

### 🔹 Polynomials and Rational

- $\int dx = x + c$
- $\int k\,dx = kx + c$
- $\int x^n\,dx = \frac{x^{n+1}}{n+1} + c, \quad n \ne -1$
- $\int \frac{1}{x}\,dx = \ln |x| + c$
- $\int \frac{1}{ax + b}\,dx = \frac{1}{a} \ln |ax + b| + c$

---

### 🔹 Trigonometric

- $\int \sin x\,dx = -\cos x + c$
- $\int \cos x\,dx = \sin x + c$
- $\int \sec^2 x\,dx = \tan x + c$
- $\int \csc^2 x\,dx = -\cot x + c$
- $\int \sec x \tan x\,dx = \sec x + c$
- $\int \csc x \cot x\,dx = -\csc x + c$
- $\int \tan x\,dx = \ln |\sec x| + c$
- $\int \cot x\,dx = \ln |\sin x| + c$
- $\int \sec x\,dx = \ln |\sec x + \tan x| + c$
- $\int \csc x\,dx = \ln |\csc x - \cot x| + c$

---

### 🔹 Inverse Trig

- $\int \frac{1}{\sqrt{a^2 - x^2}}\,dx = \sin^{-1} \left(\frac{x}{a}\right) + c$
- $\int \frac{1}{a^2 + x^2}\,dx = \frac{1}{a} \tan^{-1} \left( \frac{x}{a} \right) + c$
- $\int \frac{1}{x \sqrt{x^2 - a^2}}\,dx = \frac{1}{a} \sec^{-1} \left( \frac{x}{a} \right) + c$

---

### 🔹 Exponential and Logarithmic

- $\int e^x\,dx = e^x + c$
- $\int a^x\,dx = \frac{a^x}{\ln a} + c$
- $\int \ln x\,dx = x \ln x - x + c$
- $\int u e^u\,du = (u - 1) e^u + c$

---

### 🔹 Hyperbolic

- $\int \sinh x\,dx = \cosh x + c$
- $\int \cosh x\,dx = \sinh x + c$
- $\int \tanh x\,dx = \ln \cosh x + c$
- $\int \text{sech}^2 x\,dx = \tanh x + c$
- $\int \text{csch}^2 x\,dx = -\coth x + c$
- $\int \text{sech} x \tanh x\,dx = -\text{sech} x + c$

---

### 🔹 Special Forms (Examples)

- $\int \sqrt{a^2 - x^2}\,dx = \frac{x}{2} \sqrt{a^2 - x^2} + \frac{a^2}{2} \sin^{-1} \left( \frac{x}{a} \right) + c$
- $\int \sqrt{a^2 + x^2}\,dx = \frac{x}{2} \sqrt{a^2 + x^2} + \frac{a^2}{2} \ln \left| x + \sqrt{a^2 + x^2} \right| + c$
- $\int \sqrt{x^2 - a^2}\,dx = \frac{x}{2} \sqrt{x^2 - a^2} - \frac{a^2}{2} \ln \left| x + \sqrt{x^2 - a^2} \right| + c$
