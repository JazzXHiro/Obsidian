# 1.2 Types of Attacks

## Types of Attacks and Security Services

Information security requirements are defined by considering three aspects: **security service**, **security mechanism**, and **security attack**.

## Security Services (X.800)

1. **Authentication**: Providing assurance that the communicating entity is the one claimed.

2. **Access Control**: Preventing the unauthorized use of a resource.

3. **Data Confidentiality**: Protecting data from unauthorized disclosure.

4. **Data Integrity**: Providing assurance that data received is exactly as it was sent by an authorized entity.

5. **Non-Repudiation**: Protection against denial by one of the parties involved in a communication

## Security Mechanisms (X.800)

These include specific security mechanisms like encipherment, digital signatures, access controls, data integrity, authentication exchange, traffic padding, routing control, and notarization,. Pervasive security mechanisms include trusted functionality, security labels, event detection, security audit trails, and security recovery.

## Classification of Security Attacks

Attacks are generally classified into two categories:

1. **Passive Attacks**: Attacks that involve eavesdropping on, or monitoring, transmissions. The goal is to obtain information without modifying the data.

    ◦ **Examples:** Release of message contents or monitoring traffic flows (traffic analysis),. Passive attacks often involve interception.

2. **Active Attacks**: Attacks that involve the modification of the data stream or the creation of a false stream.

    ◦ **Examples:** Masquerade (one entity impersonating another), Replay (repeating previous messages), Modification (changing messages in transit), and Denial of Service (blocking delivery of a message or overwhelming a system—Interruption),.

### Cryptanalytic Attack Types

These focus on breaking the cipher algorithm itself:

• **Ciphertext Only**: The attacker knows only the algorithm and the resulting ciphertext, relying on statistical analysis to potentially identify the plaintext.

• **Known Plaintext**: The attacker knows or suspects certain portions of the plaintext corresponding to specific ciphertext.

• **Chosen Plaintext**: The attacker is able to select specific plaintext and obtain the corresponding ciphertext to study the cipher.

• **Chosen Ciphertext**: The attacker is able to select specific ciphertext and obtain the corresponding decrypted plaintext.

• **Chosen Text**: The attacker selects either plaintext or ciphertext for en/decryption to analyze the cipher,.

The most basic attack is the **Brute Force Search**, where the attacker tries every possible key, assuming they can recognize the correct plaintext when found; the time required is proportional to the key size
