# 1.1 Basic Concepts and Terminology

• **Classical Era:** All classical encryption algorithms used the **private-key** (or symmetric/conventional/single-key) method, where the sender and recipient share a common key. This was the only type of encryption prior to the invention of **public-key** cryptography in the 1970s.

• **Pre-Modern Ciphers:** Before modern ciphers, **Rotor Machines** were the most common ciphers using multi-stage encryption. They were widely used in World War II and include famous examples like the German Enigma, Allied Hagelin, and Japanese Purple. These machines implemented a complex, varying substitution cipher using a series of rotating cylinders.

|                          | **Decipher (Decrypt)**: Convert ciphertext back to plaintext.                                                   |
