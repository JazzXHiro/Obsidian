# 1.5 Cryptanalysis

**Cryptanalysis** is the study of methods for breaking ciphertext without prior knowledge of the key,.

• **Frequency Analysis:** A powerful technique against monoalphabetic substitution ciphers, utilizing the fact that letters in human languages (like English) are not equally common (e.g., 'e' is the most common). Cryptanalysts calculate letter frequencies in the ciphertext and match them against known language frequency tables.

• **Brute Force:** Trying every possible key, though feasibility depends on the key size.

Security Levels

• **Computational Security**: A cipher cannot be broken given limited computing resources (e.g., the time needed for calculations exceeds the age of the universe).

• **Unconditional Security**: A cipher cannot be broken, regardless of available computer power, because the ciphertext provides insufficient information to uniquely determine the plaintext.

## Vigenere Cipher
The **Vigenère Cipher** is an improvement over the Caesar cipher. Instead of using **one fixed shift**, it uses **multiple shifts based on a keyword**, making it more secure.

---

# ⭐ How Vigenère Cipher Works

## 🔑 You need:

1. A **message (plaintext)**
    
2. A **keyword**
    
3. The **Vigenère table** (optional, can be calculated)
    

---

# 🧠 Basic Idea

👉 Each letter of the message is shifted based on the **corresponding letter of the keyword**.

Example keyword:

```
KEY
```

Numeric shifts:

- K → 10
    
- E → 4
    
- Y → 24
    

(Where A=0, B=1, C=2 ..., Z=25)

So instead of one fixed shift, you get changing shifts like:

10, 4, 24, 10, 4, 24, …

---

# 🔐 Encryption Process

### Example

Plaintext:

```
ATTACKATDAWN
```

Keyword:

```
LEMON
```

Step 1: Repeat keyword until it matches length of message:

Plaintext: A T T A C K A T D A W N  
Keyword: L E M O N L E M O N L E

Step 2: Apply Caesar shift based on keyword letters:

|Plain|Keyword|Shift|Cipher|
|---|---|---|---|
|A (0)|L (11)|+11|L (11)|
|T (19)|E (4)|+4|X (23)|
|T (19)|M (12)|+12|F (5)|
|A (0)|O (14)|+14|O (14)|
|C (2)|N (13)|+13|P (15)|
|K (10)|L (11)|+11|V (21)|
|A (0)|E (4)|+4|E (4)|
|T (19)|M (12)|+12|F (5)|
|D (3)|O (14)|+14|R (17)|
|A (0)|N (13)|+13|N (13)|
|W (22)|L (11)|+11|H (7)|
|N (13)|E (4)|+4|R (17)|

👉 Ciphertext:

```
LXFOPVEFRNHR
```

---

# 🔓 Decryption

Reverse the process (subtract key value).

Ciphertext:

```
LXFOPVEFRNHR
```

Keyword:

```
LEMONLEMONLE
```

Example:  
L (11) − L (11) = A  
X (23) − E (4) = T  
F (5) − M (12) = T  
...

Recovered plaintext:

```
ATTACKATDAWN
```

---

# 📌 Characteristics

### ✔ It is a **polyalphabetic cipher**

Meaning:

- It uses _multiple Caesar ciphers_.
    

### ✔ Pattern breaks

Same letter in plaintext encrypts differently

Example:  
Plaintext: A A A A  
Key: B C D E

Ciphertext: B C D E

So frequency analysis becomes difficult.

---

# 🔑 Vigenère Table (Tabula Recta)

It is a 26×26 table where each row is a shifted alphabet.

Example (partial):

||A|B|C|D|...|
|---|---|---|---|---|---|
|A|A|B|C|D|...|
|B|B|C|D|E|...|
|C|C|D|E|F|...|
|D|D|E|F|G|...|
|...|...|||||

Encryption rule is:

```
Cipher = table[row = keyword letter][column = plaintext letter]
```

---

# ⭐ Advantages Over Caesar Cipher

✔ Uses multiple shifts  
✔ Much harder to crack  
✔ Resists frequency analysis

---

# ❌ Weakness

Still breakable if:

- The keyword is short
    
- Frequency analysis is done on repeating segments
    

Modern algorithms have replaced it, but it remains an important foundation in cryptography.

The One-Time Pad

The **One-Time Pad** achieves unconditional security. It is unbreakable because it uses a **truly random key that is as long as the message** and the ciphertext consequently bears no statistical relationship to the plaintext.

• **Limitation:** The key can only be used once, and safely distributing a key equal in length to the message is a significant problem.
