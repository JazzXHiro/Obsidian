# 1.5 Cryptanalysis

**Cryptanalysis** is the study of methods for breaking ciphertext without prior knowledge of the key,.

• **Frequency Analysis:** A powerful technique against monoalphabetic substitution ciphers, utilizing the fact that letters in human languages (like English) are not equally common (e.g., 'e' is the most common). Cryptanalysts calculate letter frequencies in the ciphertext and match them against known language frequency tables.

• **Brute Force:** Trying every possible key, though feasibility depends on the key size.

Security Levels

• **Computational Security**: A cipher cannot be broken given limited computing resources (e.g., the time needed for calculations exceeds the age of the universe).

• **Unconditional Security**: A cipher cannot be broken, regardless of available computer power, because the ciphertext provides insufficient information to uniquely determine the plaintext.

## Vigenere Cipher
The **Vigenère Cipher** is an improvement over the Caesar cipher. Instead of using **one fixed shift**, it uses **multiple shifts based on a keyword**, making it more secure.

---

### ⭐ How Vigenère Cipher Works

#### 🔑 You need:

1. A **message (plaintext)**
    
2. A **keyword**
    
3. The **Vigenère table** (optional, can be calculated)
    

---

### 🧠 Basic Idea

👉 Each letter of the message is shifted based on the **corresponding letter of the keyword**.

Example keyword:

```
KEY
```

Numeric shifts:

- K → 10
    
- E → 4
    
- Y → 24
    

(Where A=0, B=1, C=2 ..., Z=25)

So instead of one fixed shift, you get changing shifts like:

10, 4, 24, 10, 4, 24, …

---

### 🔐 Encryption Process

#### Example

Plaintext:

```
ATTACKATDAWN
```

Keyword:

```
LEMON
```

Step 1: Repeat keyword until it matches length of message:

Plaintext: A T T A C K A T D A W N  
Keyword: L E M O N L E M O N L E

Step 2: Apply Caesar shift based on keyword letters:

|Plain|Keyword|Shift|Cipher|
|---|---|---|---|
|A (0)|L (11)|+11|L (11)|
|T (19)|E (4)|+4|X (23)|
|T (19)|M (12)|+12|F (5)|
|A (0)|O (14)|+14|O (14)|
|C (2)|N (13)|+13|P (15)|
|K (10)|L (11)|+11|V (21)|
|A (0)|E (4)|+4|E (4)|
|T (19)|M (12)|+12|F (5)|
|D (3)|O (14)|+14|R (17)|
|A (0)|N (13)|+13|N (13)|
|W (22)|L (11)|+11|H (7)|
|N (13)|E (4)|+4|R (17)|

👉 Ciphertext:

```
LXFOPVEFRNHR
```

---

### 🔓 Decryption

Reverse the process (subtract key value).

Ciphertext:

```
LXFOPVEFRNHR
```

Keyword:

```
LEMONLEMONLE
```

Example:  
L (11) − L (11) = A  
X (23) − E (4) = T  
F (5) − M (12) = T  
...

Recovered plaintext:

```
ATTACKATDAWN
```

---

### 📌 Characteristics

### ✔ It is a **polyalphabetic cipher**

Meaning:

- It uses _multiple Caesar ciphers_.
    

#### ✔ Pattern breaks

Same letter in plaintext encrypts differently

Example:  
Plaintext: A A A A  
Key: B C D E

Ciphertext: B C D E

So frequency analysis becomes difficult.

---

### ⭐ Advantages Over Caesar Cipher

✔ Uses multiple shifts  
✔ Much harder to crack  
✔ Resists frequency analysis

---

### ❌ Weakness

Still breakable if:

- The keyword is short
    
- Frequency analysis is done on repeating segments
    

Modern algorithms have replaced it, but it remains an important foundation in cryptography.

### Hill Cipher – Exam-Oriented Notes

---

## Definition**

Hill cipher is a **polygraphic substitution cipher** based on **linear algebra**.  
Invented by Lester Hill in 1929.

It encrypts a block of letters using:

```
C = K × P mod 26
```

---

---

# **Key Concepts**

### ✔ Each letter → number

```
A = 0, B = 1, … , Z = 25
```

### ✔ Block (n-gram) encryption

- If K is **2×2**, plaintext taken as 2 letters at a time
    
- If K is **3×3**, plaintext taken as 3 letters at a time
    

### ✔ Key must be invertible mod 26

---

---

# **Encryption**

Let

- P = column vector of plaintext
    
- K = encryption key matrix
    

Then ciphertext:

```
C = K × P mod 26
```

Example:

Let key matrix

```
K = | 3 3 |
    | 2 5 |
```

Plaintext: "HI"  
→ H = 7, I = 8

```
C = K × P = |3 3| × |7| = |3×7 + 3×8| = |45|
            |2 5|   |8|   |2×7 + 5×8|   |54|
```

Now mod 26:

```
45 mod 26 = 19 → T
54 mod 26 = 2  → C
```

Ciphertext = **"TC"**

---

---

# **Decryption**

Formula:

```
P = K⁻¹ × C mod 26
```

So compute **inverse of key matrix mod 26**.

---

---

# **Finding Inverse of 2×2 Key Matrix**

Let

```
K = |a b|
    |c d|
```

Step-wise:

1️⃣ Compute determinant

```
det(K) = ad − bc
```

2️⃣ Compute inverse of determinant mod 26  
Find `det⁻¹` such that

```
(det × det⁻¹) mod 26 = 1
```

(using trial, extended Euclid or modular inverse formula)

3️⃣ Multiply adjoint matrix  
Adj(K) =

```
| d  −b |
| −c  a |
```

4️⃣ Final inverse:

```
K⁻¹ = det⁻¹ × Adj(K) mod 26
```

---

---

## Worked Example of Decryption

Using same key:

```
K = |3 3|
    |2 5|
```

Step-1:

```
det = (3×5 − 3×2) = 15 − 6 = 9
```

Step-2: Find inverse of 9 mod 26  
Search for x such that:

```
9x mod 26 = 1
```

Try x = 3:

```
9×3 = 27 = 1 mod 26 → OK
```

So det⁻¹ = 3

Step-3: Adj(K) =

```
| 5  −3 |
| −2  3 |
```

Step-4:

```
K⁻¹ = 3 × | 5 −3 |
            |−2  3 |
```

Multiply:

```
= |15 −9 |
  |−6  9 |
```

Take mod 26:

```
15 → 15
−9 → 17
−6 → 20
 9 → 9
```

Hence,

```
K⁻¹ = |15 17|
      |20  9|
```

👉 Now use for decryption:

```
P = K⁻¹ × C mod 26
```

---

---

# **Conditions on Key Matrix**

To be valid key:

✔ Matrix must be **square**  
✔ Determinant must be **non-zero modulo 26**  
✔ Determinant must have inverse mod 26  
→ i.e. gcd(det, 26) = 1

Therefore acceptable determinants must be coprime with 26 (i.e., ≠ multiples of 2 or 13)

---

---

# **Advantages**

✔ Strong against frequency attack (polygraphic)  
✔ Includes confusion and diffusion  
✔ Mathematical formulation and systematic encryption

---

---

# **Disadvantages**

✘ Susceptible if attacker has plaintext-ciphertext pairs  
✘ Requires matrix inverse mod 26  
✘ Implementation complexity (compared to Caesar/Vigenère)

# **Quick Memory Trick**

Matrix inverse pattern:

```
|a b|⁻¹ = det⁻¹ × | d  −b |
|c d|           | −c  a |
```

✔ Swap diagonal  
✔ Negate off-diagonal  
✔ Multiply by modular inverse of determinant

The One-Time Pad

The **One-Time Pad** achieves unconditional security. It is unbreakable because it uses a **truly random key that is as long as the message** and the ciphertext consequently bears no statistical relationship to the plaintext.

• **Limitation:** The key can only be used once, and safely distributing a key equal in length to the message is a significant problem.
