## Automaton & Its Configuration

### 1. Automaton as Recognizer or Acceptor
- Automaton takes an **input string** $w$.
- It checks whether $w \in L$ over $\Sigma$.

Results:
- **YES** → $w$ is a valid string.
- **NO** → $w$ is an invalid string.

---

### 2. Automaton as Generator, Enumerator, or Transducer
- Automaton takes an **input string** $w$.
- Automaton produces **output**.

Result:
- **Output string** $w$

## Finite Automata

- Finite automata are mainly used for **pattern recognition**.  

- It takes the **string of symbols** as **input** and changes its **state** accordingly.  

- When the desired symbol is found, then a **transition** occurs.  

- At the time of transition, the automaton can either move to the **next state** or stay in the **same state**.  

- Finite automata have two states:  
  - **Accept state**  
  - **Reject state**  

---

## Formal Description of Finite Automata (FA)

A finite automaton is a collection of **5-tuple**:

$$(Q, \Sigma, q_0, F, \delta)$$

where:

1. $Q$ : Finite set of states  
2. $\Sigma$ : Finite set of input symbols (alphabet)  
3. $q_0 \in Q$ : Initial state  
4. $F \subseteq Q$ : Set of final (accepting) states  
5. $\delta : Q \times \Sigma \to Q$ : Transition function  

---

## Finite Automata Model

Finite automata can be represented by **input tape** and **finite control**.

---

### Input Tape
- It is a linear tape having some number of cells.  
- Each input symbol is placed in each cell.  

Example:  
Input tape:  
$$a | \; b |\; c |\; a |\; b |\; b |\; a$$

### Finite Control
- The finite control decides the **next state** on receiving a particular input from the input tape.  
- The tape reader reads the cells one by one **from left to right**.  
- At a time, only **one input symbol** is read.

## Deterministic Finite Automata (DFA)

- **DFA** refers to *Deterministic Finite Automata*.  
  - *Deterministic* refers to the **uniqueness** of the computation.  

- Example alphabet:  
  $$ \Sigma = \{0, 1\} $$

- In DFA, there is **only one path** for a specific input from the current state to the next state.  

- **DFA does not accept the null move**, i.e., the DFA **cannot change state without any input character**.  

---
## Formal Description of DFA

A DFA is a collection of 5-tuples same as we described in the definition of FA:

$$ FA = \{Q, \Sigma, q_0, F, \delta\} $$

---

### Components:

1. **Q**: finite set of states  
2. **Σ**: finite set of the input symbols  
3. **q₀**: initial state  
4. **F**: final state  
5. **δ**: Transition function  

### Transition Function

The transition function can be defined as:  

$$ \delta : Q \times \Sigma \rightarrow Q $$

# Processing of Strings by DFA

Suppose  

$$ a_1, a_2, a_3, \dots, a_n $$  

is a sequence of input symbols.  

We start out with a **Deterministic Finite Automaton (DFA)** having  

$$ q_0, q_1, q_2, \dots, q_n $$  

states, where:  
- $q_0$ is the **initial state**  
- $q_n$ is the **final state**  

---

### Two Cases

1. **Accepted**  
   - If the DFA ends in a **final state** after processing the input string.

2. **Rejected**  
   - If the DFA does **not** end in a final state after processing the input string.
