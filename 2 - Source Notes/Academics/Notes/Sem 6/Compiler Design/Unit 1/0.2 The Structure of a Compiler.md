# 0.2 The Structure of a Compiler

> There are two parts to the mapping of the source program to a semantically equivalent target program - 
> i) analysis              and              (ii) synthesis

![[Pasted image 20260116222156.png]]


> [!NOTE] Analysis and Synthesis
> 
> Analysis - The analysis part breaks up the source into it's constituent parts and imposes a grammatical structure on them. It then utilizes that structure to create an intermediate representation of the source program. If the analysis part concludes that any part of the source code is syntatically or semantically wrong, it needs to send a message to the user for the appropriate corrective action. The analysis part also collects the information about the source program and stores it in a data structure called the Symbol table, which is then passed along to the synthesis part along with the Symbol table.
