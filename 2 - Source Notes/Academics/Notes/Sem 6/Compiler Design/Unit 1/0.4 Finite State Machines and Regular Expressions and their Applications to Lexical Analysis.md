# Finite State Machines and Regular Expressions and their Applications to Lexical Analysis

## Lexical Analyzer

First phase of compiler design. The task of lexical analyzer phase is to identify the valid words that we have in the $i/p$ program for the language that we are considering which should be independent of formatting(or indentation) generally. Lexical Analyzers is divided into cascade of two processes.

### Two Main Processes

#### 1. Scanning

- Reads the input program character by character.
    
- Removes:
    
    - White spaces
        
    - Comments
- Groups characters into meaningful sequences.

```
+-------------+     +-----------+     +-------------------+     +--------+
|   Input     | --> | Scanning  | --> | Lexical Analysis  | --> | Tokens |
|   Program   |     |           |     |                   |     |        |
+-------------+     +-----------+     +-------------------+     +--------+
```
#### 2. Lexical Analysis(Token Generation)

- Converts sequences of characters into **tokens**.
  
- Produces tokens for the parser.

##### [[0.2 The Structure of a Compiler#^143883|Token]]
A pair comprising of token name and and an optional token value.
**Examples:**

- Keywords → `int`, `float`
    
- Identifiers → `a`, `sum`
    
- Operators → `+`, =
    
- Constants → `10`, `5.5`

##### Lexeme
A sequence of $i/p$ characters that comprises of a single token.

**Example-**

```cpp
#include <stdio.h>

int main()
	{
	printf("HELLO WORLD");
	return 0;
	}
```

$$\#include<stdio.h>\text{intmain()}\{\text{printf("HELLOWORLD");return0;}\}$$

##### Pattern
A description of the form that Lexeme of a token may take.


> [!NOTE] Extra
> Lexeme are also defined as sequence of characters in the source program that matches the pattern of token.

###### Types of Tokens

1. **Keywords**
   - Reserved words.
   - Have predefined meaning.
   - Cannot be used as identifiers.
   - Example:`if, else, while, int, float, return, for`
   - Token form: `<KEYWORD>`

2. **Identifiers**
   - Names given by programmers
   - Used for variables, functions, arrays etc.
   - Usually: letter followed by letters and digits.
   - Examples: `a, sum, totalMarks, pi`
   - Token form: `ID, pointer_to_symbol_table`

3. **Constants (Literals)**
   - Integer constants, floating constants, character constants
