# Bootstrapping

**Bootstrapping** is the technique of creating an advanced compiler from a simpler and basic version of the compiler. This process helps in development of new programming languages. Starting with a simple compiler permits gradual improvements and makes the compiler more efficient over time.

- Bootstrapping relies on the idea of self-compiling compiler, where the iteration improves the compiler's ability to handle more complex code.
  
- It simplifies the development cycle, allowing incremental improvements and faster deployment of more robust compilers.

- Many successful programming languages such as C and Java have utilized bootstrapping technique during their development.

## Working of Bootstrapping

It involves a methodology where a slightly more complicated compiler is created using a simple language(such as assembly language). The slightly more complicated compiler, in turn, is used to create an even advanced compiler and this process is continued until desired result is achieved.

**1. Start with a Basic Compiler -** The first step is to create a basic compiler that can handle the most essential feature of a programming language. This simple compiler is often written in assembly language or machine language to make it easier to build.

**2. Use the Basic Compiler to Create a More Advanced Version -** Once the basic compiler is ready. It is useful to compile a more advanced version of itself. This new version can handle more complex features like better error-checking and optimizations.

**3. Gradually Improve the Compiler -** Each new version iterates over the last to provide more features making the compiler stronger and efficient.
