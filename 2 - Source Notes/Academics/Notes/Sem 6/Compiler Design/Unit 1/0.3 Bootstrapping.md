# Bootstrapping

**Bootstrapping** is the technique of creating an advanced compiler from a simpler and basic version of the compiler. This process helps in development of new programming languages. Starting with a simple compiler permits gradual improvements and makes the compiler more efficient over time.

- Bootstrapping relies on the idea of self-compiling compiler, where the iteration improves the compiler's ability to handle more complex code.
  
- It simplifies the development cycle, allowing incremental improvements and faster deployment of more robust compilers.

- Many successful programming languages such as C and Java have utilized bootstrapping technique during their development.

## Working of Bootstrapping

It involves a methodology where a slightly more complicated compiler is created using a simple language(such as assembly language). The slightly more complicated compiler, in turn, is used to create an even advanced compiler and this process is continued until desired result is achieved.

**1. Start with a Basic Compiler -** The first step is to create a basic compiler that can handle the most essential feature of a programming language. This simple compiler is often written in assembly language or machine language to make it easier to build.

**2. Use the Basic Compiler to Create a More Advanced Version -** Once the basic compiler is ready. It is useful to compile a more advanced version of itself. This new version can handle more complex features like better error-checking and optimizations.

**3. Gradually Improve the Compiler -** Each new version iterates over the last to provide more features making the compiler stronger and efficient.

For example, let's assume a compiler which takes C language as input and generates an assembly language as an output.

1. To generate this compiler we first write a compiler for a small subset of C language i.e. C0 in assembly language. Subset of C means C language with less functionality.

## Cross-Compilation using Bootstrapping

Cross-Compilation is the process where a compiler runs on one platform(host) but generates machine code on another platform(target). This is useful in the cases the target platform isn't powerful enough to run the full compiler or when the target architecture is different from the host system. Using bootstrapping in cross-compilation can help create a compiler that runs one system and produces code on other system.

For example, suppose we want to write a cross compiler for new language X. To create a cross-compiler for a new language X that generates code in language Z, we start by using an existing compiler Y (running on machine M) to compile a simple version of language X into language Z. The first step is to create a basic compiler, XYZ, using Y that translates X code into Z code, all while running on machine M. This results in a cross-compiler XMZ, which is capable of generating target code in language Z for the source code in language X, but it runs on machine M. This method allows us to create a compiler for a new language without needing to run it on the target system directly.

## Advantages

1. **Improved Efficiency:** Bootstrapping makes the development process faster. Once you have a basic compiler, you can use it to create more advanced versions, making the entire process of building a complex compiler much quicker. It’s like building a tool that helps you build better versions of itself.  
    
2. **Portability:** Bootstrapping helps create compilers that can work across different systems. Once you’ve bootstrapped a compiler, it can be used to generate code for various platforms, making it more flexible and portable.  
    
3. **Reduced Dependency:** With bootstrapping, you don’t need to rely on other compilers or external tools. As long as you have a simple starting compiler, you can use it to build more complex versions and handle all your compiling needs. This reduces the need for other software or external dependencies.

> **Initial Effort**: Writing the very first version of the compiler is tough. Before bootstrapping can even begin, you need to create a simple, working compiler from scratch, which requires a lot of time and effort.
