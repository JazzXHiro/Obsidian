# Introduction

## Compiler

It is a software system that translates a given program's language to a computer executable program in another language.
The role of an compiler is also to report errors that it detects during the translation process.

## Interpreter

Interpreters are also a kind of language processors that utilize user input to execute the instructions provided in the source program, instead of creating a target program.

![[Pasted image 20260116213412.png]]

*The machine language target program translated by compiler is much faster than interpreters mapping of inputs and outputs.*
*Interpreters are usually better diagnostics because of their statement by statement execution nature of the source code.*

## Hybrid Compiler

Java language uses a combination of interpreter and compiler. A Java source code may first be compiled into an intermediate form called bytecode and that bytecode can be executed with the help of a virtual machine (***JVM** - which interprets or just-in-time compiles into machine code*) to provide uniform output throughout various systems of various architecture.

![[Pasted image 20260116215016.png]]

*Faster processing of inputs and outputs in Java is achieved via just-in-time(JIT) compilers.*

## Preprocessor

A source program maybe divided into several modules stored in several files. The program that collects the source program from it's various location is called a preprocessor.

*A preprocessor may also expand shorthands, called macros, into source language statements before compilation.*
![[Pasted image 20260116220334.png]]
