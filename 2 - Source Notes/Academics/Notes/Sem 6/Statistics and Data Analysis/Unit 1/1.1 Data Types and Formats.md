# Data Types and Formats

## Types of Data

### 1. Structured Data

Data that is **organized in a fixed format**, usually in tables.

**Characteristics**

- Rows and columns

- Easy to store in databases

**Examples**

- SQL database tables

- Excel sheets

- CSV files

### 2. Unstructured Data

Data that **does not have any predefined structure**.

**Examples:** Images, Audio, Videos, Emails, Text documents, Social media posts etc.

### 3. Semi-structured Data

**Semi-structured data** is data that **does not follow a strict table format like relational databases but still contains some organizational structure using tags, keys, or markers.**

#### Characteristics

1. **No fixed schema** (unlike relational tables).

2. **Self-describing structure** using tags or key-value pairs.

3. **Flexible format** — fields can vary between records.

4. Often used in **web and data exchange formats**.

**Examples:** JSON APIs, logs etc.


> [!NOTE] Data Types based on Nature
> - **Qualitative:** Qualitative data refers to non-numerical data that describes qualities or characteristics.
> - **Quantitative:** **Quantitative data** refers to **numerical data that can be measured or counted**.  
It represents quantities and can be analyzed using mathematical or statistical methods.
