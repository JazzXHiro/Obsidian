# Statistics

## What is statistics?

Statistics is the science of:
- Collecting data
- Organizing data
- Analyzing data
- Interpreting results for decision making

In software systems, we rarely have complete data. Instead of perfect information, we work with partial logs, sample user data, noisy sensor readings etc. Statistics allows us to make reliable decisions despite uncertainity.

## Descriptive vs Inferential Statistics

Descriptive statistics answers:
- What is happening in the system?
- What does the data look like?

Common tools:
- Mean, m
