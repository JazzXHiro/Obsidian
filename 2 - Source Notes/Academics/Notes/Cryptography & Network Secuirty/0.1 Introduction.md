# 0.1 Introduction

- **When was Cryptography first used?**
		As early as Hieroglyphics

- ##### 🔐 What is a Scytale?

	A **Scytale** is a **cylindrical tool** used to perform a **transposition cipher**, which rearranges the letters of a message rather than substituting them.
	
	###### 🧠 How it Works:
	
	1. **Sender and receiver** both have identical **cylinders (rods) of the same diameter**.
	    
	2. The sender wraps a strip of parchment or leather (called a **ribbon**) around the cylinder.
	    
	3. The message is written across the **length** of the cylinder.
	    
	4. Once unwrapped, the letters appear **scrambled** and **illegible**.
	    
	5. To **decode**, the receiver wraps the ribbon around their own scytale and reads the message across the lines.
