# Maths LaTex

### To enter maths window-
Alt + M

### Latex Cheatsheet for the plugin-
#### pmat - for matrix
1. Tab(&) - for new element in same line
2. Enter() - for new line
3. Shift + Enter - for exiting the matrix

#### Spacing and text-

- `\;` adds a small amount of space.
- `\quad` adds more space.
- Using `\text{for}` ensures that "for" appears in regular text font.
- To align a text to the left(&& makes sure content aligns on the left side)
            `\begin{flalign*}`
            `\text{where c is a constant.} &&`
            `\end{flalign*}` 

#### Comparison Operators-
- $\ne$ $\rightarrow$ `ne`
#### Number System Symbolics-
- $\mathbb{R}$ $\rightarrow$ `\mathbb{R}`

#### Maths Variables-
- $\theta \rightarrow$ \theta
