# Witaj

The Polish word **„Witaj”** (meaning **“Welcome”** or **“Hello”** in an informal/friendly way) is pronounced:

### **IPA:** /ˈvi.taj/

### **Breakdown:**

- **w** → pronounced like English **v**
- **i** → like **ee** in _see_
- **t** → like English **t**
- **a** → like **a** in _father_
- **j** → pronounced like English **y** in _yes_

### **Approximate English pronunciation:**

**“VEE-tie”**  
(rhymes with _be-tie_)
