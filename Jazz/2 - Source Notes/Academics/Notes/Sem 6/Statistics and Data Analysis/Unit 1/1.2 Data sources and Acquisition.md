# Data sources and Acquisition

## Data Collection

If data is poorly collected, incomplete or biased, the statistical analysis will be misleading.

In software systems and games, data is generated continuously. Understanding where
data comes from and how it is captured is essential for meaningful analysis.

## Types of Data Sources

### 1. Primary Data Sources

Primary Data is collected directly by the researcher.

Examples:

- Surveys

- Interviews

- Experiments

**Advantages:**

• Data is relevant and customized 
• Higher control over quality

**Disadvantages:**

• Time-consuming 
• Expensive at scale

### 2. Secondary Data Sources

Secondary data already exists and is reused.

Examples:

- Government datasets

- Research papers

- Public databases
