# Routing Protocols

## Routing
Routing is the process of selecting a path for traffic in a network or between or across multiple networks. It is done so via Routing tables.
### **Functions of Routing**

- **Path determination**: Deciding the best route for data.
    
- **Packet forwarding**: Moving packets from the source toward the destination.
    
- **Network traffic management**: Balancing the load across the network.

### **Types of Routing**

| Type                | Description                                                          |
| ------------------- | -------------------------------------------------------------------- |
| **Static Routing**  | Manually configured routes; does not change unless manually updated. |
| **Dynamic Routing** | Uses routing algorithms to automatically update routes.              |
| **Default Routing** | Used when there is only one route to reach all other networks.       |

## 🌐 Interior and Exterior Gateway Protocols

---

### 📌 **1. What are Gateway Protocols?**

Gateway protocols are **routing protocols** used to exchange routing information between routers.  
They are categorized into:

- **Interior Gateway Protocols (IGPs)** – Used **within** an Autonomous System (AS)
    
- **Exterior Gateway Protocols (EGPs)** – Used **between** Autonomous Systems
    

---

## 🏠 **2. Interior Gateway Protocols (IGPs)**

- Operate **inside a single AS**
    
- Focus on **fast convergence and scalability**
    
- Examples: **RIP, OSPF, EIGRP, IS-IS**
    

### 🧩 **Types of IGPs:**

| Protocol  | Type            | Description                                                  |
| --------- | --------------- | ------------------------------------------------------------ |
| **RIP**   | Distance Vector | Uses hop count; max 15 hops; slow convergence                |
| **OSPF**  | Link State      | Uses Dijkstra’s algorithm; fast and scalable                 |
| **EIGRP** | Hybrid (Cisco)  | Combines distance vector and link state; uses DUAL algorithm |


---

## 🌍 **3. Exterior Gateway Protocols (EGPs)**

- Operate **between different ASes**
    
- Used for **inter-domain routing** (e.g., Internet)
    
- Most common protocol: **BGP (Border Gateway Protocol)**
    

### 🔄 **BGP (Border Gateway Protocol)**

- **Type**: Path Vector Protocol
    
- **Used by** ISPs and large organizations
    
- **Function**: Exchanges routing info between ASes
    
- **Metric**: Based on policy, path, and rule preferences (not just hop count)
    
- **Supports** classless routing and CIDR
    

---

### ⚖️ **4. Comparison: IGP vs EGP**

|Feature|IGP (Interior Gateway Protocol)|EGP (Exterior Gateway Protocol)|
|---|---|---|
|Scope|Within an AS|Between ASes|
|Convergence Speed|Fast|Slower|
|Complexity|Simpler|More complex|
|Examples|RIP, OSPF, EIGRP, IS-IS|BGP|
|Metric|Hop count, cost, delay|Path attributes, policy|

---

### 📝 **5. Autonomous System (AS)**

- A **collection of networks** under a single administrative control.
    
- Identified by an **AS Number (ASN)**.
    
- ASes use IGP internally and EGP to communicate with other ASes.
    
---

### **4. Routing Algorithms**

#### a) **Distance Vector Routing**

- Routers share info with neighbors periodically.
    
- Uses **Bellman-Ford Algorithm**.
    
- Examples: **RIP**.
    
- Cons: Slow convergence, routing loops.
    

#### b) **Link State Routing**

- Routers know full network topology.
    
- Uses **Dijkstra’s Algorithm**.
    
- Examples: **OSPF**.
    
- Faster convergence, more accurate.
    

#### c) **Hybrid Routing**

- Combines distance vector and link state features.
    
- Example: **EIGRP (Cisco proprietary)**.
