# TCP

![[Pasted image 20250513072347.png]]

- **Byte Streaming -** The data received from the application layer is segmented into bytes.
- **Connection Oriented** - Reliability
- **Full Duplex -** Both Sender and receiver can send data to each other simultaneously
- **Piggybacking -** When acknowledgment is being sent from receiver to sender, data can also be sent alongside with it. Uses Go-back-N & Selective Repeat
- **Error Control**
- **Flow Control**
- **Congestion Control**

PSH - often data is stored in buffer before being sent to the application and before sending the data accumulates until completion and is then sent, but at times the data is needed immediately so we use push.

Window Size - whenever a sender/reciever sends the data, it also sends it window capacity along with it.

MSS - Maximum Segment Size(resides in Optional and Padding)
