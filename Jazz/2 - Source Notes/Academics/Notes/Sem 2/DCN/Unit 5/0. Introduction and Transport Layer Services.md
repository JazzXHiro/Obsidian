# Introduction and Transport Layer Services


### 📌 **1. What is the Transport Layer?**

The **Transport Layer** is **Layer 4** of the **OSI model** and **TCP/IP model**, responsible for **end-to-end communication** between devices.

It ensures that data is **delivered accurately, in order**, and **without loss or duplication**.

---

### 🎯 **2. Key Responsibilities of the Transport Layer**

| Responsibility                         | Description                                                                                                     |
| -------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| **1. Process-to-Process Delivery**     | Transfers data from the application on one device to the correct application on another using **port numbers**. |
| **2. Segmentation and Reassembly**     | Breaks large data into **smaller segments** and reassembles them at the destination.                            |
| **3. Connection Control**              | Supports both **connection-oriented (TCP)** and **connectionless (UDP)** communication.                         |
| **4. Flow Control**                    | Prevents the sender from overwhelming the receiver. Example: **Sliding Window** protocol.                       |
| **5. Error Control**                   | Ensures reliable delivery using error detection, retransmission, and acknowledgment.                            |
| **6. Congestion Control**              | Manages traffic load to avoid congestion in the network. (e.g., TCP Congestion Control)                         |
| **7. Multiplexing and Demultiplexing** | Combining the singals from different applications into one is Multiplexing.<br>Reverse is Demultiplexing        |

---

### 🔁 **3. Transport Layer Protocols**

|Protocol|Type|Description|
|---|---|---|
|**TCP**|Connection-oriented|Reliable, ordered delivery with flow & error control|
|**UDP**|Connectionless|Fast, no guarantee of delivery (used in streaming, DNS)|

---

### 🧩 **4. Port Numbers**

Used to **identify specific applications/services** on a device.

|Port Range|Purpose|
|---|---|
|0 – 1023|Well-known ports (e.g., HTTP - 80, FTP - 21)|
|1024 – 49151|Registered ports|
|49152 – 65535|Dynamic/private ports|

---

### 🔄 **5. Transport Layer in OSI vs TCP/IP Models**

|OSI Model|TCP/IP Model|
|---|---|
|Layer 4|Transport Layer|
|Provides|End-to-end communication, reliability, segmentation|

---

### ✅ **6. Summary**

- The **Transport Layer** ensures **reliable** and **accurate delivery** of data.
    
- It enables **process-level communication** using **port numbers**.
    
- Two major protocols: **TCP** (reliable) and **UDP** (unreliable but faster).
    
- Important for **flow, error, and congestion control**.
