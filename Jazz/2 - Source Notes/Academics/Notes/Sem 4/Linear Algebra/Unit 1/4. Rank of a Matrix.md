# Rank of a Matrix
It is the order of highest order non-zero minor of A. It is denoted by $rank(A)$ or $ρ(A)$ or $r(A)$.
In other words, for a given matrix $A_{n*n}$ , $ρ(A) = r$, $r<n$, then,

1. All the minors of A of order higher than r, i.e.,
   $(r+1), (r+2),\dots,n$ will be zero.
2. And there exists atleast one non-zero minor of order n.
   
**Also,** 
The **rank** of a matrix is the **maximum number of linearly independent rows or columns** in the matrix. It represents the **dimension of the column space (or row space)** of the matrix.

i.e. non-zero meaning determinant of each minor of that order is non-zero.

**NOTE:**
- $ρ(A_{m*n}) \leq min{(m,n)}$ where $m \neq n$

- Rank of a null matrix is defined to be zero.

- Let $A_{m*n}$ be a non-zero matrix, then, $ρ(A) \geq 1.$

- $ρ(A)= ρ(A^{T})= ρ(AA^{T})$

- Null matrix is the only matrix which has rank zero.

- Rank of a matrix in which every element is unity is 1.

- A matrix $A_{n*n}$ is a non singular. Then rank(A) = n.

- A matrix $A_{n*n}$ is a singular iff $rank(A) < n$.
  

	- $n(A) \text{ is refered to as nullity of a matrix, basically it is the number of zero rows}$
	- $\text{Sum of Rank of a matrix ρ(A) and nullity of a matrix n(A) = order of the matrix}$ (Only for square matrix)
