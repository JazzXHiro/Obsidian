# Operations on Matrices

Matrix operations are fundamental in linear algebra. Below are the most common operations on matrices, along with their properties:

### 1. **Matrix Addition**

Matrix addition involves adding two matrices of the same dimension by adding their corresponding elements. If $A$ and $B$ are two matrices of the same size, the sum $C=A+B$ is given by:

$$C_{ij}=A_{ij}+B_{ij}$$

#### Properties of Matrix Addition:

- **Commutative**: $A+B=B+A$
- **Associative**: $(A+B)+C=A+(B+C)$
- **Additive Identity**: There exists a zero matrix 0 such that $A+0=A$ for any matrix $A$.
- **Additive Inverse**: For any matrix $A$, there exists a matrix $−A$ such that $A + (−A)=0$.

### 2. **Matrix Scalar Multiplication**

Scalar multiplication involves multiplying a matrix by a scalar (a real number). If A is a matrix and $k$ is a scalar, the matrix $kA$ is obtained by multiplying each element of $A$ by $k$:

$$(kA)_{ij}=k⋅A_{ij}$$

#### Properties of Scalar Multiplication:

- **Distributive over Matrix Addition**: $k(A+B)=kA+kB$
- **Distributive over Scalar Addition**: $(k+m)A=kA+mA$
- **Associative**: $k(mA)=(km)A$
- **Multiplying by 1**: $1⋅A=A$
- **Multiplying by 0**: $0⋅A=0$(the zero matrix)

### 3. **Matrix Multiplication**

Matrix multiplication involves multiplying two matrices, where the number of columns of the first matrix must be equal to the number of rows of the second matrix. If $A$ is an $m×n$ matrix and B is an $n \times p$ matrix, the product matrix $C=AB$ is an $m \times p$ matrix, and each element of $C$ is computed as:

$$C_{ij}= \sum_{}^{} A_{ik} \cdot B_{kj}$$

#### Properties of Matrix Multiplication:

- **Associative**: $A(BC)=(AB)C$
- **Distributive over Matrix Addition**: $A(B+C)=AB+AC$ and $(A+B)C=AC+BC$
- **Not Commutative**: In general, $AB≠BA$
- **Multiplying by the Identity Matrix**: $AI=A$ and $IA=A$ (where II is the identity matrix of appropriate size)
- **Multiplying by Zero Matrix**: $A \cdot 0 = 0$ and $0 \cdot A = 0$

### 4. **Matrix Transposition**

The transpose of a matrix $A$ is denoted by $A^T$ and is obtained by swapping the rows and columns of $A$. If $A = \begin{pmatrix} a & b \\ c & d \end{pmatrix}$, then:

$$A^T = \begin{pmatrix} a & c \\ b & d \end{pmatrix}$$

#### Properties of Transposition:

- **Double Transpose**: $(A^T)^T = A$
- **Transpose of a Sum**: $(A + B)^T = A^T + B^T$
- **Transpose of a Scalar Multiple**: $(kA)^T = kA^T$
- **Transpose of a Product**: $(AB)^T = B^T A^T$

### 5. **Matrix Inversion**

A square matrix $A$ has an inverse (denoted $A^{-1}$) if and only if $A$ is non-singular (i.e., $\text{det}(A) \neq 0$). The inverse of $A$ satisfies:

$$A A^{-1} = A^{-1} A = I$$

where $I$ is the identity matrix.

#### Properties of Matrix Inversion:

- **Inverse of a Product**: $(AB)^{-1} = B^{-1} A^{-1}$
- **Inverse of a Scalar Multiple**: $(kA)^{-1} = \frac{1}{k} A^{-1} (\text{for} \; k \ne 0)$
- **Double Inverse**: $(A^{-1})^{-1} = A$
- **Identity Matrix Inverse**: $I^{-1} = I$

### 6. **Determinant**

The determinant is a scalar value associated with a square matrix. It can be calculated from the elements of the matrix and provides important information about the matrix, such as whether it is invertible (a matrix is invertible if and only if its determinant is non-zero).

#### Properties of Determinants:

- **Determinant of a Product**: $\text{det}(AB) = \text{det}(A) \cdot \text{det}(B)$
- **Determinant of a Scalar Multiple**: $\text{det}(kA) = k^n \cdot \text{det}(A)$, where $n$ is the size of the matrix.
- **Determinant of the Transpose**: $\text{det}(A^T) = \text{det}(A)$
- **Determinant of the Identity Matrix**: $\text{det}(I) = 1$
- **Determinant of a Singular Matrix**: If $A$ is singular, $\text{det}(A) = 0$

### 7. **Rank of a Matrix**

The rank of a matrix is the maximum number of linearly independent rows or columns in the matrix. It is an important concept in determining the solvability of linear systems and the properties of the matrix.

#### Properties of Matrix Rank:

- **Rank of a Product**: $\text{rank}(AB) \leq \min(\text{rank}(A), \text{rank}(B))$
- **Rank of a Transpose**: $\text{rank}(A^T) = \text{rank}(A)$
- **Rank of an Invertible Matrix**: If $A$ is invertible, $\text{rank}(A) = n$, where $A$ is an $n \times n$ matrix.
