# Testing Tools

# Static Test Tools

- **Purpose**: Analyze code without executing the software (input/output not required).  

## Types:  
- **Flow Analyzers**: Track data flow from input to output.  
- **Path Tests**: Identify unused or inconsistent code.  
- **Coverage Analyzers**: Ensure all logical paths are tested.  
- **Interface Analyzers**: Verify variable/data passing between modules.

# Dynamic Test Tools

- **Purpose**: Test software execution with real/current data.  

## Types:  
- **Test Driver**: Supplies input data to the module-under-test (MUT).  
- **Test Beds**: Displays source code during program execution.  
- **Emulators**: Mimic undeveloped system parts for testing.  
- **Mutation Analyzers**: Assess fault tolerance by intentionally injecting code errors.

## Some Popular Testing Tools-

### 1. Jira (Test Management & Issue Tracking)

#### What is Jira?  
A widely-used tool for test management and bug tracking in **Agile/DevOps** environments.  

#### Key Features:  
- **Bug & Issue Tracking**: Log and monitor software defects.  
- **Test Case Management**: Via plugins (Xray, Zephyr).  
- **Agile Boards**: Scrum/Kanban for sprint planning.  
- **Custom Workflows**: Define test cycles and resolution steps.  

#### Testing Use Cases:  
- Document/link test cases to user stories.  
- Log and assign bugs to developers.  
- Manage test cycles and defect reporting.

### 2. Selenium (Automation Testing)

#### What is Selenium?  
A leading **web application** automation testing tool.  

#### Components:  
- **WebDriver**: Automates browser actions.  
- **Grid**: Parallel testing across machines/browsers.  
- **IDE**: Record-and-playback for simple tests.  

#### Use Cases:  
- UI testing automation.  
- Cross-browser testing (Chrome, Firefox, Edge).  
- Data-driven tests (via TestNG/JUnit).

### 3. JUnit (Unit Testing in Java)

#### What is JUnit?  
A Java framework for **unit testing** individual software components.  

#### Key Features:  
- **Annotations**: `@Test`, `@BeforeEach`, `@AfterEach`.  
- **Assertions**: Validate expected vs. actual results.  
- **Parameterized Tests**: Run multiple test cases.  
- **Test Suites**: Execute multiple tests together.
