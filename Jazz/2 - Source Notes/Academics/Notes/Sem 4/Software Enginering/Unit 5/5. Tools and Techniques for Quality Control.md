## Example: Quality Tools in Software Companies (e.g., Wipro, Infosys)  

- **Check Sheet**: Track bug types during testing.  
- **Pareto Chart**: Identify high-defect modules.  
- **Cause-and-Effect Diagram**: Analyze project delays.  
- **Histogram**: Visualize task completion time distribution.  
- **Scatter Diagram**: Correlate developer experience with bug rates.  
- **Flow Chart**: Document SDLC processes.  
- **Control Charts**: Monitor code complexity/defect density trends.
