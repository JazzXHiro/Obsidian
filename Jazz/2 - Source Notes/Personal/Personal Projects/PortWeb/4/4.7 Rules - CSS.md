# Rules - CSS

## 🧠 What Is a CSS Rule?

A **CSS rule** has **two main parts**:

```
selector {
  property: value;
}
```

This reads as:

> “Select these elements and apply these styles to them.”

---

## 🔍 Anatomy of a CSS Rule (Line by Line)

### Example

```css
.nav__link {
  color: white;
  font-size: 1rem;
}
```

### 1️⃣ Selector

```css
.nav__link
```

- Decides **which HTML elements** the rule applies to
    
- Can target:
    
    - Tags (`p`, `div`)
        
    - Classes (`.nav__link`)
        
    - IDs (`#header`)
        
    - States (`:hover`)
        
    - Pseudo-elements (`::after`)
        

---

### 2️⃣ Declaration Block

```css
{
  color: white;
  font-size: 1rem;
}
```

Everything inside `{ }` is the **declaration block**.

---

### 3️⃣ Declarations

Each line inside is a **declaration**.

```css
color: white;
```

A declaration has:

- **Property** → what you’re styling (`color`)
    
- **Value** → how you’re styling it (`white`)
    
- Ends with a **semicolon `;`**
    

---

## 🧩 One Rule = Many Declarations

```css
.card {
  background-color: black;
  padding: 1rem;
  border-radius: 0.5rem;
}
```

- One selector
    
- Multiple declarations
    
- All apply to the same elements
    

---

## 🧠 Types of CSS Rules (Very Important)

### 1️⃣ Style Rules (Most Common)

```css
p {
  color: red;
}
```

Used to style elements.

---

### 2️⃣ At-Rules (Start with `@`)

Special rules that control behavior or conditions.

Examples:

#### Media query

```css
@media (max-width: 768px) {
  body {
    background: black;
  }
}
```

#### Font-face

```css
@font-face {
  font-family: "MyFont";
  src: url(font.woff2);
}
```

#### Keyframes (animations)

```css
@keyframes fade {
  from { opacity: 0; }
  to { opacity: 1; }
}
```

---

### 3️⃣ Nested Rules (Conceptually)

CSS itself doesn’t support nesting everywhere yet, but logically:

```css
.nav__menu a {
  color: white;
}
```

This is still **one rule**:

- Selector: `.nav__menu a`
    
- Declaration: `color: white`
    

---

## 🧠 How Browsers Apply Rules

1. Browser reads HTML
    
2. Browser reads CSS rules
    
3. For each element:
    
    - Find matching selectors
        
    - Resolve conflicts using the **cascade**
        
    - Apply final styles

If two rules conflict → **cascade order decides**.

---

## ⚠️ Important Details (Common Exam Traps)

- Semicolons are required (except last one is optional, but recommended)
    
- Property names are **case-insensitive**
    
- Values can be:
    
    - Keywords (`red`)
        
    - Numbers (`16px`)
        
    - Functions (`hsl()`, `var()`)

---

## 🧠 Minimal Rule Example (Complete)

```css
h1 {
  color: blue;
}
```

- `h1` → selector
    
- `color` → property
    
- `blue` → value
    
- Entire thing → **one CSS rule**
    

---

## 🎯 Interview-Ready Definition

> “A CSS rule consists of a selector and a declaration block that defines the styles to be applied to the selected elements.”
