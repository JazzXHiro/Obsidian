# 1.8 Script

## 🧠 The Line

```html
<script src="https://cdnjs.cloudflare.com/ajax/libs/scrollReveal.js/4.0.9/scrollreveal.min.js"></script>
```

---

## 1️⃣ `<script> ... </script>` — The Element

### 🔹 What `<script>` Does

The `<script>` tag is used to **load and execute JavaScript** in your webpage.

It can:

- Run inline JavaScript
    
- Load JavaScript from an external file
    

In this case → **external file**.

---

## 2️⃣ `src="..."` — Source Attribute

### 🔹 What `src` Means

`src` specifies **where the JavaScript file is located**.

```text
https://cdnjs.cloudflare.com/...
```

This is a **CDN URL** (Content Delivery Network).

Instead of:

```html
<script src="assets/js/scrollreveal.js"></script>
```

You’re saying:

> “Load this JS file from the internet.”

---

## 3️⃣ What Is This Library?

This line loads **ScrollReveal**.

ScrollReveal is a lightweight JS library that:

- Animates elements when they **enter the viewport**
    
- Creates smooth **scroll-based reveal effects**
    
- Requires **zero CSS animation code**
    

Typical effects:

- Fade in
    
- Slide up
    
- Zoom
    
- Delay / stagger animations

## 4️⃣ Breaking Down the URL (Important)

```text
cdnjs.cloudflare.com
```

➡ CDN provider (Cloudflare CDN)

```text
/ajax/libs/
```

➡ Library directory

```text
/scrollReveal.js/
```

➡ Library name

```text
/4.0.9/
```

➡ Exact version number

```text
/scrollreveal.min.js
```

➡ Minified JavaScript file

---

## 5️⃣ What Does “min.js” Mean?

`scrollreveal.min.js` is:

- Compressed
    
- Whitespace removed
    
- Variable names shortened
    

Purpose:  
✔ Faster download  
✔ Better performance

Functionality is **identical** to the normal version.

---

## 6️⃣ What Happens When the Browser Loads This?

### Step-by-step:

1. Browser reaches `<script>`
    
2. Downloads JS file from CDN
    
3. Executes it immediately
    
4. Exposes `ScrollReveal` globally
    

Now you can use it in your own JS:

```js
ScrollReveal().reveal('.section', {
  delay: 200,
  distance: '50px'
});
```

---

## 7️⃣ Why This Script Is Usually Placed at the Bottom

If placed at the end of `<body>`:

- HTML loads first
    
- JS runs after elements exist
    
- Prevents errors like “element not found”
    

Bad:

```html
<script>JS runs before HTML exists</script>
```

Good:

```html
</body>
<script src="..."></script>
```

---

## ❌ What This Script Tag Is NOT

- ❌ It is not HTML
    
- ❌ It does not add styles directly
    
- ❌ It does not animate anything by itself
    
- ❌ It does not affect SEO directly
    

It only **adds a JS API** you must explicitly use.
