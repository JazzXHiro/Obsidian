# Title

## 🧠 What `<title>` Is

```html
<title>My Portfolio</title>
```

The `<title>` element defines the **title of the webpage**.

It is **not shown inside the webpage content**.  
It lives inside the `<head>` section.

---

## 📍 Where the Title Appears

![Image](https://design.innovaccer.com/static/3b3bf471415296dbc315a896b54fab15/3cbba/intro-image.png)

![Image](https://i.sstatic.net/q2PdI.jpg)

The text inside `<title>` is displayed in:

1. **Browser tab**
    
2. **Search engine results (SEO)**
    
3. **Bookmarks / history**
    
4. **Tab switchers / task view**
    

So even though users don’t _see_ it on the page, they **interact with it constantly**.

---

## 🔍 What `<title>` Does Technically

- Helps browsers identify the page
    
- Helps search engines understand page topic
    
- Helps users distinguish tabs
    

Think of it as:

> **The page’s official name**

---

## 🧠 Why It Matters (Very Important)

### 1️⃣ SEO (Search Engine Optimization)

Search engines use the `<title>` as a **primary ranking signal**.

Good:

```html
<title>Ishu Yadav | CS Student Portfolio</title>
```

Bad:

```html
<title>Home</title>
```

---

### 2️⃣ User Experience

If someone opens 10 tabs:

```
Home | Home | Home | Home ❌
```

vs

```
Portfolio | Projects | Resume ✔
```

---

### 3️⃣ Accessibility

Screen readers announce the `<title>` when the page loads.

---

## 🧪 Rules for `<title>`

- Must be **inside `<head>`**
    
- Only **one** per document
    
- Text-only (no HTML inside)
    
- Recommended length: **50–60 characters**
    

---

## ❌ What `<title>` Is NOT

- ❌ It is not a heading (`<h1>`)
    
- ❌ It does not style text
    
- ❌ It does not appear in the page body
    

---

## 🧠 Interview-Ready Answer

> “The title tag defines the page’s title, which appears in the browser tab and search engine results and is critical for SEO and accessibility.”

Perfect.

---

## ✅ Best Practice for Your Portfolio

Instead of:

```html
<title>My Portfolio</title>
```

Use:

```html
<title>Ishu Yadav | Computer Science Portfolio</title>
```

Or for projects page:

```html
<title>Projects | Ishu Yadav</title>
```

---

## 🧠 Final Insight

> If the `<h1>` is for humans on the page,  
> the `<title>` is for browsers, search engines, and tab management.
