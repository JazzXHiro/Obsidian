# Code Snippet - CSS

```css
.contact__input::placeholder{

  color: var(--gray-color);

  transition: color .4s;

}
```

## **Explanation**

`::placeholder` is a **pseudo-element** that styles the placeholder text inside input fields.

### What is a placeholder?

The placeholder is the hint text that appears inside an input field before the user types:

```html
<input type="text" placeholder="Enter your name">
```

```
┌─────────────────────────────┐
│ Enter your name             │  ← This gray text is the placeholder
└─────────────────────────────┘
```

### What is `::` (double colon)?

`::` indicates a **pseudo-element** — it targets a part of an element, not the element itself.

| `:`  | `::`  |
|------|-------|
| Pseudo-class (state) | Pseudo-element (part) |
| `:hover`, `:focus` | `::placeholder`, `::before`, `::after` |
| Describes a condition | Targets specific content |

### In your code:

```css
.contact__input::placeholder {
  color: var(--gray-color);      /* Placeholder appears gray */
  transition: color .4s;         /* Smooth color change */
}
```

This makes the hint text inside the input field **gray and transitions smoothly** when you focus on it.

**Other common pseudo-elements:**
- `::before` — adds content before an element
- `::after` — adds content after an element
- `::first-line` — styles first line of text
- `::selection` — styles highlighted text
