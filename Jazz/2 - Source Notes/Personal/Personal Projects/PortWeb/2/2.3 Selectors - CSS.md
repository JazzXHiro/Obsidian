# 2.3 Selectors - CSS

A **selector** is simply **the part of CSS that chooses _which HTML elements_ the styles will apply to**.

Think of it as the **target**.

---

## 🧠 Definition (Interview-Ready)

> **A CSS selector is a pattern used to select one or more HTML elements so that styles can be applied to them.**

---

## 🔍 Example From Your Code

```css
.header {
  position: fixed;
}
```

### Here:

- `.header` → **selector**
    
- `{ ... }` → styles applied to what the selector selects
    

This selector targets:

```html
<header class="header"></header>
```

---

## 🧩 How Selectors Work (Conceptually)

```
Selector  →  finds elements in the DOM
Rules     →  applied to those elements
```

CSS reads it as:

> “Find all elements matching this selector, then apply these styles.”

---

## 🔹 Common Types of Selectors

### 1️⃣ **Element (Tag) Selector**

Targets all elements of a type.

```css
p {
  color: red;
}
```

Targets:

```html
<p>All paragraphs</p>
```

---

### 2️⃣ **Class Selector** (Most Common)

Uses a dot `.`

```css
.header {
  background: black;
}
```

Targets:

```html
<div class="header"></div>
```

✔ Reusable  
✔ Best for styling

---

### 3️⃣ **ID Selector**

Uses `#`

```css
#nav-menu {
  display: flex;
}
```

Targets:

```html
<div id="nav-menu"></div>
```

⚠️ Must be unique  
⚠️ Mostly used for JavaScript, not styling

---

### 4️⃣ **Universal Selector**

Targets _everything_

```css
* {
  margin: 0;
}
```

Used for resets.

---

### 5️⃣ **Descendant Selector**

Targets elements _inside_ others.

```css
.nav a {
  color: white;
}
```

Targets:

```html
<a> inside .nav</a>
```

---

### 6️⃣ **Multiple Selectors**

Same styles for many targets.

```css
h1, h2, h3 {
  font-weight: bold;
}
```

---

## 🧠 Selector vs Property vs Value

```css
.header {
  position: fixed;
}
```

|Part|Name|
|---|---|
|`.header`|Selector|
|`position`|Property|
|`fixed`|Value|

This distinction matters in exams/interviews.

---

## 🎯 Why Selectors Matter

Good selectors mean:

- Cleaner CSS
    
- Better performance
    
- Easier maintenance
    
- Fewer bugs
    

Bad selectors = messy, fragile CSS.

---

## 🧠 One-Line Rule to Remember

> **Selectors decide _where_ styles go; properties decide _what_ styles do.**
