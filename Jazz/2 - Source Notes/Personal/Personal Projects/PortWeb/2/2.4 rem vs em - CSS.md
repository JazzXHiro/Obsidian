# 2.4 rem vs em - CSS

This is a **core CSS concept** and interview favorite. Let’s clear it up **once and for all**.

---

# 🧠 `rem` vs `em` — What’s the Difference?

Both are **relative CSS units**.  
The key difference is **what they are relative to**.

---

## 🔹 `rem` — _Root EM_

### Definition

> `rem` is relative to the **root (`<html>`) font size**.

By default:

```css
html {
  font-size: 16px;
}
```

So:

```
1rem = 16px
2rem = 32px
0.5rem = 8px
```

### Example

```css
h1 {
  font-size: 2rem; /* always 32px */
}
```

✔ Predictable  
✔ Consistent  
✔ Easy to scale whole site

---

## 🔹 `em` — _Element EM_

### Definition

> `em` is relative to the **font-size of the parent element**.

### Example

```css
.parent {
  font-size: 20px;
}

.child {
  font-size: 1.5em; /* 30px */
}
```

Here:

```
1em = parent’s font-size
```

---

## ⚠️ The Big Gotcha with `em` (Nesting)

```css
.parent {
  font-size: 1.5em;
}

.child {
  font-size: 1.5em;
}
```

If base = 16px:

```
parent = 24px
child  = 36px 😵
```

This is called **compounding**.

---

## 🆚 Side-by-Side Comparison

|Feature|`rem`|`em`|
|---|---|---|
|Relative to|Root (`html`)|Parent element|
|Affected by nesting|❌ No|✅ Yes|
|Predictability|✅ High|❌ Can get messy|
|Best for|Layout, spacing, typography|Component-level scaling|
|Beginner-friendly|✅ Yes|⚠️ Risky|

---

## 🧠 When to Use WHAT (Very Important)

### ✅ Use `rem` for:

- Font sizes
    
- Margins & padding
    
- Layout spacing
    
- Heights like headers
    

Example:

```css
.header {
  height: 3.5rem;
}
```

This is exactly what you saw in your code:

```css
--header-height: 3.5rem;
```

✔ Stable across the whole site

---

### ✅ Use `em` for:

- Buttons
    
- Icons
    
- Components that scale with text
    

Example:

```css
.button {
  padding: 0.5em 1em;
}
```

If text size increases → button scales naturally.

---

## 🧠 Why Modern CSS Prefers `rem`

Because:

- One root change scales everything
    
- No surprise nesting bugs
    
- Easier dark mode & accessibility scaling
    

Example:

```css
html {
  font-size: 18px; /* accessibility zoom */
}
```

Entire site scales instantly.

---

## 🎯 Interview-Ready Answers

### Short

> “`rem` is relative to the root font size, while `em` is relative to the parent element’s font size.”

### Better

> “`rem` provides consistent sizing across the site, whereas `em` allows component-level scaling but can compound with nesting.”

---

## 🧠 One-Line Rule (Memorize This)

> **Use `rem` for consistency, `em` for scalability.**
