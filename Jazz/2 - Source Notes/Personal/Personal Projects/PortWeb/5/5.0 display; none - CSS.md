# display; none - CSS

`display: none;` **completely removes an element from the page layout**.

## 🧠 What `display: none;` Does

```css
.element {
  display: none;
}
```

This tells the browser:

> **“Pretend this element does not exist.”**

Effects:

- ❌ Element is **not visible**
    
- ❌ Element takes **no space**
    
- ❌ Element is **removed from layout flow**
    
- ❌ Child elements are also removed
    
- ❌ Cannot be interacted with (click, hover, focus)
    

---

## 🔍 Before vs After

### HTML

```html
<div class="box">Hello</div>
<p>World</p>
```

### Without `display: none`

```
[ Hello ]
[ World ]
```

### With `display: none`

```css
.box { display: none; }
```

```
[ World ]
```

The `div` is **gone**.

---

## 🧩 Important: Layout Impact

Because it’s removed from layout:

- Other elements **move up**
    
- Space collapses completely
    

This is why menus “snap” when toggled with `display: none`.

---

## 🆚 `display: none` vs `visibility: hidden`

|Property|Visible|Takes space|Interactive|
|---|---|---|---|
|`display: none`|❌|❌|❌|
|`visibility: hidden`|❌|✅|❌|

Example:

```css
visibility: hidden;
```

→ Invisible, but space is still reserved.

---

## 🧠 Why `display: none` Is NOT Used for Animations

You **cannot animate** `display`.

❌ This won’t animate:

```css
display: none → display: block;
```

That’s why menus are often hidden like this instead:

```css
position: fixed;
top: -100%;
```

Then animated with `transition`.

---

## 🔁 JavaScript Interaction

```js
element.style.display = "none";  // hide
element.style.display = "block"; // show
```

But modern best practice:

```js
element.classList.add("hidden");
```

```css
.hidden {
  display: none;
}
```

---

## ⚠️ Accessibility Note (Important)

Elements with `display: none`:

- Are **not read by screen readers**
    
- Are **not focusable**

This is good for:

- Modals (when closed)
    
- Menus (when hidden)

But bad for:

- Content you want screen readers to access

---

## 🎯 Interview-Ready Explanation

> “`display: none` removes an element from the document flow so it is not rendered, does not occupy space, and cannot be interacted with.”
