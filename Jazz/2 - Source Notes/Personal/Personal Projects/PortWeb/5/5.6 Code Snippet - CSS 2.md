# Code Snippet - CSS 2

---

## 🧠 The Code

```css
/* For medium devices */
@media screen and (min-width: 540px){
  .home__container{
    grid-template-columns: 400px;
    justify-content: center;
  }
}
```

---

## 1️⃣ `@media screen and (min-width: 540px)`

### What this targets

> Screens that are **540px wide or larger**

Typical devices:

- Large phones (landscape)
    
- Small tablets
    
- Small laptop windows

So this is a **“medium breakpoint”**.

---

## 2️⃣ `.home__container` (Grid container)

This assumes `.home__container` already has something like:

```css
.home__container {
  display: grid;
}
```

So:

- You’re working with **CSS Grid**
    
- This rule adjusts how the grid behaves at this screen size

---

## 3️⃣ `grid-template-columns: 400px;`

### What this does

> Forces the grid to have **one column that is exactly 400px wide**

Instead of:

- Stretching full width
    
- Or being too narrow on medium screens
    

This creates a **controlled content width**.

---

## 4️⃣ `justify-content: center;`

### What this does

> Centers the **entire grid column** horizontally inside the container

Without this:

- The 400px column would sit on the **left**
    
- Leaving awkward empty space on the right
    

With this:

- The content is **perfectly centered**
    

---

## 🧠 WHY this is needed (the real reason)

### The problem this solves

On medium screens:

- Full-width layouts look **too stretched**
    
- Single-column content feels **unbalanced**
    
- Text lines become too long (bad readability)
    

So instead of:

```
| content content content content |
```

You get:

```
|        content (400px)         |
```

Centered. Clean. Readable.

---

## 🧩 Why not do this on mobile?

On small screens (< 540px):

- 400px may **overflow**
    
- You want full-width usage
    

So this rule only activates **after there’s enough space**.

---

## 🧩 Why not do this on desktop?

On large screens:

- You’ll usually switch to **multiple columns**
    
- Or a larger max-width (e.g., 1120px)
    

This is just the **middle step** in responsive scaling.

---

## 🔁 Typical Responsive Flow (What You’re Seeing)

```text
Mobile        → full width (default)
Medium (540+) → centered 400px column
Desktop       → multi-column layout
```

This is **professional, mobile-first design**.
