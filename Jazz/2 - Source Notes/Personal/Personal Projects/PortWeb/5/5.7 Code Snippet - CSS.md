The “rows” come from **CSS Grid** too (same idea as the columns).

You have this global rule:

```css
.grid {
  display: grid;
  gap: 1.5rem;
}
```

So any element with class `grid` becomes a grid container.

### Where do the rows “form”?
In a grid, if you **don’t** define `grid-template-rows`, the browser uses the default:

- `grid-auto-flow: row` (items fill **row by row**)
- `grid-auto-rows: auto` (each row’s height fits its content)

So rows are created automatically as the grid items stack.

### Specifically for `.home__data`
Your HTML has `class="home__data grid"`, so it’s a grid container. Its children are:

- the subtitle `<p>`
- the title `<h1>`
- the description `<p>`
- the buttons `<div>`

Since you didn’t set columns on `.home__data`, it defaults to **one column**, so each child goes on a new **row** automatically.

### What does `row-gap` do?
When you write:

```css
.home__data {
  row-gap: 1.5rem;
}
```

you’re not *creating* rows — you’re setting the **spacing between the rows that already exist** in that grid.
