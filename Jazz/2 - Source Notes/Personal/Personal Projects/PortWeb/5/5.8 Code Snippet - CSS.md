# Code Snippet - CSS

```css
  .home__buttons{

    margin-top: 3.5rem;

  }
```

`margin-top: 3.5rem;` creates space **above** `.home__buttons`, measured from the **bottom edge of the element before it** (the previous sibling).

In your HTML structure inside `.home__data`, the order is likely:
1. subtitle `<p>`
2. title `<h1>`
3. description `<p>`
4. buttons `<div class="home__buttons">`

So `margin-top: 3.5rem` pushes the buttons **3.5rem down** from the description paragraph above it.

Note: Since `.home__data` is also a grid with `row-gap`, both `row-gap` and `margin-top` can create space. In CSS Grid, margins on grid items **add to** the row-gap (they don't collapse like in normal flow). So you'd get `row-gap + margin-top` of total space above the buttons.
