# const

## 🧠 What `const` Means

```js
const x = 10;
```

**`const` declares a variable whose binding cannot be reassigned.**

In simple terms:

> You **cannot change what the variable points to** after it’s assigned.

---

## 🔑 Key Rules of `const`

### 1️⃣ Must be initialized immediately

```js
const a;     ❌ Error
const a = 5; ✅ Correct
```

You **must** give it a value at declaration.

---

### 2️⃣ Cannot be reassigned

```js
const x = 10;
x = 20; ❌ Error
```

Once assigned → **fixed reference**.

---

### 3️⃣ Block-scoped (like `let`)

```js
{
  const y = 5;
}
console.log(y); ❌ Error
```

It exists **only inside the block `{}`**.

---

## ⚠️ The Most Common Confusion (Very Important)

### ❗ `const` does NOT mean “immutable”

```js
const arr = [1, 2, 3];
arr.push(4); ✅ Allowed
```

Why?

- The **array reference** is constant
    
- The **contents** are still mutable
    

But this is NOT allowed:

```js
arr = [4, 5]; ❌ Error
```

Same with objects:

```js
const user = { name: "Ishu" };
user.name = "Alex"; ✅ Allowed
user = {}; ❌ Error
```

---

## 🧠 Mental Model (Memorize This)

```
const → the variable name cannot be reassigned
```

Not:

```
const → value can never change
```

---

## 🆚 `const` vs `let` vs `var`

|Feature|`const`|`let`|`var`|
|---|---|---|---|
|Reassignable|❌ No|✅ Yes|✅ Yes|
|Block scoped|✅ Yes|✅ Yes|❌ No|
|Hoisted|✅ (TDZ)|✅ (TDZ)|✅ (undefined)|
|Best practice|⭐⭐⭐|⭐⭐|❌|

**TDZ** = Temporal Dead Zone (can’t use before declaration).

---

## 🎯 When to Use `const` (Best Practice)

Use `const` when:

- The variable should not be reassigned
    
- You want safer, predictable code

Examples:

```js
const API_URL = "https://api.example.com";
const navMenu = document.getElementById("nav-menu");
const colors = ["red", "blue"];
```

Use `let` only when reassignment is needed:

```js
let count = 0;
count++;
```

---

## 🎯 Interview-Ready Explanation

> “`const` declares a block-scoped variable whose reference cannot be reassigned, though the contents of objects or arrays declared with `const` can still be modified.”

---

## 🧠 One-Line Rule (Memorize This)

> **Use `const` by default. Use `let` only when reassignment is required.**
