# 3.2 display flex; - CSS

`display: flex;` turns an element into a **Flexbox container**, enabling a powerful layout system for arranging its direct children.

---

## 🧠 What `display: flex;` Does

```css
display: flex;
```

This tells the browser:

> **“Lay out this element’s direct children using the Flexbox layout model.”**

The element becomes a **flex container**.  
Its **direct children** become **flex items**.

---

## 🔁 Before vs After

### ❌ Without Flexbox

```html
<div class="box">
  <div>A</div>
  <div>B</div>
</div>
```

- Elements stack vertically
    
- Hard to align and space

---

### ✅ With Flexbox

```css
.box {
  display: flex;
}
```

- Items line up in a row (by default)
    
- Easy alignment and spacing

---

## 🧭 Default Behavior of Flexbox

When you apply `display: flex`:

|Property|Default|
|---|---|
|Direction|`row`|
|Wrap|`nowrap`|
|Main axis|Horizontal|
|Cross axis|Vertical|

So children are laid out **left → right**.

---

## 🧩 What Flexbox Enables

Once `display: flex` is set, you can use:

### Align items horizontally

```css
justify-content: space-between;
```

### Align items vertically

```css
align-items: center;
```

### Change direction

```css
flex-direction: column;
```

### Allow wrapping

```css
flex-wrap: wrap;
```

---

## 🧠 Common Example (Navbar)

```css
.nav {
  display: flex;
  justify-content: space-between;
  align-items: center;
}
```

Result:

- Logo on left
    
- Menu on right
    
- Perfect vertical centering
    

---

## 🧪 Important Rule (Often Missed)

Flexbox affects **only direct children**.

```html
<div class="flex">
  <div>✔ flex item</div>
  <div>
    <div>❌ not a flex item</div>
  </div>
</div>
```

Only the first-level `<div>` elements are flex items.

---

## 🎯 Interview-Ready Explanation

> “`display: flex` enables the Flexbox layout model, allowing flexible alignment and distribution of space among an element’s direct children.”

Perfect answer.

---

## 🧠 One-Line Rule

> **`display: flex` controls how children are laid out, not the element itself.**
