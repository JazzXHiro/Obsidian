# outline; none - CSS

`outline: none;` removes the **default focus outline** that appears when an input field is clicked or focused.

### What it does:

**Without `outline: none;`:**
When you click on an input field, the browser adds a default glowing outline (usually blue or browser-dependent):

```
┌─────────────────────┐
│ Input field         │  ← Default blue glow appears here
└─────────────────────┘
```

**With `outline: none;`:**
```
┌─────────────────────┐
│ Input field         │  ← No outline, just your custom border
└─────────────────────┘
```

### In your code:

```css
.contact__input {
  border: 2px solid var(--first-color);  /* Your custom cyan border */
  outline: none;                          /* Remove default browser outline */
}
```

You're removing the browser's default outline so the **custom cyan border** you defined is the only visual feedback when someone focuses on the input field.

**Note:** `outline: none;` can hurt accessibility since users won't see focus indication. A better approach is to add custom focus styling:

```css
.contact__input:focus {
  outline: none;
  box-shadow: 0 0 0 3px rgba(cyan, 0.3);  /* Custom focus effect */
}
```

But for your dark portfolio design with the cyan border, `outline: none;` works fine.
