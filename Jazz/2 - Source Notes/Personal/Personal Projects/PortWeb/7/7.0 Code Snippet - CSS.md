# Code Snippet - CSS

`repeat(2, 350px)` is a shorthand that creates **2 columns, each 350px wide**.

```css
grid-template-columns: repeat(2, 350px);
```

Is equivalent to:

```css
grid-template-columns: 350px 350px;
```

### Syntax:

```css
repeat(count, size)
```

- **count** — How many times to repeat
- **size** — The column width

### Visual:

```
┌────────────────────────────────────────┐
│   ┌──────────┐    ┌──────────┐         │
│   │  350px   │    │  350px   │         │
│   │  col 1   │    │  col 2   │         │
│   └──────────┘    └──────────┘         │
└────────────────────────────────────────┘
```

### Why use `repeat()`?

It's cleaner when you have many columns:

```css
/* Without repeat - tedious! */
grid-template-columns: 1fr 1fr 1fr 1fr 1fr 1fr;

/* With repeat - cleaner */
grid-template-columns: repeat(6, 1fr);
```

In your case with just 2 columns, either way works, but `repeat()` is a common convention and scales better if you ever need more columns.
