# display; grid; vs display; flex;

Both create flexible layouts, but they work in **different dimensions**:

### `display: flex;` — 1D Layout (One Direction)

Arranges items in **one line** (row or column):

```css
.container {
  display: flex;
  flex-direction: row;  /* Left to right */
}
```

```
Item 1  Item 2  Item 3  Item 4
← One line, flowing in one direction →
```

**Use flexbox for:**
- Navigation menus (horizontal links)
- Button groups
- Single rows or columns
- Centering content

### `display: grid;` — 2D Layout (Two Directions)

Arranges items in **rows AND columns** simultaneously:

```css
.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);  /* 3 columns */
}
```

```
Item 1  Item 2  Item 3
Item 4  Item 5  Item 6
Item 7  Item 8  Item 9
↑                     ↑
Rows flowing downward, columns flowing across
```

**Use grid for:**
- Multi-column layouts (like your projects section)
- Tables/data displays
- Complex page layouts
- Gallery/card grids

### In Your Portfolio:

```css
.nav__list {
  display: flex;          /* Navigation items in one column/row */
  flex-direction: column;
}

.projects__container {
  display: grid;          /* Projects in 2D grid (2-3 columns) */
  grid-template-columns: repeat(2, 350px);
}
```

**Simple rule:** Use **flex** for single-line layouts, **grid** for multi-row/multi-column layouts.

## Doesn't flex-wrap do the same thing as display: grid; then?

No, `flex-wrap` and `display: grid;` are **fundamentally different**:

### `flex-wrap: wrap;`
Allows a **single flex row** to wrap to multiple rows when items don't fit.

```css
.container {
  display: flex;
  flex-wrap: wrap;  /* Items wrap to next line */
}
```

```
Item 1  Item 2  Item 3
Item 4  Item 5
← Still 1D layout, just wrapping to new lines
```

### `display: grid;`
Creates a **true 2D grid** with explicit rows and columns defined upfront.

```css
.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);  /* 3 columns defined */
}
```

```
Item 1  Item 2  Item 3
Item 4  Item 5  Item 6
← Proper 2D grid with fixed structure
```

### Key Difference:

| Feature | `flex-wrap` | `display: grid` |
|---------|------------|-----------------|
| Dimensions | 1D (rows OR columns) | 2D (rows AND columns) |
| Wrapping | Responsive wrapping | Fixed structure |
| Column control | No column definition | Explicit columns |
| Alignment | Limited to flex properties | Full 2D alignment control |

**Example:** With `flex-wrap`, items might wrap at different points depending on screen width. With `grid`, you **define exactly 3 columns** and items always align to that structure.

They're different tools for different layouts!
