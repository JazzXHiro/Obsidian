# section vs div

## `section` vs `div` (HTML)

### Core difference

- **`section`** is **semantic** (has meaning).
    
- **`div`** is **non-semantic** (no meaning).

---

## `section`

### What it is

A semantic element used to group **related content that forms a logical section** of a page.

### When to use it

Use `section` when the content:

- Has a **clear topic or purpose**
    
- Could reasonably have a **heading**
    
- Represents a **distinct part** of the page

### Example

```html
<section id="projects">
  <h2>Projects</h2>
  <p>My recent work</p>
</section>
```

### Why it matters

- Improves **SEO**
    
- Improves **accessibility** (screen readers understand page structure)
    
- Makes HTML easier to understand and maintain

---

## `div`

### What it is

A generic container with **no semantic meaning**.

### When to use it

Use `div` when:

- You only need a container for **styling or layout**
    
- There is **no meaningful section** to describe
    
- It’s a purely structural wrapper

### Example

```html
<div class="card">
  <img src="project.png">
  <p>Description</p>
</div>
```

---

## Key Differences (Direct Comparison)

|Aspect|`section`|`div`|
|---|---|---|
|Semantic meaning|Yes|No|
|SEO impact|Yes|No|
|Accessibility|Helps screen readers|Neutral|
|Requires heading|Recommended|Not needed|
|Layout use|Yes|Yes|

---

## Important Rules (Practical)

- **Do not** use `section` just to replace `div`
    
- If you can **name the content**, use `section`
    
- If it’s just a wrapper, use `div`
    
- A `section` should usually contain a heading (`h1–h6`)
    

---

## Common Portfolio Example (Correct Usage)

```html
<section id="home"></section>
<section id="about"></section>
<section id="projects"></section>
<section id="contact"></section>
```

Inside them:

```html
<div class="container">
  <!-- layout elements -->
</div>
```

This is the **correct pattern**.

---

## Interview-ready answer

> "`section` is a semantic element used for meaningful page sections, while `div` is a generic container used only for layout or styling."
