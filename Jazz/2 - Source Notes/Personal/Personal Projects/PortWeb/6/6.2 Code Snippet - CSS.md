# Code Snippet - CSS

Good question! Yes, `.about__data` gets `text-align: initial`, but that's not enough for `.section__title` because:

**The issue: specificity / direct rules beat inheritance**

1. `.section__title` has `text-align: center;` set **directly on it** (line 120)
2. `.about__data { text-align: initial; }` only sets alignment on the parent
3. Children *would* inherit `text-align` from parent... **BUT** a direct rule on an element always beats an inherited value

So even though `.about__data` is left-aligned, the `.section__title` inside it still has its own direct `text-align: center` rule, which wins.

**That's why you need all three:**

```css
.home__data,              /* sets text-align on home data */
.about__data,             /* sets text-align on about data */
.about__data .section__title{  /* overrides the DIRECT rule on section__title */
  text-align: initial;
}
```

Without the third line, the section title would stay centered because its own `text-align: center` beats the inherited value from `.about__data`.
