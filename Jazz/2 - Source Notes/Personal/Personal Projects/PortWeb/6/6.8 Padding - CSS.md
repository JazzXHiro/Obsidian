# Padding - CSS

## What is padding (definition)

**Padding is the inner space between an element’s content and its border.**  
It increases the clickable/visual area **inside** the element.

---

## All padding properties in CSS

### 1. `padding` (shorthand)

Sets padding on **all four sides**.

```css
padding: 1rem;
```

Order when using multiple values:

```css
padding: top right bottom left;
```

Examples:

```css
padding: 1rem;               /* all sides */
padding: 1rem 2rem;          /* top/bottom | left/right */
padding: 1rem 2rem 3rem;     /* top | left/right | bottom */
padding: 1rem 2rem 3rem 4rem;/* top | right | bottom | left */
```

---

### 2. Physical padding properties (direction-based)

These are **fixed directions**, not language-aware.

```css
padding-top
padding-right
padding-bottom
padding-left
```

Example:

```css
padding-top: 1rem;
padding-left: 2rem;
```

---

### 3. Logical padding properties (modern, recommended)

These adapt automatically to **writing direction (LTR / RTL)**.

#### Block direction (vertical flow)

```css
padding-block
padding-block-start
padding-block-end
```

Example:

```css
padding-block: 1rem;            /* top + bottom */
padding-block-start: 2rem;      /* top (in LTR) */
```

---

#### Inline direction (text flow)

```css
padding-inline
padding-inline-start
padding-inline-end
```

Example:

```css
padding-inline: 1.5rem;         /* left + right (in LTR) */
padding-inline-end: 2rem;
```

---

## Physical vs Logical (important distinction)

|Type|Properties|Use case|
|---|---|---|
|Physical|`padding-left`, `padding-right`|Simple layouts|
|Logical|`padding-inline`, `padding-block`|Responsive + RTL-safe|

---

## Units allowed in padding

Padding accepts:

- `px`
    
- `rem`
    
- `em`
    
- `%`
    
- `vw`, `vh`
    
- `calc()`
    

Example:

```css
padding: calc(1rem + 2px);
```

❌ Padding **cannot be negative**.

---

## What padding affects

- Increases element’s **visual size**
    
- Affects **clickable area**
    
- Included in layout size unless `box-sizing: border-box` is used
    

---

## Common real-world pattern

```css
.container {
  max-width: 1120px;
  margin-inline: auto;
  padding-inline: 1.5rem;
}
```

---

## Interview-ready definition

> “Padding defines the internal spacing between an element’s content and its border and can be set using shorthand, physical, or logical properties.”
