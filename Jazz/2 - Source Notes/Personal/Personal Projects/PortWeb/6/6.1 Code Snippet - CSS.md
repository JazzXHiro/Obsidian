# Code Snippet - CSS

Looking at the context:

```css
.about__subtitle i{
  font-size: 1.5rem;
  font-weight: initial;
}
```

This targets an **icon** (`<i>`) inside `.about__subtitle`.

**What `font-weight: initial` does here:**
- Resets `font-weight` back to its default value (`normal` / 400)
- This prevents the icon from inheriting bold weight from parent elements

**Why it's needed:**
- Your headings have `font-weight: var(--font-semi-bold)` (600)
- `.about__subtitle` uses `--h3-font-size`, so it likely inherits bold styling
- Icon fonts (like Remix Icons) can look **distorted or broken** when rendered in bold
- Setting `initial` ensures the icon displays correctly with normal weight

Without this, the icon might appear thicker/bolder than intended, which can look off for icon fonts.
